## 6.6.11 RI-MP2 Method with the Laplace Transformation

(July 4, 2026)

Joonho Lee working with Martin Head-Gordon added a libgmbpt-based
Laplace-transformed RI-MP2 implementation for both same-spin and opposite-spin
correlations.[[784]](../bib_references/bib.md#bib829)
 To use this feature, one can just add
LAPLACE_TRANSFORM TRUE to the *$rem* block.
