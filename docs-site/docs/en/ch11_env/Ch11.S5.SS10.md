## 11.5.10 Calculation of User-Defined EFP Potentials

(July 4, 2026)

User-defined EFP parameters can be generated in “MAKEFP” job in **gamess**; see the
**gamess** manual for details. The user-defined parameter (`.efp`) files should be located in the
working directory; the name of the `.efp` file should match exactly the name of the fragment,
for example, beginning of the `cl_ion.efp` parameter file should look like:

```qchem
$cl_ion
 Comment line
 COORDINATES (BOHR)
  ....
```

The EFP potential generation begins by determining an accurate structure for
the fragment (EFP is the frozen-geometry potential, so the fragment geometry
will remain the same in all subsequent calculations). We recommend MP2/cc-pVTZ level of theory.

## 11.5.10.1 Generating EFP Parameters Using **gamess**

EFP parameters can be generated in **gamess** using a “MAKEFP” job (`RUNTYP=MAKEFP` in **gamess**).
For EFP parameters calculations, 6-311++G(3df,2p) basis set is recommended.
Originally Stone’s distributed multipole analysis
is recommended for non-aromatic compounds (`bigexp = 0` in the group `$stone`);
optionally, one may decrease the
basis set to 6-31G* or 6-31+G* for generation of electrostatic multipoles and
screening parameters. (To prepare such a “mixed” potential, one has to run two
separate MAKEFP calculations in larger and smaller bases, and combine the
corresponding parts of the potential). In aromatic compounds, one must either
use numerical grid for generation of multipoles (`bigexp = 4.0`) or use 6-31G*
basis with standard analytic DMA, which is recommended. The MAKEFP job produces
(usually in the scratch directory) the `.efp` file containing all the necessary
EFP parameters. See the **gamess** manual for further details. Below are examples of a **gamess** input file for
RUNTYP = MAKEFP, for water and for benzene.

```qchem
GAMESS input example for water.

 $contrl units=angs local=boys runtyp=makefp coord=cart icut=11 $end
 $system timlim=99999 mwords=200 $end
 $scf soscf=.f. diis=.t. conv=1.0d-06 $end
 $basis gbasis=n311 ngauss=6 npfunc=2 ndfunc=3 nffunc=1
   diffs=.t. diffsp=.t. $end
 $damp ifttyp(1)=3,2 iftfix(1)=1,1 thrsh=500.0 $end
 $dampgs
h3=h2
bo31=bo21
 $end
 $makefp chtr=.f. disp7=.f. $end
 $data
 water h2o (geometry: mp2/cc-pvtz)
 c1
o1 8.0  0.0000  0.0000  0.1187
h2 1.0  0.0000  0.7532 -0.4749
h3 1.0  0.0000 -0.7532 -0.4749
 $end
```

In QM/EFP calculations of excited states, the user might skip computing exchange-repulsion
and dispersion parameters, as these terms are not coupled to the QM region and do not
affect the excitation energies. In this case, a recommended template for the parameter
preparation in **gamess**is the following:

```qchem
! GAMESS template for preparing fragments for excited state QM/EFP calculations

 $contrl units=angs local=boys runtyp=makefp coord=cart icut=11 $end
 $system timlim=99999  mwords=200 $end
 $scf dirscf=.t. soscf=.f. diis=.t. conv=1.0d-06  $end
 $basis gbasis=n31 ngauss=6 ndfunc=1 diffsp=.t. $end
 $damp ifttyp(1)=2,0 iftfix(1)=1,1 thrsh=500.0 $end
 $makefp POL=.t. DISP=.f. CHTR=.f.  EXREP=.f. $end

 $data
comment line
C1
N  7  1.08099635  1.08099635  1.08099635
H  1  1.89264145  1.37035655  0.59462495
H  1  1.37035655  0.59462495  1.89264145
H  1  0.59462495  1.89264145  1.37035655
 $end
```
