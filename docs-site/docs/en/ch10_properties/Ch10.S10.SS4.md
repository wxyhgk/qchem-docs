computed analytically using the MOProp module"

    ```qchem
     1 2
       O  0.003  1.517  0.000
       H  0.913  1.819  0.000

       MOPROP              2
       MOPROP_CONV_1ST     8
       MOPROP_MAXITER_1ST  200

       POINT_GROUP_SYMMETRY false
    $end
    ```
