## 10.2.1 Introduction

(July 4, 2026)

**Q-Chem** performs some standard wave function analyses by default.
Setting WAVEFUNCTION_ANALYSIS = FALSE in the *$rem* section will turn off all
wave function analysis features, or alternatively these can be controlled individually as described in this section.
The Natural Bond Orbital (NBO) analysis program is interfaced with **Q-Chem** and can perform more sophisticated analyses;
see Section [10.3.1](sect_NBO.md) for more details.

WAVEFUNCTION_ANALYSIS

### `WAVEFUNCTION_ANALYSIS`

> **Controls the running of the default wave function analysis tasks.**
>
> * **Type**: `LOGICAL`
> * **Default**: `TRUE`
> * **Options**:
>     * TRUE
>     * Perform default wave function analysis.
>     * FALSE
>     * Do not perform default wave function analysis.
> * **Recommendation**: None. This option has no effect on NBO analysis.
