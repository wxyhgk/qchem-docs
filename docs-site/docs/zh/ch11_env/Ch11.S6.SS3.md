## 11.6.3 基于投影的嵌入外部接口

（2026 年 7 月 4 日）

现已提供一种通用的基于投影的嵌入（projection-based embedding）接口，可使用来自外部程序的分子轨道（molecular orbitals），

目前该接口已配置为可与 **CP2K** 程序生成的分子轨道（MO）配合使用。[[737]](../bib_references/bib.md#bib771)

通过将 EXTERNAL_EMBED 设置为 CP2K 即可启用此选项。外部嵌入计算任务需要一个
*$cp2k* 节段，用于指定来自 **CP2K** 的分子轨道文件（参见下方示例）。

该接口的工作流程如下：

1. 发起一次 **Q-Chem** 计算，程序将生成 **CP2K** 格式的坐标文件和基组（basis set）文件。
输出文件中会包含一段 **CP2K** 输入片断，指向坐标文件与基组文件的路径。
2. 执行采用高斯 augmented plane wave（GAPW，高斯加平面波）方法的 **CP2K** 计算，并生成分子轨道（MO）文件。
3. 重新发起 **Q-Chem** 计算，并在输入文件中指定所使用的 **CP2K** 分子轨道（MO）。
4. 外部嵌入机制（external embedding machinery）
解析 MO 文件并将其存储，从而在基于投影的嵌入理论流程中生成低级别超大体系（supersystem）能量。

要成功使用该接口，需要具备运行 **CP2K** 的实际知识。

### `GEN_SCFMAN_EMBED`

> **使用基于 GEN_SCFMAN 的实现来运行基于投影的嵌入计算**
>
> * **类型**：`BOOLEAN`
> * **默认值**：`FALSE`
> * **选项**：
>     * TRUE
>     * 执行基于投影的嵌入计算
>     * FALSE
>     * 不执行嵌入计算
> * **建议**：无

???+ example "示例 11.46：使用 CP2K 的外部嵌入——水二聚体的 R-in-R（PBE0 嵌入周期体系 PBE0）计算。"
    ```qchem
    $molecule
    0 1
    ---
    0 1
      O   -2.4811226    1.4547870   -0.0204910
      H   -1.4917963    1.4805135    0.0137861
      H   -2.7704879    2.0232698    0.7369378
    ---
    0 1
      O   -7.4811226    1.4547870   -0.0204910
      H   -6.4917963    1.4805135    0.0137861
      H   -7.7704879    2.0232698    0.7369378
    $end
    
    $rem
    exchange pbe0
    basis def2-svp
    gen_scfman_embed true
    external_embed cp2k
    env_method pbe0
    spade_partition true
    concentric_virts true
    !embedding_early_stop true
    scf_convergence 8
    scf_algorithm GDM
    mem_total 180000
    mem_static 8000
    max_scf_cycles 200
    $end
    
    $cp2k
        mo_file H2O-my_mos-1_0.MOLog
    $end
    ```
