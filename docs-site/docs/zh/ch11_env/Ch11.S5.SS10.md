## 11.5.10 用户自定义 EFP 势的计算

（2026 年 7 月 4 日）

用户自定义的 EFP（Effective Fragment Potential，有效片段势）参数可以在 **gamess** 的 "MAKEFP" 作业（job）中生成；详情请参阅 **gamess** 手册。用户定义的参数（`.efp`）文件应放置在当前工作目录中；`.efp` 文件的名称必须与片段的名称完全一致，例如，`cl_ion.efp` 参数文件的开头部分应如下所示：

```qchem
$cl_ion
 Comment line
 COORDINATES (BOHR)
  ....
```

EFP 势的生成首先要为片段确定一个精确的结构（EFP 是冻结几何构型的势，因此片段的几何结构在后续所有计算中将保持不变）。我们建议采用 MP2/cc-pVTZ 理论水平。

## 11.5.10.1 使用 **gamess** 生成 EFP 参数

可以在 **gamess** 中使用 "MAKEFP" 作业（在 **gamess** 中设置 `RUNTYP=MAKEFP`）来生成 EFP 参数。对于 EFP 参数的计算，推荐使用 6-311++G(3df,2p) 基组（Basis Set）。最初推荐对非芳香化合物使用 Stone 的分布式多极分析（Distributed Multipole Analysis, DMA）（在 `$stone` 基组中设置 `bigexp = 0`）；作为一种可选方案，在生成静电多极矩和屏蔽参数时，可以将基组减小为 6-31G* 或 6-31+G*。（若要制备 such 一种"混合"势，需要分别在较大和较小的基组下运行两次独立的 MAKEFP 计算，然后将势的相应部分组合起来。）对于芳香化合物，必须要么使用数值网格生成多极矩（`bigexp = 4.0`），要么使用 6-31G* 基组配合标准的解析 DMA，后者是推荐做法。MAKEFP 作业会生成（通常在临时目录中）包含所有必要 EFP 参数的 `.efp` 文件。更多详情请参阅 **gamess** 手册。以下是用于 RUNTYP = MAKEFP 的 **gamess** 输入文件示例，分别针对水和苯。

```qchem
GAMESS input example for water.

 $contrl units=angs local=boys runtyp=makefp coord=cart icut=11 $end
 $system timlim=99999 mwords=200 $end
 $scf soscf=.f. diis=.t. conv=1.0d-06 $end
 $basis gbasis=n311 ngauss=6 npfunc=2 ndfunc=3 nffunc=1
   diffs=.t. diffsp=.t. $end
 $damp ifttyp(1)=3,2 iftfix(1)=1,1 thrsh=500.0 $end
 $dampgs
h3=h2
bo31=bo21
 $end
 $makefp chtr=.f. disp7=.f. $end
 $data
 water h2o (geometry: mp2/cc-pvtz)
 c1
o1 8.0  0.0000  0.0000  0.1187
h2 1.0  0.0000  0.7532 -0.4749
h3 1.0  0.0000 -0.7532 -0.4749
 $end
```

在激发态的 QM/EFP（量子力学/有效片段势）计算中，用户可以跳过交换排斥（exchange-repulsion）和色散（dispersion）参数的计算，因为这些项不与 QM 区域发生耦合，也不会影响激发能。在这种情况下，**gamess** 中用于参数制备的推荐模板如下：

```qchem
! GAMESS template for preparing fragments for excited state QM/EFP calculations

 $contrl units=angs local=boys runtyp=makefp coord=cart icut=11 $end
 $system timlim=99999  mwords=200 $end
 $scf dirscf=.t. soscf=.f. diis=.t. conv=1.0d-06  $end
 $basis gbasis=n31 ngauss=6 ndfunc=1 diffsp=.t. $end
 $damp ifttyp(1)=2,0 iftfix(1)=1,1 thrsh=500.0 $end
 $makefp POL=.t. DISP=.f. CHTR=.f.  EXREP=.f. $end

 $data
comment line
C1
N  7  1.08099635  1.08099635  1.08099635
H  1  1.89264145  1.37035655  0.59462495
H  1  1.37035655  0.59462495  1.89264145
H  1  0.59462495  1.89264145  1.37035655
 $end
```
