## 11.3.3 附加作业控制变量

（2026 年 7 月 4 日）

通过设置 *$rem* 变量 QM_MM_INTERFACE 和 FORCE_FIELD 来请求 QM/MM 作业。
此外还需要 *$qm_atoms* 输入段，并对 *$molecule* 段进行适当的修改，如前文所述。此处详述其他作业控制变量。

### `QM_MM_INTERFACE`

> **启用内部 QM/MM 计算。**
>
> * **类型**: `STRING`
> * **默认值**: `NONE`
> * **选项**:
>     * `MM`: 分子力学计算（即，不含 QM 区域）
>     * `ONIOM`: 使用两层力学嵌入（mechanical embedding）的 QM/MM 计算
>     * `JANUS`: 使用电子嵌入（electronic embedding）的 QM/MM 计算
> * **建议**: ONIOM 模型与 Janus 模型已在前文描述。选择 MM 将不进行任何电子结构计算。不过，使用 MM 时仍需定义 $rem 变量 BASIS 和 EXCHANGE，以便 Q-Chem 顺利运行。

### `FORCE_FIELD`

> **指定 QM/MM 计算中 MM 能量所使用的力场。**
>
> * **类型**: `STRING`
> * **默认值**: `NONE`
> * **选项**:
>     * `AMBER99`
>     * AMBER99 力场
>     * `CHARMM27`
>     * CHARMM27 力场
>     * `OPLSAA`
>     * OPLSAA 力场
> * **建议**: 无。

### `CHARGE_CHARGE_REPULSION`

> **YinYang 原子的排斥库仑相互作用参数。**
>
> * **类型**: `INTEGER`
> * **默认值**: `550`
> * **选项**:
>     * $n$: 使用 Q = $n\times 10^{-3}$
> * **建议**: 排斥库仑势用于维持涉及 YinYang 原子的键长，其势能为 $V(r)=Q/r$ 。默认参数针对碳原子进行了参数化。

### `FORCEMAN_PRINT`

> **控制 MM（以及 QM/MM）作业的打印级别。**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **选项**:
>     * `0`: 最少打印，适用于运行 many 步的大型 MM 作业。
>     * `1`: 附加信息，包括 MM 梯度。
>     * `2`: 打印 MM 能量表达式中的各项。
>     * `3`: 打印连接性信息。
>     * `4`: 打印 MM 梯度中的各项。
> * **建议**: 除非试图诊断问题，否则使用默认值。

### `GAUSSIAN_BLUR`

> **在 QM/MM 计算中启用高斯离域外部电荷。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * `TRUE`: 使用高斯函数使外部电荷离域。
>     * `FALSE`: 点电荷
> * **建议**: 无

### `GAUSS_BLUR_WIDTH`

> **Janus 计算中外部 MM 高斯电荷的离域宽度。**
>
> * **类型**: `INTEGER`
> * **默认值**: `NONE`
> * **选项**:
>     * $n$: 使用宽度 $n\times 10^{-4}$ Å。
> * **建议**: 在 QM/MM 计算中以指定宽度对所有 MM 外部电荷进行高斯模糊（Gaussian blurring）。目前高斯模糊与 PCM 计算不兼容。参考文献 300 Das D. et al. J. Chem. Phys. (2002) , 117 , pp. 10534 . Link . 推荐值为 1.0–2.0 Å。

### `MM_SUBTRACTIVE`

> **指定在计算的 $E_{\mathrm{Coul}}$ 部分（公式 ( 11.50 ) ）中是否使用减去法（subtractive）方案。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * `FALSE`: 仅使用非 1-2、1-3 或 1-4 的对。
>     * `TRUE`: 计算所有对，然后减去被重复计算的对（1-2、1-3 和 1-4）。
> * **建议**: 运行 QM/MM 或 MM 计算时无特别建议。运行 QM/MM-Ewald 计算时，该值必须设置为 TRUE 。

### `MODEL_SYSTEM_CHARGE`

> **当 QM 子系统的电荷与 $molecule 段不同时，指定该电荷值。**
>
> * **类型**: `INTEGER`
> * **默认值**: `NONE`
> * **选项**:
>     * $n$: QM 子系统的电荷。
> * **建议**: 仅当 QM 子系统（模型体系）的电荷与整个体系的电荷不同时，才需要使用此选项。

### `MODEL_SYSTEM_MULT`

> **当 QM 子系统的自旋多重度与 $molecule 段不同时，指定该多重度。**
>
> * **类型**: `INTEGER`
> * **默认值**: `NONE`
> * **选项**:
>     * $n$: QM 子系统的自旋多重度。
> * **建议**: 仅当 QM 子系统（模型体系）的自旋多重度与整个体系的多重度不同时，才需要使用此选项。ONIOM 计算必须为闭壳层（closed shell）。

### `PRINT_INPUT`

> **指定是否在输出中回显输入文件。**
>
> * **类型**: `INTEGER`
> * **默认值**: `TRUE`
> * **选项**:
>     * `TRUE`: 将 Q-Chem 输入文件作为 Q-Chem 输出文件的一部分打印出来。
>     * `FALSE`: 不重复输出输入文件。
> * **建议**: 此选项便于存档记录，默认值为 TRUE；但 QM/MM 作业除外——由于某些输入文件体积较大，其默认值为 FALSE。

### `USER_CONNECT`

> **启用显式定义的化学键。**
>
> * **类型**: `STRING`
> * **默认值**: `FALSE`
> * **选项**:
>     * `TRUE`: 从 $molecule 段读取键连接性
>     * `FALSE`: 由原子间距离判定键连接性
> * **建议**: 若已知键连接性，则设置为 TRUE，此时必须在该 $molecule 段中指定此连接性。这可以显著加速 MM 计算。
