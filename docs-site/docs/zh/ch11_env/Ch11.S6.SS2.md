## 11.6.2 嵌入计算的作业控制

(July 4, 2026)

DFT-in-DFT 与波函数-in-DFT 计算在 **Q-Chem** 中是在其默认 SCF 引擎 GEN_SCFMAN 的框架下实现的，该引擎通过设置 GEN_SCFMAN_EMBED = TRUE 来触发。嵌入计算需要通过 *$molecule* 部分指定片段（参见第 [12.2](../ch12_frag/sect_FRAGinput.md) 节）。除非另有说明，第一个片段被视为被嵌入的（“活性”）片段。用户可以通过 *$embed_fragment* 部分选择被嵌入的片段。

高水平电子结构方法由 *$rem* 变量 METHOD 给出，低水平方法可以通过 ENV_METHOD 指定。注意，应选择平均场方法作为低水平理论，例如纯泛函或杂化密度泛函。与先前基于 “EmbedMan” 的嵌入理论实现（第 [11.6.5](subsec_embedman.md) 节）不同，对高水平方法没有限制。当前支持的选项包括用于基态计算的杂化 DFT（*e.g.*，$\omega$B97X-V）和相关波函数方法（*e.g.*，MP2、CCSD(T) 等），以及用于激发态计算的 TDDFT 和基于波函数的方法（如 EOM-CCSD）。

计算首先从低水平理论的 SCF 计算开始，然后执行嵌入的 SCF 计算，其中使用更高水平的 DFT（对于 DFT-in-DFT 情形）或 Hartree-Fock（对于波函数-in-DFT 情形）。为了使得 post-SCF 相关方法可以直接应用，分子轨道按照 “[Occ(环境) $|$ Occ(活性) $|$ Vir(活性) $|$ Vir(非活性)]” 的顺序存储在磁盘上，环境占据轨道和被排除的非活性虚轨道在相关波函数方法中分别作为冻结核轨道和冻结虚轨道处理。注意，除非通过设置 CONCENTRIC_VIRTS = TRUE 调用同心定域化（concentric localization）方法，否则虚轨道不会被截断，因为这是 **Q-Chem** 中目前唯一可用于基于投影的嵌入理论的虚空间截断方案。

在 **Q-Chem** 5.3 中，基于投影的嵌入理论仅限于整体闭壳层体系（“restricted-in-restricted” 嵌入）。基于非限制（unrestricted）SCF 计算向开壳层体系的扩展已在 **Q-Chem** 5.4.1 及后续版本中启用。

从 **Q-Chem** 5.4.2 起，基于投影的嵌入扩展为支持复基函数（complex basis functions）。这使得可以将 CBF 高水平方法（即 CBF-(EOM-)CCSD 和 CBF-(EOM-)CC2）与复 HF 结合起来（这些方法的理论和实现分别在第 [7.9.10](../ch07_excited/sub_cc_cs_cap.md) 节和第 [4.9.5](../ch04_scf/sec_cbfscf.md) 节中描述）。触发此功能的关键字是 GEN_SCFMAN_NH_EMBED。该框架中未实现 SPADE 分区，轨道通过 Pipek-Mezey 定域化以及实部的 Mulliken 布局分析进行划分。

ENV_METHOD

### `ENV_METHOD`

> **在基于投影的嵌入计算中指定低水平理论**
>
> * **类型**: `STRING`
> * **默认值**: `NONE`
> * **选项**:
>     * 解析方式与
>     * $rem
>     * 变量 “
>     * METHOD
>     * ” 相同
> * **建议**: 应选择平均场方法（纯泛函或杂化密度泛函）。

FIXING_V_EMBED

### `FIXING_V_EMBED`

> **对嵌入计算所使用的能量泛函调用线性化近似**
>
> * **类型**: `BOOLEAN`
> * **默认值**: `TRUE`
> * **选项**:
>     * TRUE
>     * 对能量泛函使用线性化近似 [式 (
>     * 11.106
>     * )]
>     * FALSE
>     * 使用原始能量泛函 [式 (
>     * 11.100
>     * )]
> * **建议**: 使用默认值以节省计算成本

SPADE_PARTITION

### `SPADE_PARTITION`

> **使用 SPADE 方法确定初始的嵌入（活性）轨道集合**
>
> * **类型**: `BOOLEAN`
> * **默认值**: `FALSE`
> * **选项**:
>     * TRUE
>     * 使用 SPADE 对占据空间进行分区
>     * FALSE
>     * 使用 Pipek-Mezey 定域化 + Mulliken 布局分析来指派占据轨道
> * **建议**: 如果能在奇异值谱中检测到显著间隙，则使用 SPADE。

CONCENTRIC_VIRTS

### `CONCENTRIC_VIRTS`

> **使用同心定域化（CL）方案截断虚空间**
>
> * **类型**: `BOOLEAN`
> * **默认值**: `FALSE`
> * **选项**:
>     * TRUE
>     * 使用 CL 方案截断虚空间
>     * FALSE
>     * 不截断虚空间
> * **建议**: 在波函数-in-DFT 计算中使用 CL 截断。

CONCENTRIC_VIRTS_ZETA

### `CONCENTRIC_VIRTS_ZETA`

> **指定截断后虚空间的大小**
>
> * **类型**: `INTEGER`
> * **默认值**: `2`
> * **选项**:
>     * $m$
>     * 经 CL 截断后的虚轨道总数为
>     * $m\times n_{\text{occ}}^{\text{active}}$
> * **建议**: 使用默认值；若要求更高精度，可设置为更大的值。

CONCENTRIC_REF_BASIS

### `CONCENTRIC_REF_BASIS`

> **指定同心定域化过程中的投影基（PB）**
>
> * **类型**: `STRING`
> * **默认值**: `NONE`
> * **选项**:
>     * 解析方式与
>     * BASIS
>     * 相同；若未指定，则使用工作基（WB）作为 PB。
> * **建议**: WB 通常是不错的选择；可以谨慎地选择更小的基组以进一步降低计算成本。

EMBEDDING_EARLY_STOP

### `EMBEDDING_EARLY_STOP`

> **一旦完成体系分区即终止嵌入计算（跳过嵌入 SCF）**
>
> * **类型**: `BOOLEAN`
> * **默认值**: `FALSE`
> * **选项**:
>     * TRUE
>     * 一旦完成体系分区即终止嵌入计算（跳过嵌入 SCF）
>     * FALSE
>     * 执行正常的嵌入计算
> * **建议**: 在环境 ESP/电场计算中开启此选项（参见第 10.6 节）

NADD_XMETHOD

### `NADD_XMETHOD`

> **允许基于用户自定义的 XC 泛函构造嵌入势，与获得超体系密度时所使用的交换-关联泛函无关。**
>
> * **类型**: `STRING`
> * **默认值**: `None`
> * **选项**:
>     * None
>     * 使用与描述环境时相同的交换-关联泛函来构造嵌入势。
>     * GEN
>     * 需要一个
>     * $nadd_xc_functional
>     * 部分来指定所使用的非附加交换-关联泛函。
>     * $nadd_xc_functional
>     * 部分的构造方式如下所示。
>     * $nadd_xc_functional
>     * 中的每一行需要三个变量：X 或 C，用于指明这是交换成分还是关联成分；泛函的符号表示，与 EXCHANGE 或 CORRELATION 关键字变量所使用的写法一致；以及每个成分的实数系数（有关格式的更多细节，另参见第
>     * 5.3.7
>     * 节）。
> * **建议**: None

> ```qchem
> ¯¯$nadd_xc_functional
> ¯¯X   exchange_symbol   coefficient
> ¯¯X   exchange_symbol   coefficient
> ¯¯...
> ¯¯C   correlation_symbol   coefficient
> ¯¯C   correlation_symbol   coefficient
> ¯¯$end
> ¯
> ```

???+ example "示例 11.39: DFT-in-DFT 嵌入计算：$\omega$B97X-V（水分子 2）处于由 PBE 描述的水分子 1 和 3 的环境中。
被嵌入的（“活性”）片段由用户通过 $embed_fragment 部分指定。"
    ```qchem
    $molecule
       0 1
       --
       0 1
       O    -0.00000   -0.00000   0.00000
       H     0.56704    0.41003   0.65488
       H     0.16427   -0.95671   0.05856
       --
       0 1
       O    -0.45701   -2.75857   0.16997
       H    -0.36918   -3.38806  -0.54777
       H    -1.36971   -2.42607   0.12617
       --
       0 1
       O    -2.62421   -0.99554  -0.00046
       H    -3.25789   -0.73194   0.66864
       H    -1.89698   -0.35254   0.04416
    $end
    
    $rem
       METHOD             wb97x-v
       BASIS              def2-svpd
       GEN_SCFMAN_EMBED   true
       THRESH             14
       SCF_CONVERGENCE    8
       ENV_METHOD         pbe
    $end
    
    $embed_fragment
       2
    $end
    ```
