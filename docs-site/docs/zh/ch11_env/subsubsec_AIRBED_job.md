## 11.9.2 AIRBED 作业控制

（2026 年 7 月 4 日）

### `AIRBED`

> **执行 AIRBED 计算。**
>
> * **类型**：`BOOLEAN`
> * **默认值**：`False`
> * **可选值**：
>     * True
>     * 执行 AIRBED 计算。
>     * False
>     * 不执行 AIRBED 计算。
> * **建议**：将 $rem 变量 DFT_D 设置为 EMPIRICAL_GRIMME。

### `AIRBED_ALPHA`

> **设定 $\alpha$ 的数值。**
>
> * **类型**：`INTEGER`
> * **默认值**：`0`
> * **可选值**：
>     * $n$
>     * 对应的
>     * $\alpha$
>     * =
>     * $n/1000$
> * **建议**：对于 hBN（六方氮化硼）表面，取 0 或 -1200。
