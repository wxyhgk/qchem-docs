## 11.5.12 输入关键字

（2026 年 7 月 4 日）

EFP_COORD_XYZ

### `EFP_COORD_XYZ`

> **使用三个原子的坐标（而非欧拉角）来指定片段的位置和取向**
>
> * **类型**：`LOGICAL`
> * **默认值**：`FALSE`
> * **选项**：
>     * TRUE FALSE
> * **建议**：无

EFP_DIRECT_POLARIZATION_DRIVER

### `EFP_DIRECT_POLARIZATION_DRIVER`

> **对 EFP 极化使用直接求解器**
>
> * **类型**：`LOGICAL`
> * **默认值**：`FALSE`
> * **选项**：
>     * TRUE FALSE
> * **建议**：直接极化求解器可实现诱导偶极的稳定收敛，而当片段彼此靠得很近、极化性强或带电时，收敛可能成为问题。对于包含超过 10000 个可极化点的体系，直接极化相比迭代极化的计算开销会更高。

EFP_ENABLE_LINKS

### `EFP_ENABLE_LINKS`

> **在 EFP 区域中启用片段连接（links）**
>
> * **类型**：`LOGICAL`
> * **默认值**：`FALSE`
> * **选项**：
>     * TRUE FALSE
> * **建议**：无

EFP

### `EFP`

> **指定请求进行 EFP 计算**
>
> * **类型**：`LOGICAL`
> * **默认值**：`FALSE`
> * **选项**：
>     * TRUE FALSE
> * **建议**：若请求进行激发态计算，则应包含此关键字

EFP_FRAGMENTS_ONLY

### `EFP_FRAGMENTS_ONLY`

> **指定是否存在 QM 部分**
>
> * **类型**：`LOGICAL`
> * **默认值**：`FALSE`
> * **选项**：
>     * TRUE
>     * 仅存在 MM 部分：所有片段均由 EFP 处理
>     * FALSE
>     * 存在 QM 部分：进行 QM/MM EFP 计算
> * **建议**：无

EFP_INPUT

### `EFP_INPUT`

> **指定 EFP 输入的格式**
>
> * **类型**：`LOGICAL`
> * **默认值**：`FALSE`
> * **选项**：
>     * TRUE
>     * 在
>     * $molecule
>     * 节中使用不含虚原子（dummy atom）的格式
>     * FALSE
>     * 在
>     * $molecule
>     * 节中使用含虚原子的格式
> * **建议**：无

FEFP_EFP

### `FEFP_EFP`

> **指定请求进行 fEFP_EFP 计算，以计算配体（$efp_fragments 节中的最后一个片段）与蛋白质（由 fEFP 表示）之间的总相互作用能**
>
> * **类型**：`STRING`
> * **默认值**：`OFF`
> * **选项**：
>     * OFF
>     * 禁用 fEFP
>     * LA
>     * 以连接原子（Link Atom，HLA 或 CLA）方案启用 fEFP（仅包含
>     * 静电作用和极化作用）
>     * MFCC
>     * 以 MFCC 方案启用 fEFP（仅包含
>     * 静电作用）
> * **建议**：若请求 EFP/fEFP（相互作用能计算），则应调用此关键字。该关键字必须与 EFP_FRAGMENT_ONLY = TRUE 配合使用。要开启/关闭静电作用或极化作用，使用常规的 EFP 控制关键字即可。

FEFP_QM

### `FEFP_QM`

> **指定请求进行 fEFP_QM 计算，以执行 QM/fEFP 组合计算。其中 fEFP 部分为分块化（fractionated）的大分子。**
>
> * **类型**：`STRING`
> * **默认值**：`OFF`
> * **选项**：
>     * OFF
>     * 禁用 fEFP_QM，并执行 QM/EFP 计算
>     * LA
>     * 以连接原子（Link Atom）方案启用 fEFP_QM
> * **建议**：若请求 QM/fEFP，则应调用此关键字。该关键字必须与 efp_fragment_only false 配合使用。目前仅支持静电作用。

EFP_ELEC_DAMP

### `EFP_ELEC_DAMP`

> **控制 EFP 中片段-片段的静电屏蔽（screening）**
>
> * **类型**：`INTEGER`
> * **默认值**：`2`
> * **选项**：
>     * 0
>     * 关闭静电屏蔽
>     * 1
>     * 使用基于重叠（overlap）的阻尼校正
>     * 2
>     * 若 EFP 势中提供了 SCREEN2 屏蔽参数，则使用指数阻尼校正
> * **建议**：推荐使用基于重叠的阻尼

EFP_DISP_DAMP

### `EFP_DISP_DAMP`

> **控制 EFP 中片段-片段的色散屏蔽（screening）**
>
> * **类型**：`INTEGER`
> * **默认值**：`2`
> * **选项**：
>     * 0
>     * 关闭色散屏蔽
>     * 1
>     * 使用 Tang-Toennies 屏蔽，参数固定为
>     * $b=1.5$
>     * 2
>     * 使用基于重叠的阻尼
> * **建议**：无

EFP_POL_DAMP

### `EFP_POL_DAMP`

EFP_POL_DAMP_TT_VALUE

### `EFP_POL_DAMP_TT_VALUE`

> **控制 EFP 中片段–片段极化 Tang–Toennies 屏蔽因子的取值**
>
> * **类型**：`INTEGER`

> * **选项**：
>     * n
>     * 对应于 n/1000。
> * **建议**：对该屏蔽因子使用默认值 0.6，该值在原始 EFP 实现中为硬编码值。

EFP_QM_ELEC_DAMP

### `EFP_QM_ELEC_DAMP`

EFP_ORDER

### `EFP_ORDER`

> **控制 QM-EFP 成对（pairwise）片段能量分解分析**
>
> * **类型**：`INTEGER`
> * **默认值**：`0`

EFP_PAIRWISE_STATES

### `EFP_PAIRWISE_STATES`

> **激活 $efp_pairwise_states 组，用于指定成对分析所用激发态的子集**
>
> * **类型**：`INTEGER`
> * **默认值**：`0`
> * **选项**：
>     * 0
>     * 1
>     * 激活
>     * $efp_pairwise_states
>     * 组
> * **建议**：无

EFP_QMMM

### `EFP_QMMM`

> **在 LIBEFP 框架下为各类 QM/MM 任务提供功能支持**
>
> * **类型**：`INTEGER`
> * **默认值**：`0`
> * **选项**：
>     * 0
>     * 该关键字不激活，即正常的 QM/EFP 任务
>     * 1
>     * 力学嵌入（mechanical embedding）QM/MM，所有 EFP 项均关闭；片段之间的相互作用使用 MM 电荷和 LJ 参数计算
>     * 2
>     * 静电嵌入（electrostatic embedding）QM/MM，在 QM 与 MM 之间以及各 EFP 之间加入 LJ 项
>     * 3
>     * 静电嵌入 QM/MM，在 QM 与 MM 之间加入 LJ 项；EFP-EFP 项按输入设置处理
>     * 4
>     * QM/EFP，在 QM 区域与 EFP 区域之间加入 LJ 项；EFP-EFP 项按输入设置处理
> * **建议**：无

EFP_QM_FRAGMENT

### `EFP_QM_FRAGMENT`

> **指定 QM 片段的位置**
>
> * **类型**：`INTEGER`
> * **默认值**：`0`
> * **选项**：
>     * 0
>     * QM 片段是体系中的第一个片段
>     * n
>     * QM 片段是第 (n+1) 个片段
> * **建议**：该关键字与 EFP_QMMM 关键字配合使用。

EFP_POL_FIELD_UPDATE

### `EFP_POL_FIELD_UPDATE`

> **控制 EFP 极化场的更新频率**
>
> * **类型**：`INTEGER`
> * **默认值**：`1`
> * **选项**：
>     * 1
>     * 在每次 SCF 迭代时更新 EFP 极化场
>     * n
>     * 每 n 步更新一次 EFP 极化场
> * **建议**：无
