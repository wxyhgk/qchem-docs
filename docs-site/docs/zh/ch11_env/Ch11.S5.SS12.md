## 11.5.12 输入关键字

（2026 年 7 月 4 日）

EFP_COORD_XYZ

### `EFP_COORD_XYZ`

> **使用三个原子的坐标代替欧拉角（Euler angles）来指定片段的位置和取向**
>
> * **类型**： `LOGICAL`
> * **默认值**： `FALSE`
> * **选项**：
>     * TRUE FALSE
> * **建议**： 无

EFP_DIRECT_POLARIZATION_DRIVER

### `EFP_DIRECT_POLARIZATION_DRIVER`

> **使用直接求解器计算 EFP 极化**
>
> * **类型**： `LOGICAL`
> * **默认值**： `FALSE`
> * **选项**：
>     * TRUE FALSE
> * **建议**： 直接极化求解器可为诱导偶极子提供稳定的收敛性；而当体系中存在距离很近、极性很强或带电荷的片段时，迭代求解可能出现问题。对于包含超过 10000 个可极化点的体系，直接极化求解相对于迭代极化求解的计算成本会更高。

EFP_ENABLE_LINKS

### `EFP_ENABLE_LINKS`

> **在 EFP 区域中启用片段链接（fragment links）**
>
> * **类型**： `LOGICAL`
> * **默认值**： `FALSE`
> * **选项**：
>     * TRUE FALSE
> * **建议**： 无

EFP

### `EFP`

> **指定请求进行 EFP 计算**
>
> * **类型**： `LOGICAL`
> * **默认值**： `FALSE`
> * **选项**：
>     * TRUE FALSE
> * **建议**： 若请求进行激发态计算，则必须包含该关键字

EFP_FRAGMENTS_ONLY

### `EFP_FRAGMENTS_ONLY`

> **指定是否存在 QM 部分**
>
> * **类型**： `LOGICAL`
> * **默认值**： `FALSE`
> * **选项**：
>     * TRUE
>     * 仅存在 MM 部分：所有片段均由 EFP 处理
>     * FALSE
>     * 存在 QM 部分：进行 QM/MM EFP 计算
> * **建议**： 无

EFP_INPUT

### `EFP_INPUT`

> **指定 EFP 输入的格式**
>
> * **类型**： `LOGICAL`
> * **默认值**： `FALSE`
> * **选项**：
>     * TRUE
>     * 在
>     * $molecule
>     * 部分中不使用虚原子（dummy atom）的格式
>     * FALSE
>     * 在
>     * $molecule
>     * 部分中使用虚原子的格式
> * **建议**： 无

FEFP_EFP

### `FEFP_EFP`

> **指定请求进行 fEFP_EFP 计算，以计算配体（$efp_fragments 部分中的最后一个片段）与蛋白质（由 fEFP 表示）之间的总相互作用能**
>
> * **类型**： `STRING`
> * **默认值**： `OFF`
> * **选项**：
>     * OFF
>     * 禁用 fEFP
>     * LA
>     * 以连接原子（Link Atom，HLA 或 CLA）方案启用 fEFP（仅限
>     * 静电和极化作用）
>     * MFCC
>     * 以 MFCC 启用 fEFP（仅限
>     * 静电作用）
> * **建议**： 若请求进行 EFP/fEFP 计算（相互作用能计算），则应调用该关键字。此关键字必须与 EFP_FRAGMENT_ONLY = TRUE 一起使用。若要开启或关闭静电或极化相互作用，可使用常规的 EFP 控制选项。

FEFP_QM

### `FEFP_QM`

> **指定请求进行 fEFP_QM 计算，以执行 QM/fEFP 计算。fEFP 部分为经分片段处理的大分子。**
>
> * **类型**： `STRING`
> * **默认值**： `OFF`
> * **选项**：
>     * OFF
>     * 禁用 fEFP_QM，并执行 QM/EFP 计算
>     * LA
>     * 以连接原子（Link Atom）方案启用 fEFP_QM
> * **建议**： 若请求进行 QM/fEFP 计算，则应调用该关键字。此关键字必须与 efp_fragment_only false 一起使用。仅支持静电作用。

EFP_ELEC_DAMP

### `EFP_ELEC_DAMP`

> **控制 EFP 中片段-片段间的静电屏蔽**
>
> * **类型**: `INTEGER`
> * **默认值**: `2`
> * **选项**:
>     * 0
>     * 关闭静电屏蔽
>     * 1
>     * 使用基于重叠的阻尼校正
>     * 2
>     * 若 EFP 势中提供了 SCREEN2 屏蔽参数，则使用指数型阻尼校正
> * **推荐设置**: 推荐使用基于重叠的阻尼

EFP_DISP_DAMP

>     * 使用基于重叠的阻尼
> * **推荐设置**: 无

EFP_POL_DAMP_TT_VALUE

>

> * **推荐设置**: 该屏蔽因子推荐使用默认值 0.6，此值在最初的 EFP 实现中为硬编码。

EFP_PAIRWISE_STATES

> * **推荐设置**: 无

EFP_QMMM

### `EFP_QMMM`

> **在 LIBEFP 框架下提供多种 QM/MM（量子力学/分子力学）计算功能**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **选项**:
>     * 0
>     * 该关键字不生效；即执行正常的 QM/EFP 计算
>     * 1
>     * 力学嵌入（mechanical embedding）QM/MM，所有 EFP 项均关闭；片段间相互作用采用 MM 电荷和 LJ（Lennard-Jones）参数计算
>     * 2
>     * 静电嵌入（electrostatic embedding）QM/MM，在 QM 与 MM 之间以及各 EFP 之间均包含 LJ 项
>     * 3
>     * 静电嵌入 QM/MM，仅在 QM 与 MM 之间包含 LJ 项；EFP-EFP 各项按输入文件中的设定计算
>     * 4
>     * QM/EFP 计算，在 QM 与 EFP 区域之间额外加入 LJ 项；EFP-EFP 各项按输入文件中的设定计算
> * **推荐设置**: 无

EFP_QM_FRAGMENT

### `EFP_QM_FRAGMENT`

> **指定 QM 片段的位置**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **选项**:
>     * 0
>     * QM 片段为系统中的第一个片段
>     * n
>     * QM 片段为第 (n+1) 个片段
> * **推荐设置**: 该关键字应与 EFP_QMMM 关键字配合使用。

EFP_POL_FIELD_UPDATE

### `EFP_POL_FIELD_UPDATE`

> **控制 EFP 极化场的更新频率**
>
> * **类型**：`INTEGER`
> * **默认值**：`1`
> * **选项**：
>     * 1
>     * 每次自洽场（SCF）迭代时更新 EFP 极化场
>     * n
>     * 每隔 n 次 SCF 迭代更新一次 EFP 极化场
> * **建议**：当 EFP 区域较大时，取 n = 2 或 3 可以加快 QM/EFP 计算。可通过将 EFP_PRINT 设为 1 来查看耗时信息。

EFP_PRINT

### `EFP_PRINT`

> **控制与 EFP 相关的打印输出量**
>
> * **类型**：`INTEGER`
> * **默认值**：`0`
> * **选项**：
>     * 1
>     * 打印耗时信息以及 EFP 极化收敛的基本信息
>     * 2
>     * 提供体系结构的详细信息，以及更完整的 EFP 极化收敛诊断信息。对调试崩溃的作业很有用。
>     * 3
>     * 额外打印片段参数，用于调试崩溃的作业
> * **建议**：调试极化不收敛的作业时，使用（= 2）。
