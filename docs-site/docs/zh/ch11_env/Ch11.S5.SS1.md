## 11.5.1 引言

（2026 年 7 月 4 日）

有效片段势（Effective Fragment Potential, EFP）方法是一种计算开销低廉的、用于模拟非共价体系中分子间相互作用的方法。EFP 方法可被视为一种无经验参数的可极化 QM/MM 方案。EFP 最初由 Mark Gordon 教授的研究组[[309]](../bib_references/bib.md#bib314) 开发，并在 **gamess** 程序中实现。[[1213]](../bib_references/bib.md#bib1269)

关于 EFP 理论及其应用的综述可参见文献 [[438]](../bib_references/bib.md#bib448) 和 [[474]](../bib_references/bib.md#bib488)。

基于 Ilya Kaliman 博士开发的 **libefp** 库（参见 `https://libefp2.github.io`）的 EFP 方法新实现已被加入 **Q-Chem**。[[662]](../bib_references/bib.md#bib686) 新的 EFP 模块称为 EFPMAN2。EFPMAN2 可以在共享内存多核计算机以及计算机集群上并行运行计算。EFPMAN2 与 CCMAN 和 CCMAN2 模块相连，从而支持结合 EFP 的耦合簇和 EOM-CC 计算；它还与 ADCMAN 模块相连，支持 ADC/EFP 计算。结合 EFP 的 CIS 和 TDDFT 计算同样可用。
