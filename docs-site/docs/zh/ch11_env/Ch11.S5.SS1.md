## 11.5.1 引言

(July 4, 2026)

有效片段势（Effective Fragment Potential, EFP）方法是一种计算开销较低的方法，用于模拟非共价体系中的分子间相互作用。
EFP 方法可以被视为一种不含经验参数的可极化 QM/MM 方案。EFP 最初由 Mark Gordon 教授的团队开发[[309]](../bib_references/bib.md#bib314)
，并在 **gamess** 中得以实现。[[1213]](../bib_references/bib.md#bib1269)

有关 EFP 理论与应用的综述可参见文献 [[438]](../bib_references/bib.md#bib448)
 和 [[474]](../bib_references/bib.md#bib474)。
