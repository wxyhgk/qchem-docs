## 11.3.4 QM/MM 示例

（2026 年 7 月 4 日）

本作业的功能特点：

- 使用 ONIOM 机械嵌入（mechanical embedding）进行几何优化。
- MM 区域（水分子 1）采用 OPLSAA 力场描述。
- QM 区域（水分子 2）采用 PBE0/6-31G* 方法描述。
- *$molecule* 输入段包含用户定义的 MM 键。
若不再有其它连接，则用零作为占位符。

???+ example "示例 11.24：水二聚体的 ONIOM 优化。"
    ```qchem
    $molecule
       0 1
       O   -0.790909    1.149780    0.907453  186  2  3  0  0
       H   -1.628044    1.245320    1.376372  187  1  0  0  0
       H   -0.669346    1.913705    0.331002  187  1  0  0  0
       O    1.178001   -0.686227    0.841306  186  5  6  0  0
       H    0.870001   -1.337091    1.468215  187  4  0  0  0
       H    0.472696   -0.008397    0.851892  187  4  0  0  0
    $end
    
    $rem
       JOBTYPE           opt
       METHOD            pbe0
       BASIS             6-31G*
       QM_MM_INTERFACE   oniom
       FORCE_FIELD       oplsaa
       USER_CONNECT      true
       MOLDEN_FORMAT     true
    $end
    
    $qm_atoms
       4 5 6
    $end
    ```

本作业的功能特点：

- 采用 YinYang 连接原子（即脱氧核糖 C1${}^{\prime}$ 位的糖苷碳）的 Janus 电子嵌入。
- MM 区域（脱氧核糖）采用 AMBER99 力场描述。
- QM 区域（腺嘌呤）采用 HF/6-31G* 方法描述。
- 利用 CIS 计算前 5 个电子激发态。
假定 QM 原子与 MM 原子之间的 MM 能量相互作用（*例如*，范德华相互作用，以及仅涉及单个 QM 原子的键角项）在激发态与基态中相同。
- *$molecule* 输入段包含用户定义的 MM 键。
- 对所有 MM 原子使用高斯模糊电荷（Gaussian-blurred charges），模糊宽度设为 1.5 Å。

本作业的功能特点：

- 纯 MM 计算。为防止程序崩溃，必须定义 BASIS 和 EXCHANGE，
但实际并不执行任何电子结构计算。
- 所有原子类型及 MM 相互作用均在 *$force_field_params* 中定义，采用
CHARMM27 力场。原子电荷、平衡键长和平衡键角
取自 HF/6-31G* 计算结果，但力常数和范德华参数
为本示例虚构的数值。
- 在微正则系综（NVE）内进行 10 步分子动力学演化，
这是目前唯一可用的系综。初始速度按 400 K 的玻尔兹曼分布抽样。

???+ example "示例 11.26：使用用户定义 MM 参数的分子动力学计算。"
    ```qchem
    $molecule
      -2 1
       C    0.803090    0.000000    0.000000  -1  2  3  6  0
       C   -0.803090    0.000000    0.000000  -1  1  4  5  0
       H    1.386121    0.930755    0.000000  -2  1  0  0  0
       H   -1.386121   -0.930755    0.000000  -2  2  0  0  0
       H   -1.386121    0.930755    0.000000  -2  2  0  0  0
       H    1.386121   -0.930755    0.000000  -2  1  0  0  0
    $end
    
    $rem
       METHOD            hf
       BASIS             sto-3g
       QM_MM_INTERFACE   MM
       FORCE_FIELD       charmm27
       USER_CONNECT      true
       JOBTYPE           aimd
       TIME_STEP         42
       AIMD_STEPS        10
       AIMD_INIT_VELOC   thermal
       AIMD_TEMP         400
    $end
    
    $force_field_params
       NumAtomTypes 2
       AtomType -1  -0.687157  2.0000  0.1100
       AtomType -2  -0.156422  1.3200  0.0220
       Bond     -1  -1  250.00  1.606180
       Bond     -1  -2  300.00  1.098286
       Angle    -2  -1  -2  50.00  115.870
       Angle    -2  -1  -1  80.00  122.065
       Torsion  -2  -1  -1  -2  2.500  180.0  2
    $end
    ```

更多 QM/MM 计算示例可在 `$QC/samples`
目录中找到，其中包括一个 QM/MM/PCM 示例 `pcm_qmmm_crambin.in`。
该计算包含一个用力场描述的蛋白质分子（牙渍素，crambin），
但其中一个酪氨酸侧链用电子结构理论描述。整个 QM/MM 体系
被置于隐式溶剂模型之中，其原理见第 [11.2.3](topic_pcm-em.md) 节所述。
