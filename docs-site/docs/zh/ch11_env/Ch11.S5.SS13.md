???+ example "示例 11.35：使用 LIBEFP 接口的静电嵌入（electrostatic embedding）QM/MM 计算。"
    ```qchem
    $comment
    EFP_QMMM keyword provides functionality for various QM/MM jobs within LIBEFP umbrella
    EFP fragment parameters should contain MM_CHARGE and MM_LJ sections
    The QM region should be present as a fragment, at the position given
    by the EFP_QM_FRAGMENT keyword
    EFP_QMMM = 0 - normal QM/EFP job
             = 1 - mechanical embedding QM/MM, all EFP terms are turned off;
                   interactions between fragments are computed
                   using MM charges and LJ parameters
             = 2 - electrostatic embedding QM/MM with LJ terms between QM and MM
                   and between EFPs
             = 3 - electrostatic embedding QM/MM with LJ terms between QM and MM;
                   EFP-EFP terms as given in input
             = 4 - QM/EFP with LJ terms between QM and EFP region added;
                   EFP-EFP terms as given in input
    $end
    ```
