## 7.10.5 自旋相反缩放 ADC(2) 模型

(July 4, 2026)

自旋相反缩放（spin-opposite scaling, SOS）方法源于 MP2，其核心思想是：若对自旋相反的分量施以适当的缩放，则自旋相同的贡献可以完全忽略。
类似地，也可以通过忽略 ADC 矩阵中自旋相同的贡献来简化二阶 ADC 方程，
而自旋相反的贡献则用适当的半经验参数进行缩放。[[553]](../bib_references/bib.md#bib568)

从 SOS-MP2 基态出发，在 ADC 方程中引入相同的缩放参数 $c_{T}=1.3$ 来缩放 $t_{2}$
振幅。
然而，仅这样做并不能带来任何计算量的节省，也无法显著改善 ADC(2)
的结果。
此外，还必须用第二个参数 $c_{c}$ 对 $ph$/$2p2h$ 以及 $2p2h$/$ph$
耦合块中的自旋相反分量进行缩放，才能得到实用的 SOS-ADC(2)-s 模型。
利用该模型计算单重态激发态时，参数 $c_{c}$
的最佳值被发现为 1.17。[[1479]](../bib_references/bib.md#bib1540)

若要将 SOS 近似推广到 ADC(2)-x 方法，还需为 $2p2h$/$2p2h$ 块中
非对角元素的自旋相反分量引入另一个缩放参数 $c_{x}$。
此时，缩放参数的最佳值被确定为 $c_{c}=1.0$ 和 $c_{x}=0.9$，而 $c_{T}$ 保持不变。[[717]](../bib_references/bib.md#bib740)
