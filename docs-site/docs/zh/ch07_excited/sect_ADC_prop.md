## 7.10.10 性质与可视化

（2026 年 7 月 4 日）

使用 **ADCman** 模块计算激发态、电离态和电子附着态时，默认会输出通常的激发能、电离势和电子附着能以及相应的激发振幅，此外还包括跃迁偶极矩、振子强度（对于 IP- 和 EA-ADC 计算则为极点强度，pole strengths），以及振幅的双激发部分的范数（若适用）。此外，还可以分别通过设置 *$rem* 变量 ADC_PROP_ES 和 ADC_PROP_ES2ES 来请求计算激发态、电离态和电子附着态的性质（如偶极矩）以及这些态之间的跃迁性质。

激发态的共振双光子吸收截面也可以进行计算，使用态求和（sum-over-states）表达式或矩阵求逆技术均可。如果设置了 ADC_PROP_ES2ES，则通过态求和表达式的计算会自动激活。然而，结果的精度在很大程度上取决于求和中包含的态数目，*即* 计算得到的态数目。对于双光子吸收截面，至少需要（每个不可约表示）20-30 个激发态才能给出有用的结果。或者，也可以通过将 ADC_PROP_TPA 设置为 TRUE 来计算共振双光子吸收截面。在这种情况下，避免了计算大量激发态，并且与激发态数目无关。取而代之的是，对于计算双光子吸收截面的每个激发态，都必须求解一个附加的线性矩阵方程。因此，获得的共振双光子吸收截面通常更为可靠。打印出的物理量是微观截面（也称为转动平均 2PA 强度）。具体而言，打印出的值为 $30\times\delta^{m}_{TP}$，其中 $\delta^{m}_{TP}$ 定义在参考文献 [[1494]](../bib_references/bib.md#bib1555) 的公式 (13) 中。

此外，**ADCman** 模块允许对激发态进行详细分析，并导出各种与激发态相关的轨道和密度。这可以通过设置关键字 STATE_ANALYSIS 来激活。有关可用分析和导出选项的详细信息，参见第 [10.2.12](../ch10_properties/ex_StateAnal_MolDen.md) 节。
