## 7.8.4 SOS-CIS(D) 模型

(July 4, 2026)

与 MP2 情形类似，可以通过对 CIS(D) 表达式中的自旋相反（opposite-spin）分量进行半经验缩放来提高 CIS(D) 计算的精度：

<a id="Ch7.E91"></a>
$$
E^{\mathrm{SOS-CIS(D)}}=c_{U}\left\langle{\Psi^{\mathrm{CIS}}}\right|V\left|{U_{2}^{\mathrm{OS}}\Psi^{\mathrm{HF}}}\right\rangle+c_{T}\left\langle{\Psi^{\mathrm{CIS}}}\right|V\left|{T_{2}^{\mathrm{OS}}U_{1}\Psi^{\mathrm{{HF}}}}\right\rangle
$$
