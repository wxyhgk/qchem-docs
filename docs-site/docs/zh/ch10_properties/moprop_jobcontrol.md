## 10.10.3 MOProp 模块的作业控制

（2026 年 7 月 4 日）

通过 *$rem* 变量 MOPROP 指定作业编号即可调用 MOProp 模块。除电学性质外，该模块还可以计算 NMR 化学位移（MOPROP = NMR）；此功能在第 [10.11](sec_magnetic.md) 节中描述。

### `MOPROP`

> **指定 MOProp 模块的作业编号。**
>
> * **类型**: `STRING`
> * **默认值**: `0`
> * **可选值**:
>     * `NMR`
>     * NMR 化学屏蔽张量。
>     * `STATIC_POLAR`: 静态极化率。
>     * `ISSC`: 间接核自旋-自旋耦合张量。
>     * `DYN_POLAR`: 动态极化率。
>     * `HYPERPOL`: 利用 Wigner 的 $2n+1$ 规则计算一阶超极化率。
> * **建议**: 无

### `MOPROP_PERTNUM`

> **设置将一起处理的微扰密度数目。**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **可选值**:
>     * `0`: 一次性全部处理。
>     * $n$: 分批处理微扰密度。
> * **建议**: 使用默认值。对于大体系，可能需要限制该数目以避免内存耗尽。

### `MOPROP_CONV_1ST`

> **设置 CPSCF 及一阶 TDSCF 的收敛判据。**
>
> * **类型**: `INTEGER`
> * **默认值**: `6`
> * **可选值**:
>     * $n<10$: 收敛阈值设为 $10^{-n}$。
> * **建议**: 无

### `MOPROP_CONV_2ND`

> **设置二阶 TDSCF 的收敛判据。**
>
> * **类型**: `INTEGER`
> * **默认值**: `6`
> * **可选值**:
>     * $n<10$: 收敛阈值设为 $10^{-n}$。
> * **建议**: 无

### `MOPROP_MAXITER_1ST`

> **CPSCF 及一阶 TDSCF 的最大迭代次数。**
>
> * **类型**: `INTEGER`
> * **默认值**: `50`
> * **可选值**:
>     * $n$: 将最大迭代次数设为
>     * $n$: 。
> * **建议**: 使用默认值。

### `MOPROP_MAXITER_2ND`

> **二阶 TDSCF 的最大迭代次数。**
>
> * **类型**: `INTEGER`
> * **默认值**: `50`
> * **可选值**:
>     * $n$: 将最大迭代次数设为
>     * $n$: 。
> * **建议**: 使用默认值。

### `MOPROP_ISSC_PRINT_REDUCED`

> **指定在计算间接核自旋-自旋耦合时，是否在依赖于同位素的 $\mathbf{J}$ 张量之外，额外打印与同位素无关的约化耦合张量 $\mathbf{K}$。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **可选值**:
>     * `FALSE`: 不打印 $\mathbf{K}$。
>     * `TRUE`: 打印 $\mathbf{K}$。
> * **建议**: 无

### `MOPROP_ISSC_SKIP_FC`

> **指定是否跳过计算间接核自旋-自旋耦合张量的费米接触（Fermi contact）贡献。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **可选值**:
>     * `FALSE`: 计算费米接触贡献。
>     * `TRUE`: 跳过费米接触贡献。
> * **建议**: 无

### `MOPROP_ISSC_SKIP_SD`

> **指定是否跳过计算间接核自旋-自旋耦合张量的自旋-偶极（spin-dipole）贡献。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **可选值**:
>     * `FALSE`: 计算自旋-偶极贡献。
>     * `TRUE`: 跳过自旋-偶极贡献。
> * **建议**: 无

### `MOPROP_ISSC_SKIP_PSO`

> **指定是否跳过计算间接核自旋-自旋耦合张量的顺磁自旋-轨道（paramagnetic spin-orbit）贡献。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **可选值**:
>     * `FALSE`: 计算顺磁自旋-轨道贡献。
>     * `TRUE`: 跳过顺磁自旋-轨道贡献。
> * **建议**: 无

### `MOPROP_ISSC_SKIP_DSO`

> **指定是否跳过计算间接核自旋-自旋耦合张量的抗磁自旋-轨道（diamagnetic spin-orbit）贡献。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **可选值**:
>     * `FALSE`: 计算抗磁自旋-轨道贡献。
>     * `TRUE`: 跳过抗磁自旋-轨道贡献。
> * **建议**: 无

### `MOPROP_DIIS`

> **控制在求解 CPSCF 方程时是否使用 Pulay 的 DIIS。**
>
> * **类型**: `INTEGER`
> * **默认值**: `5`
> * **可选值**:
>     * `0`: 关闭 DIIS。
>     * `5`: 开启 DIIS。
> * **建议**: 无

### `MOPROP_DIIS_DIM_SS`

> **指定 DIIS 子空间的维数。**
>
> * **类型**: `INTEGER`
> * **默认值**: `20`
> * **可选值**:
>     * `0`: 不使用 DIIS。
>     * $n$: 使用维数为
>     * $n$: 的子空间。
> * **建议**: 无

### `SAVE_LAST_GPX`

> **在计算动态极化率时保存最后一个 $\mathbf{G}[\mathbf{P}^{x}]$，以便在第二次运行中通过 MOPROP = 104 调用 MOProp 代码（该选项与 MOPROP = HYPERPOL 基本相同）。**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **可选值**:
>     * `0`: False
>     * `1`: True
> * **建议**: 无

### `MOPROP_RESTART`

> **指定重启 MOProp 计算的选项。**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **可选值**:
>     * `0`: 非重启计算。
>     * `1`: 使用相同的临时目录（scratch directory）从先前的计算重启。
> * **建议**: 还需要同时设置 "SCF_GUESS READ" 和 "SKIP_SCFMAN TRUE"，以确保使用同一组分子轨道（MO）。
