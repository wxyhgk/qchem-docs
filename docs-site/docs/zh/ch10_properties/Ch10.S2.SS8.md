## 10.2.8 本征原子轨道（Intrinsic Atomic Orbitals）

（2026 年 7 月 4 日）

由于常用基组（Basis Set）的形式，SCF 波函数 $|\Phi\rangle$ 通常难以从原子轨道（Atomic Orbital, AO）基函数的角度进行直观解释。
特别是对于大基组，无法将某个基函数对波函数的贡献明确无误地归属于其所中心化的原子。
另一方面，将分子轨道在极小基组（由自由原子 AO 构成）上展开，则可以对波函数给出简明的解释。
然而，自由原子轨道无法给出定性正确的极小基组展开，
因为这些 AO 并未考虑分子环境所引起的极化效应。
Knizia 提出的方法克服了这一缺陷，通过确定一组*极化的* AOs $\{|\rho\rangle\}$（称为本征原子轨道（Intrinsic Atomic Orbitals, IAOs）[[697]](../bib_references/bib.md#bib729)），
使其能够精确表达
波函数 $|\Phi\rangle$ 的占据空间 $\mathcal{O}=\sum_{i}|i\rangle\langle i|$。
因此，借助 IAOs 可以获得原子性质，例如部分电荷（partial charges）。
闭壳层体系由 IAO 导出的原子电荷为

<a id="Ch10.E22"></a>
$$
q_{A}=Z_{A}-\sum_{\rho\in A}\langle\rho|\gamma|\rho\rangle, \tag{10.22}
$$

其中 $Z_{A}$ 是原子 $A$ 的核电荷，$\gamma$ 表示闭壳层 SCF 密度矩阵 $\gamma=2\sum_{i}|i\rangle\langle i|$。

将所得 IAOs 与轨道定域化方案结合使用，可以构造成键轨道，称为本征键轨道（Intrinsic Bond Orbitals, IBOs）。
所采用的定域化方案类似于 Pipek-Mezey 方法[[1093]](../bib_references/bib.md#bib1138)，
通过最大化泛函

<a id="eq:ibo_functional"></a>
$$
L=\sum_{A}^{\text{atoms}}\sum_{i^{\prime}}^{\text{occ}}[n_{A}(i^{\prime})]^{4}, \tag{10.23}
$$

相对于单位正交轨道旋转，有效地最小化了某个轨道所涉及的原子数目。上式中，
$n_{A}(i^{\prime})$ 是旋转后的轨道 $|i^{\prime}\rangle$ 中位于原子 A 的 IAOs 上的电子数：

<a id="Ch10.E24"></a>
$$
n_{A}(i^{\prime})=2\sum_{\rho\in A}\langle i^{\prime}|\rho\rangle\langle\rho|i^{\prime}\rangle. \tag{10.24}
$$

本征键轨道能够精确表示占据的分子轨道，因此可用于解释分子的电子结构。

本征键轨道的计算由以下 *$rem* 变量控制：

DO_IBO

### `DO_IBO`

> **启用 IBO 计算流程**
>
> * **类型**: `BOOL`
> * **默认值**: `FALSE`
> * **选项**:
>     * FALSE
>     * 不计算 IBO
>     * TRUE
>     * 执行 IBO 计算流程
> * **建议**: 无

IBO 计算流程的其他控制参数可以在 *$loco* 输入段中声明，列示如下。

### `MIN_BASIS`

> **指定用于构造 IAO 的自由原子基组。输入段（INPUT SECTION）：$loco**
>
> * **类型**: `STRING`
> * **默认值**: `MINAO`
> * **选项**:
>     * MINAO
>     * 使用截断的 cc-pVTZ 基组（与原始文献相同）
>     * STO-3G
>     * 使用 STO-3G 基组
>     * STO-6G
>     * 使用 STO-6G 基组
>     * autoSAD
>     * 通过 autoSAD 流程构造极小基组。
> * **建议**: 使用 autoSAD 流程。

### `EXP_FOUR`

> **是否在定域化泛函（公式 10.23）中使用指数 $p=4$。输入段（INPUT SECTION）：$loco**
>
> * **类型**: `BOOL`
> * **默认值**: `TRUE`
> * **选项**:
>     * TRUE
>     * 使用指数
>     * $p=4$
>     * （与原始文献相同）
>     * FALSE
>     * 使用指数
>     * $p=2$
> * **建议**: 优先使用指数 $p=4$，因为它能在芳香体系中实现离散定域化（$p=2$ 则不能）。

### `IBO_POP_THRESH`

> **打印 IBO 占据数的阈值。输入段（INPUT SECTION）：$loco**
>
> * **类型**: `FLOAT`
> * **默认值**: `0.1`
> * **选项**:
>     * 0.1
>     * 打印 IBO 占据数
>     * $>10\%$
> * **建议**: 使用默认值。

### `IBO_MEM`

> **IBO 计算流程的内存（单位 MB）输入段（INPUT SECTION）：$loco**
>
> * **类型**: `INTEGER`
> * **默认值**: `500`
> * **建议**: 对大多数用途而言 500MB 已经足够。仅在需要时增大。

### `EXPORT_MOLDEN`

> **是否以 Molden 格式写出 IBO。输入段（INPUT SECTION）：$loco**
>
> * **类型**: `BOOL`
> * **默认值**: `FALSE`
> * **选项**:
>     * TRUE
>     * 以 Molden 格式导出 IBO（
>     * ibo.molden
>     * ）。
>     * FALSE
>     * 不创建 Molden 文件。
> * **建议**: 无

???+ example "示例 10.4: 通过 IAO/IBO 流程计算原子部分电荷与键布居数的输入示例。"
    ```qchem
    $molecule
    0 1
    O        0.0000000000     0.0000000000     0.1172309766
    H       -0.7626482594     0.0000000000    -0.4685977726
    H        0.7626482594     0.0000000000    -0.4685977726
    $end
    
    $rem
    method          = wB97M-V
    basis           = def2-TZVP
    mem_total       = 4000
    mem_static      = 500
    scf_convergence = 9
    thresh          = 14
    gui             = 2
    do_ibo          = true
    $end
    
    
    $loco
    min_basis     = autosad
    export_molden = true
    $end
    ```
