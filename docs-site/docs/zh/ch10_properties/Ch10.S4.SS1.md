## 10.4.1 核处的自旋密度与电荷密度

（2026 年 7 月 4 日）

高斯型基组违背了核尖点条件（nuclear cusp conditions）。[[670]](../bib_references/bib.md#bib695)

这可能导致核附近波函数出现较大误差，尤其对于自旋密度的计算。[[243]](../bib_references/bib.md#bib243)
 该问题可以通过使用一种平均化算符（averaging operator）来缓解，
该算符基于波函数在库仑奇点附近必须满足的约束条件来计算波函数密度。[[1150]](../bib_references/bib.md#bib1202)
 该算符的推导
基于超维里定理（hyper virial theorem）[[582]](../bib_references/bib.md#bib605)
，并在
文献 [[1150]](../bib_references/bib.md#bib1202)
 中给出。将其应用于自旋极化[[1151]](../bib_references/bib.md#bib1203)
以及密度泛函理论（Density Functional Theory, DFT）[[1423]](../bib_references/bib.md#bib1485)
波函数的分子自旋密度计算，
相比传统的 δ 函数算符有显著改善。

这类算符最简单的形式之一基于高斯权重函数 $\exp[-(Z/r_{0})^{2}(\mathbf{r}-\mathbf{R})^{2}]$，
该函数对位于 $\bf R$、电荷为 $Z$ 的原子核邻近区域进行采样。参数 $r_{0}$
必须足够小，以忽略量级为 ${\cal{O}}({r_{0}^{4}})$ 的双电子贡献，
同时又必须足够大，以实现有意义的平均。已有研究表明 0.15–0.3 a.u. 的取值范围是合适的，
且最终结果对 $r_{0}$ 的精确选择相对不敏感。[[1150]](../bib_references/bib.md#bib1202)

$r_{0}$ 的值通过 RC_R0 关键字选取，单位为 0.001 a.u.。
该平均化算符已针对单行列式 Hartree-Fock 和 DFT，以及关联 SSG 波函数实现。
分子中所有原子核（包括虚原子，ghost atoms）的自旋密度和电荷密度都会被打印输出。

### `RC_R0`

> **确定用于平滑核处密度的高斯权重函数中的参数。**
>
> * **类型**：`INTEGER`
> * **默认值**：`0`
> * **可选值**：
>     * 0
>     * 对应传统的 δ 函数自旋密度与电荷密度
>     * $n$
>     * 对应
>     * $n\times 10^{-3}$
>     * a.u.
> * **建议**：对于典型的自旋价层基组（spin valence basis），我们建议取值为 250。对于在核附近灵活性更高的基组，取较小的 $r_{0}$ 值同样可以得到足够的自旋密度精度。
