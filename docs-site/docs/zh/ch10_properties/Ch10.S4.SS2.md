## 10.4.2 分子中的原子

（2026 年 7 月 4 日）

**Q-Chem** 可以输出适合用“分子中的原子”软件包（Atoms in Molecules package，AIMPAC）进行分析的文件。AIMPAC 的源代码可从以下网站免费下载

`http://www.chemistry.mcmaster.ca/aimpac/imagemap/imagemap.htm`

用户应访问该网站以获取有关安装和运行 AIMPAC 的更多信息。AIMPAC 输入文件通过在 *$rem* 中为 WRITE_WFN 指定文件名来创建。

WRITE_WFN

### `WRITE_WFN`

> **指定是否创建适合 AIMPAC 使用的 .wfn 文件。请注意，目前写入该文件的输出仅限于 $f$ 轨道。**
>
> * **类型**：`STRING`
> * **默认值**：`(NULL)`
> * **选项**：
>     * filename
>     * 指定输出文件名。
>     * 后缀
>     * .wfn
>     * 将
>     * 附加到该文件名之后。
> * **建议**：无
