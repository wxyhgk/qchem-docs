## 10.13.2 静态极化率的数值计算

（2026 年 7 月 4 日）

在解析梯度（Analytic Gradients）不可用的情况下，可以（仅针对静态极化率）通过在施加外场下进行有限差分来计算，这种方法被称为*有限场*（Finite Field, FF）方法。从 **Q-Chem** 5.1 版本开始，提供了一种精巧的“隆贝格”（Romberg）有限场微分方法，其中包含评估结果对有限差分步长稳定性的相关程序。Romberg 方法详见第 [10.13.3](sect_Romberg.md) 节。本节介绍 **Q-Chem** 较早的有限场计算方法，其基础是沿相应笛卡尔（Cartesian）方向直接施加小电场。

偶极矩（Dipole Moment）可以作为能量对 $\vec{F}$ 的一阶导数进行数值计算，方法是将 JOBTYPE 设为 DIPOLE 并将 IDERIV 设为 0。如果未显式指定 IDERIV，偶极矩将被解析计算，而对于后哈特里-福克（post-Hartree–Fock）级别的理论，这将调用梯度计算以利用弛豫波函数（Relaxed Wave Function）。

类似地，将 JOBTYPE 设为 POLARIZABILITY 即可对静态极化率张量 $\mathord{\buildrel{\lower 3.0pt\hbox{$\scriptscriptstyle\leftrightarrow$}}\over{\alpha}}$ 进行数值计算。这可以通过一阶有限差分实现，即对解析偶极矩求一阶场导数；也可以通过对能量作二阶有限差分实现。后者对于解析梯度不可用的方法十分有用（实际上是必需的），例如 CCSD(T)。但请注意，在静电场存在时，电子云在形式上是非束缚的，因此束缚解只是使用有限基组（Basis Set）的结果。（在解析导数技术中，微扰场是无穷小的，因此不存在这个问题。）这一事实，加上数值导数对有限差分步长的整体敏感性，意味着在选择所施加有限场强度时必须格外谨慎。

要控制对所施加电场进行数值微分的阶数，请按照与几何导数相同的方式使用 IDERIV，换言之，对于极化率，将 IDERIV 设为 0 表示对能量作二阶有限差分，设为 1 表示对梯度作一阶有限差分。此外，对于哈特里-福克（Hartree-Fock）或密度泛函理论（DFT）级别的数值极化率计算，请将 RESPONSE_POLAR 设为 $-1$，以禁用解析极化率代码。

RESPONSE_POLAR

### `RESPONSE_POLAR`

> **控制使用解析极化率还是数值极化率。**
>
> * **类型**：`INTEGER`
> * **默认值**：`0 or`
> * **选项**：
>     * 0
>     * 执行解析极化率计算。
>     * $-$
>     * 1
>     * 即使解析二阶导数可用时，也执行数值极化率计算。
> * **建议**：无
