## 10.10.1 引言

(July 4, 2026)

新型光学器件的探索是材料科学的一个重要研究领域。
在此领域,极化率和超极化率为分子体系提供了尤为重要的信息。分子体系在外部单色振荡电场存在时的响应,
由含时自洽场(time-dependent SCF,TDSCF)方程的求解来确定。
在偶极近似下,微扰表示为分子与外部电场 $\bm{{\cal E}}$ 的单个傅里叶分量之间的相互作用:

<a id="Ch10.E114"></a>
$$
\hat{H}_{\rm field}=\tfrac{1}{2}\hat{\bm{\mu}}\bm{\cdot}\bm{{\cal E}}(e^{-i\omega t}+e^{+i\omega t}) \tag{10.114}
$$

其中

<a id="Ch10.E115"></a>
$$
\hat{\bm{\mu}}=-e\sum_{i}^{N_{\rm elec}}\hat{\mathbf{r}}_{i}\;. \tag{10.115}
$$

这里,$\omega$ 为电场频率,$\hat{\bm{\mu}}$ 为偶极矩算符。TDSCF 方程可以通过标准的微扰论技术来求解。[[1229]](../bib_references/bib.md#bib1284)
作为求解结果,可以得到
一阶微扰密度矩阵 [$\mathbf{P}^{x}(\pm\omega)$] 和二阶微扰密度矩阵 [$\mathbf{P}^{xy}(\pm\omega,\pm\omega^{\prime})$]。由这些量可以计算以下性质:

- •

静态极化率:
$\alpha_{xy}(0;0)=\mathrm{tr}\bigl{[}\mathbf{H}^{\mu_{x}}\mathbf{P}^{y}(\omega=0)\bigr{]}$
- •

动态极化率:
$\alpha_{xy}(\pm\omega;\mp\omega)=\mathrm{tr}\bigl{[}\mathbf{H}^{\mu_{x}}\mathbf{P}^{y}(\pm\omega)\bigr{]}$
- •

静态超极化率:
$\beta_{xyz}(0;0,0)=\mathrm{tr}\bigl{[}\mathbf{H}^{\mu_{x}}\mathbf{P}^{yz}(\omega=0,\omega=0)\bigr{]}$
- •

二次谐波产生(second harmonic generation):
$\beta_{xyz}(\mp 2\omega;\pm\omega,\pm\omega)=\mathrm{tr}\bigl{[}\mathbf{H}^{\mu_{x}}\mathbf{P}^{yz}(\pm\omega,\pm\omega)\bigr{]}$
- •

电光普克尔斯效应(Electro-optical Pockels effect):
$\beta_{\mathrm{xyz}}(\mp\omega;0,\pm\omega)=\mathrm{tr}\bigl{[}\mathbf{H}^{\mu_{x}}\mathbf{P}^{yz}(\omega=0,\pm\omega)\bigr{]}$
- •

光整流(optical rectification):
$\beta_{xyz}(0;\pm\omega,\mp\omega)=\mathrm{tr}\bigl{[}\mathbf{H}^{\mu_{x}}\mathbf{P}^{yz}(\pm\omega,\mp\omega)\bigr{]}$

这里,$\mathbf{H}^{\mu_{x}}$ 是偶极矩 $x$ 分量的矩阵表示。

对于三阶性质($\beta_{xyz}$),我们不采用二阶 TDSCF 计算并显式求解 $\mathbf{P}^{yz}$ 的方式来计算,
而是基于一阶性质,利用维格纳(Wigner)的 $2n+1$ 规则来计算。[[666]](../bib_references/bib.md#bib691)

TDSCF 计算比其前置的 SCF 计算(用于获得无外场、未微扰的分子基态)更为耗时。**Q-Chem**
对 TDSCF 方程的实现是基于分子轨道(MO)的,因此其计算代价在形式上渐近扩展为 ${\cal{O}}({N^{3}})$。
不过,立方标度步骤的 prefactor 相当小,而在实践中(在很宽的分子尺寸范围内),计算耗时主要由与双电子积分的缩并 contractions 决定,该步骤在形式上为 ${\cal{O}}({N^{2}})$ 标度,但 prefactor 非常大。利用 LinK/CFMM 方法(第 [4.6](../ch04_scf/sec_O(N).md) 节),可以将这些积分缩并的代价从二次方降低到 ${\cal{O}}({N})$。[[743]](../bib_references/bib.md#bib776)
 所有导数均为解析计算。

**Q-Chem** 中的 TDSCF 模块被称为 "MOProp",因为它(在形式上)对应于分子轨道的时间演化。(若需对 MO 进行*真正*的时间演化,参见第 [7.4](../ch07_excited/sec_TDKS.md) 节。)MOProp
模块具有以下特性:

- •

支持 LinK 与 CFMM 以计算类库仑矩阵和类交换矩阵
- •

解析导数
- •

DIIS 加速
- •

CPSCF 和 TDSCF 方程的限制性(restricted)与非限制性(unrestricted)实现均可用,适用于 Hartree-Fock 和 Kohn-Sham DFT。
- •

支持 LDA、GGA、meta-GGA,[[923]](../bib_references/bib.md#bib959)

全局杂化泛函以及常见的范围分离(range-separated)泛函。
VV10 是唯一支持的非局域关联泛函。
