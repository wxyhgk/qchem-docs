## 10.9.5 作业控制

（2026 年 7 月 4 日）

以下 *$rem* 变量可用于控制非谐频率（anharmonic frequencies）的计算。

ANHAR

### `ANHAR`

> **执行各种核振动理论（TOSH、VPT2、VCI）计算，以获取振动非谐频率。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * TRUE
>     * 执行非谐频率计算。
>     * FALSE
>     * 执行谐频（harmonic frequency）计算。
> * **建议**: 由于该计算涉及势能面极小点处的三阶和四阶导数，建议将 GEOM_OPT_TOL_DISPLACEMENT、GEOM_OPT_TOL_GRADIENT 和 GEOM_OPT_TOL_ENERGY 容差设置得更严格。请注意，若体系存在偶然简并共振（accidental degenerate resonances），VPT2 计算可能失败。关于提高非谐计算精度的更多细节，请参见 VCI $rem 变量。

VCI

### `VCI`

> **指定 VCI 计算中涉及的量子数（quanta）数目。**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **选项**:
>     * 由用户定义。最大值为 10。
> * **建议**: 其可用性取决于机器的内存。VCI 计算的内存分配（双精度）为 $2(N_{\mathrm{Vib}}+N_{\mathrm{VCI}})/N_{\mathrm{Vib}}N_{\mathrm{VCI}}$ 的平方。例如，对于一台内存为 1.5 GB 的机器，原子数少于 4 个的分子可执行 VCI(10)，原子数少于 5 个的分子可执行 VCI(6)，原子数少于 6 个的分子可执行 VCI(5)。对于原子数少于 50 个的分子，可执行 VCI(2)。VCI(1) 和 VCI(3) 通常会高估真实能量，而 VCI(4) 通常给出接近收敛能量的结果。

FDIFF_DER

### `FDIFF_DER`

> **控制用于计算高阶导数的信息类型。默认设置结合使用能量、梯度和 Hessian 信息，这使得力场（force field）计算更快。**
>
> * **类型**: `INTEGER`
> * **默认值**: `3`
> * **选项**:
>     * 0
>     * 仅使用能量信息。
>     * 1
>     * 仅使用梯度信息。
>     * 2
>     * 仅使用 Hessian 信息。
>     * 3
>     * 使用能量、梯度和 Hessian 信息。
> * **建议**: 当分子大于苯且使用小基组时，= 2 可能更快。请注意，若所请求阶数的解析导数不可用， 的值将被设置得更低。请参考 IDERIV 。

MODE_COUPLING

### `MODE_COUPLING`

> **在三阶和四阶导数计算中耦合的简正模式数目。**
>
> * **类型**: `INTEGER`
> * **默认值**: `2`
> * **选项**:
>     * $n$
>     * 表示
>     * $n$
>     * 模式耦合，最大值为 4。
> * **建议**: 使用默认值。

IGNORE_LOW_FREQ

### `IGNORE_LOW_FREQ`

> **在非谐校正计算中，可以忽略那些应被视为转动（rotation）的低频模式。**
>
> * **类型**: `INTEGER`
> * **默认值**: `300`
> * **选项**:
>     * $n$
>     * 任何谐频低于
>     * $n$
>     * 的模式将被忽略。
> * **建议**: 使用默认值。

FDIFF_STEPSIZE_QFF

### `FDIFF_STEPSIZE_QFF`

> **用有限差分计算三阶和四阶导数时使用的位移量。**
>
> * **类型**: `INTEGER`
> * **默认值**: `5291`
> * **选项**:
>     * $n$
>     * 使用大小为
>     * $n\times 10^{-5}$
>     * 的步长。
> * **建议**: 使用默认值，除非势能面非常平坦，此时应使用较大的值。

???+ example "示例 10.49: 在甲醛（formaldehyde）于 EDF2/6-31G* 优化得到的基态几何构型上，
进行四量子（four-quanta）非谐频率计算，该基态几何构型在作业的第一部分获得。
必须先执行谐频计算，它会为后续的非谐频率计算打印出一个预估时间。
如果已经执行过 FREQ 作业，则可以利用谐频计算保存的临时（scratch）文件
重新启动非谐计算。"
    ```qchem
    $molecule
       0 1
       C
       O, 1, CO
       H, 1, CH, 2, A
       H, 1, CH, 2, A, 3, D
    
       CO = 1.2
       CH = 1.0
       A  = 120.0
       D  = 180.0
    $end
    
    $rem
        JOBTYPE                     OPT
        METHOD                      EDF2
        BASIS                       6-31G*
        GEOM_OPT_TOL_DISPLACEMENT   1
        GEOM_OPT_TOL_GRADIENT       1
        GEOM_OPT_TOL_ENERGY         1
    $end
    
    @@@
    
    $molecule
        READ
    $end
    
    $rem
        JOBTYPE                     FREQ
        METHOD                      EDF2
        BASIS                       6-31G*
        ANHAR                       TRUE
        VCI                         4
    $end
    ```

非谐频率也可以采用部分 Hessian 近似（partial Hessian approximation）来计算（参见第 [10.8.4 节](partial-hess.md)）。

ANHAR_SEL

### `ANHAR_SEL`

> **选择用于后续非谐频率分析的简正模式子集。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * TRUE
>     * 选择简正模式子集
> * **建议**: 无

???+ example "示例 10.50: 本示例展示乙烯（ethene）的非谐频率计算，其中只有 C–H 伸缩振动模式被纳入非谐分析。"
    ```qchem
    $comment
      ethene
      restricted anharmonic frequency analysis
    $end
    
    $molecule
    0 1
      C   0.6665   0.0000   0.0000
      C  -0.6665   0.0000   0.0000
      H   1.2480   0.9304   0.0000
      H  -1.2480  -0.9304   0.0000
      H  -1.2480   0.9304   0.0000
      H   1.2480  -0.9304   0.0000
    $end
    
    $rem
       JOBTYPE           freq
       METHOD            hf
       BASIS             sto-3g
       ANHAR_SEL         TRUE
       N_SOL             4
    $end
    
    $alist
    9
    10
    11
    12
    $end
    ```
