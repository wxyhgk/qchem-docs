## 10.2.10 原子偶极矩与四极矩

（2026 年 7 月 4 日）

有时仅仅计算原子部分电荷是不够的，还需要进一步计算原子偶极矩（atomic dipoles）和四极矩（quadrupoles）。
这对于某些类型的力场（force field）尤其有用，它们利用这些项来更精确地模拟电荷各向异性（charge anisotropy）。
QChem 提供了计算原子偶极矩和四极矩的能力，其方法受到文献 [[1282]](../bib_references/bib.md#bib1335)
中公式化的启发。
我们只需通过将每个原子基组函数的贡献进行分配，来评估多极矩的原子贡献。
不过，我们通过使用本征原子轨道（intrinsic atomic orbitals, IAO）[[697]](../bib_references/bib.md#bib729)
来避免任何基组依赖性和离域误差，

已有研究表明 IAO 具有极好的基组收敛性[[37]](../bib_references/bib.md#bib20)。

本方法给出的原子四极矩是无迹（traceless）四极矩，这也是力场应用中更常用的类型。

我们使用以下方程计算原子偶极矩和（无迹）四极矩：

<a id="Ch10.E28"></a>

$$
\mu_{A}^{u}=\sum_{\alpha\ \mathrm{on}\ A}\sum_{\beta}2P_{\alpha\beta}^{IAO}\langle\chi_{\alpha}|u_{A}-\hat{u}|\chi_{\beta}\rangle \tag{10.28}
$$

<a id="Ch10.E29"></a>

$$
Q_{A}^{uv}=\sum_{\alpha\ \mathrm{on}\ A}\sum_{\beta}2P_{\alpha\beta}^{IAO}\langle\chi_{\alpha}|\frac{3}{2}(u_{A}-\hat{u})(v_{A}-\hat{v})-\frac{1}{2}||r_{A}-\hat{r}||^{2}\delta_{uv}|\chi_{\beta}\rangle \tag{10.29}
$$

其中 A 为原子索引，$r$ 为向量 $(x,y,z)$，$u=x,y,$ 或 $z$。
$\delta$ 是 Kronecker delta 函数，$\chi$ 表示一个本征原子轨道，
$\alpha$ 和 $\beta$ 为 IAO 索引，$P$ 是一粒子密度矩阵，
密度矩阵上的 $IAO$ 上标表示这是在 IAO 基下的密度矩阵。
此外，引入 $u_{A}$、$v_{A}$ 和 $r_{A}$（原子 A 的坐标）
保证了多极矩具有坐标原点不变性（origin-invariant）。

原子偶极矩和四极矩的计算由以下 *$rem* 变量控制：

### `DO_ATOMIC_MULTIPOLES`

> **启用原子多极矩计算**
>
> * **类型**: `BOOL`
> * **默认值**: `FALSE`
> * **取值选项**:
>     * `FALSE`: 不计算 IAO 原子多极矩
>     * `TRUE`: 计算 IAO 原子多极矩
> * **建议**: 无

???+ example "示例 10.6：通过 IAO/IBO 流程计算原子偶极矩与四极矩的输入。"
    ```qchem
    $molecule
    0 1
    F         0.0000000000    0.0000000000    0.2314949765
    H         0.0000000000    0.0000000000    1.1541050235
    $end
    
    $rem
    jobtyp sp
    method hf
    basis aug-cc-pvtz
    do_ibo true
    do_atomic_multipoles true
    $end
    
    $loco
    min_basis autosad
    ibo_mem 1000
    $end
    ```
