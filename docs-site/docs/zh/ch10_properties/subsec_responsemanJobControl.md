## 10.14.2 任务控制

（2026 年 7 月 4 日）

在 *$rem* 区段中只需一个关键字即可激活响应（response）模块。所有其他选项均通过 *$response* 输入区段进行控制。

### `RESPONSE`

> **激活通用响应性质模块。**
>
> * **类型**：`LOGICAL`
> * **默认值**：`FALSE`
> * **可选值**：
>     * FALSE（或 0）
>     * 不激活通用响应性质模块。
>     * TRUE（或 1）
>     * 激活通用响应性质模块。
> * **建议**：无。

### `ORDER`

> **设置要执行的响应理论最高阶数。输入区段：$response**
>
> * **类型**：`STRING`
> * **默认值**：`LINEAR`
> * **可选值**：
>     * LINEAR
>     * 执行至线性响应（linear response）为止。
> * **建议**：无。目前仅实现了线性响应。

### `SOLVER`

> **设置求解响应方程所用的算法。输入区段：$response**
>
> * **类型**：`STRING`
> * **默认值**：`DIIS`
> * **可选值**：
>     * LINEAR
>     * 迭代求解响应方程，不使用收敛加速。
>     * DIIS
>     * 迭代求解响应方程，并使用 DIIS 进行收敛加速。
> * **建议**：DIIS

### `HAMILTONIAN`

> **设置轨道 Hessian（orbital Hessian）所采用的近似。输入区段：$response**
>
> * **类型**：`STRING`
> * **默认值**：`RPA`
> * **可选值**：
>     * RPA
>     * 不作任何近似。
>     * TDA
>     * 与 CIS 近似相同。
>     * CIS
>     * TDA 的同义写法。
> * **建议**：无。

### `SPIN`

> **算符作用于同自旋（单重态）还是不同自旋（三重态）的激发态？输入区段：$response**
>
> * **类型**：`STRING`
> * **默认值**：`SINGLET`
> * **可选值**：
>     * SINGLET
>     * 算符保持自旋不变（spin-conserving）。
>     * TRIPLET
>     * 算符不保持自旋不变。
> * **建议**：无。需谨慎使用，因为单次计算中的所有算符都会强制遵循此选项。

### `MAXITER`

> **最大迭代次数。输入区段：$response**
>
> * **类型**：`INTEGER`
> * **默认值**：`60`
> * **可选值**：
>     * $n$
>     * 最大迭代次数。
> * **建议**：使用默认值。

### `CONV`

> **收敛阈值。对于 DIIS 求解器，这是 DIIS 误差范数；对于线性求解器，这是相邻迭代间响应向量的均方根偏差（RMSD）。输入区段：$response**
>
> * **类型**：`INTEGER`
> * **默认值**：`8`
> * **可选值**：
>     * $n$
>     * 将收敛阈值设置为
>     * $10^{-n}$
>     * 。
> * **建议**：使用默认值。

### `DIIS_START`

> **启动 DIIS 的迭代步数。在此之前执行线性迭代。输入区段：$response**
>
> * **类型**：`INTEGER`
> * **默认值**：`1`
> * **可选值**：
>     * $n$
>     * 启动 DIIS 的迭代步数。
> * **建议**：使用默认值。

### `DIIS_VECTORS`

> **保留的 DIIS 向量最大数目。输入区段：$response**
>
> * **类型**：`INTEGER`
> * **默认值**：`7`
> * **可选值**：
>     * $n>0$
>     * 保留的 DIIS 向量最大数目。
> * **建议**：使用默认值。

### `RHF_AS_UHF`

> **是否应像使用非限制（unrestricted）参考波函数那样求解响应方程？输入区段：$response**
>
> * **类型**：`LOGICAL`
> * **默认值**：`FALSE`
> * **可选值**：
>     * TRUE
>     * 将 RHF 波函数按 UHF 处理。
>     * FALSE
>     * 将 RHF 波函数按 RHF 处理。
> * **建议**：使用默认值。仅用于调试。

### `PRINT_LEVEL`

> **设置整个响应模块的通用打印级别。输入区段：$response**
>
> * **类型**：`INTEGER`
> * **默认值**：`2`
> * **可选值**：
>     * 1
>     * 打印初始猜测和最终结果。
>     * 2
>     * 级别 1 加上迭代过程和评注。
>     * 10
>     * 海量输出（“砍树”级别）。
> * **建议**：使用默认值。

### `RUN_TYPE`

> **是执行单次响应计算，还是对轨道 Hessian 与激发类型的所有组合逐一执行？输入区段：$response**
>
> * **类型**：`STRING`
> * **默认值**：`SINGLE`
> * **可选值**：
>     * SINGLE
>     * 仅使用各自关键字中指定的轨道 Hessian 近似与激发类型。
>     * ALL
>     * 使用 RPA/TDA 与单重态/三重态的所有组合。
> * **建议**：使用默认值，除非需要对比不同近似和激发类型。

### `SAVE`

> **是否将某些量保存到磁盘？输入区段：$response**
>
> * **类型**：`INTEGER`
> * **默认值**：`0`
> * **可选值**：
>     * 0
>     * 不将任何量保存到磁盘。
>     * 1
>     * 以分子轨道（MO）基保存各量。
>     * 2
>     * 以分子轨道（MO）基和原子轨道（AO）基保存各量。
> * **建议**：无。

### `READ`

> **是否从磁盘读取某些量？输入区段：$response**
>
> * **类型**：`INTEGER`
> * **默认值**：`0`
> * **可选值**：
>     * 0
>     * 不从磁盘读取任何量。
>     * 1
>     * 读取 MO 基下的各量。
>     * 2
>     * 读取 AO 基下的各量。
> * **建议**：无。

### `DUMP_AO_INTEGRALS`

> **是否将 AO 基的性质积分保存到磁盘？输入区段：$response**
>
> * **类型**：`LOGICAL`
> * **默认值**：`FALSE`
> * **可选值**：
>     * TRUE
>     * 将 AO 基性质积分保存到磁盘。
>     * FALSE
>     * 不将 AO 基性质积分保存到磁盘。
> * **建议**：无。

### `FORCE_NOT_NONORTHOGONAL`

> **是否忽略底层轨道的性质，直接求解正则（canonical）响应方程？输入区段：$response**
>
> * **类型**：`LOGICAL`
> * **默认值**：`FALSE`
> * **可选值**：
>     * TRUE
>     * FALSE
> * **建议**：保持为 false。若对非正交 MO 使用标准（正则）响应方程，将得到错误结果。

### `FORCE_NONORTHOGONAL`

> **是否忽略底层轨道的性质，直接求解非正交响应方程？输入区段：$response**
>
> * **类型**：`LOGICAL`
> * **默认值**：`FALSE`
> * **可选值**：
>     * TRUE
>     * FALSE
> * **建议**：保持为 false。与正则 MO 一起使用时，其结果应与标准方程一致，但计算代价更高。

### `FREQUENCY`

> **一个或多个入射场的场强，以原子单位表示。对每个场强都会单独执行一次响应计算。0.0 对应静态极限。输入区段：$response**
>
> * **类型**：`DOUBLE`
> * **默认值**：`0.0`
> * **可选值**：
>     * $l\,m\,n\,\dots$
>     * 一个或多个场强，以空格分隔。
> * **建议**：无。
