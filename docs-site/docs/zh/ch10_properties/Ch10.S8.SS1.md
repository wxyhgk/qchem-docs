## 10.8.1 概述

(July 4, 2026)

振动分析是量子化学家极为重要的工具，它提供了分子指纹，在众多实验研究中对于分子种类的鉴定具有不可替代的价值。**Q-Chem** 包含一个振动分析程序包，能够计算振动频率及其红外和拉曼活性。[[644]](../bib_references/bib.md#bib673)

振动频率的计算方式有三种：使用解析 Hessian 矩阵（若可用）、对梯度进行数值有限差分，或者作为最后手段，对单点能进行双重有限差分。（关于解析梯度和 Hessian 矩阵的可用性，参见表 [9.2](../ch09_opt/topic_ts_Overview.md#table:grad_and_hess)。有限差分步长由 FDIFF_STEPSIZE 控制。）
**Q-Chem** 中的默认设置是针对所请求的理论方法使用最高可得的解析导数阶数。各种 *ab initio* 理论在确定振动频率方面的性能已有充分文献记载。[[968]](../bib_references/bib.md#bib1008)

在 HF 和 DFT（密度泛函理论）水平上进行解析频率计算时，需求解耦合微扰自洽场（Coupled-Perturbed SCF, CPSCF）方程。这是计算中最耗时的步骤，同时也是最消耗内存的步骤。所需内存量为 ${\cal{O}}({N^{2}M})$，其中 $N$ 为基函数（Basis Function）数目，$M$ 为原子数目。这比 SCF（自洽场）计算所需的内存高出一个数量级，通常是在对较大体系进行解析计算时的限制因素。**Q-Chem** 采用了一种解决该问题的新方法，通过分段求解 CPSCF 方程来避免这一内存瓶颈。[[709]](../bib_references/bib.md#bib741)
 该方法不是一次性求解所有微扰，而是将其分为若干段，每次只对一段应用 CPSCF，从而使内存标度变为 ${\cal{O}}({N^{2}M/N_{\mathrm{seg}}})$，
其中 $N_{\mathrm{seg}}$ 为段数。此选项由程序自动调用。

振动分析完成后，**Q-Chem** 按照刚性转子-谐振子（Rigid-Rotor-Harmonic-Oscillator, RRHO）方法，在标准温度和压力下计算有用的统计热力学性质。
这些性质包括零点振动能（Zero-Point Vibrational Energy, ZPVE）以及平动、转动和振动的熵与焓。注意：在 **Q-Chem** 的输出中，"total enthalpy"（总焓）实际上是指对内能的总焓校正。必须将此"总焓"加到内能上，才能得到通常意义上的总焓。
除了这些热校正之外，**Q-Chem** 还按照 Head-Gordon 及其合作者提出的准 RRHO（quasi-RRHO, qRRHO）方法输出插值振动熵和振动焓，[[822]](../bib_references/bib.md#bib853)

该方法将 Grimme 先前的方案[[496]](../bib_references/bib.md#bib507)
 推广以处理低频振动；参见第 [10.8.3](sect_qrrho.md) 节。

## 10.8.1.1 作业控制

要进行频率分析，用户*至少*需要在 *$molecule* 关键字中提供一个分子，并在 *$rem* 关键字中使用 *$rem* 变量 EXCHANGE、CORRELATION（如需要）（第 [4](../ch04_scf/chap_scf.md) 章）
和 BASIS（第 [8](../ch08_basis/chap_basis.md) 章）来定义合适的理论水平。由于默认的作业类型（JOBTYPE）是单点能（SP）计算，
因此必须将 JOBTYPE *$rem* 变量设置为 FREQ。

需要特别注意的是，振动频率分析必须在势能面上的驻点处进行，且该驻点需在相同的理论水平下完成几何优化。因此，振动频率分析最自然的做法是在同一个输入文件中紧跟几何优化之后进行，
其中分子几何结构由此获得（参见示例）。

用户还应注意，DFT 计算中所使用的求积网格的质量在计算二阶导数时更为重要。**Q-Chem** 3.0 中某些原子的默认网格已发生变化（参见
第 [5.5](../ch05_dft/sect_quadrature.md) 节），因此振动频率可能与先前版本略有不同。建议在进行频率计算时使用比默认网格更大的网格。

频率分析的标准输出包括以下内容。

- •

振动频率。
- •

拉曼和红外活性及强度（需要 *$rem* DORAMAN）。
- •

原子质量。
- •

零点振动能。
- •

平动、转动和振动的熵与焓。

还有若干其他 *$rem* 变量可用于控制振动频率分析。具体如下：

DORAMAN

### `DORAMAN`

> **控制拉曼强度的计算。要求 JOBTYPE 设置为 FREQ**

> * **类型**: `LOGICAL`

>     * FALSE
>     * 不计算拉曼强度。
>     * TRUE
>     * 计算拉曼强度。

>
> * **类型**: `INTEGER`
> * **默认值**: `1`
> * **选项**:
>     * 1
>     * 标准完整信息输出。
>     * 如果
>     * VCI

>     * 4

>     * 矩阵。

## 10.8.1.2 解读输出

以下讨论中的数值对应于示例 [10.8.1.1](#ex:vib)，所引用的配分函数来自 McQuarrie & Simon 的教科书。

 注意 **Q-Chem** 默认假设 $T=298.15$ K 且
$P=1.00$ atm；有关如何修改这些设置的说明，参见第 [10.8.2](ex_Isotope-Mass.md) 节。

以零点振动能（ZPVE）列出的量，

`Zero point vibrational energy:       12.695 kcal/mol`

对应于 $\text{ZPVE}=\tfrac{1}{2}\sum_{K}hc\nu_{K}$。在 **Q-Chem** 中，振动熵（$S_{\text{vib}}$）是从势阱底部而非零点能级计算的，因此包含了零点能。这对应于如下的振动配分函数

<a id="Ch10.E66"></a>
$$
q_{\text{vib}}(T)=\prod_{K}\frac{e^{-\Theta_{\nu,K}/2T}}{1-e^{-\Theta_{\nu,K}/T}} \tag{10.66}
$$

其中 $K$ 对振动模式进行编号，$\Theta_{K}=h\nu_{K}/k_{B}$ 是第 $K$ 个模式的振动温度。
该表达式可通过乘以因子 $\Theta_{K}/2$ 来改为从第一振动能级而非势阱底部开始。振动熵则为

<a id="A3.S8.EGx79"></a>
$$
\displaystyle\begin{aligned} \displaystyle S_{\text{vib}}&\displaystyle=k_{B}T\left(\frac{\partial\ln q_{\text{vib}}}{\partial T}\right)_{\!V}+k_{B}\ln q_{\text{vib}}\\
&\displaystyle=k_{B}T\sum_{K}\left[\frac{\Theta_{K}/T}{e^{-\Theta_{K}/T}-1}-\ln(1-e^{-\Theta_{K}/T})\right]\;,\end{aligned} \tag{10.67}
$$

对于示例 [10.8.1.1](#ex:vib)，其输出为

`Vibrational Entropy:           0.620  cal/mol.K`

振动焓包含零点振动能以及一个额外的温度相关项：

<a id="Ch10.E68"></a>
$$
H_{\text{vib}}=hc\sum_{K}\left[\frac{\nu_{K}}{2}+\frac{\nu_{K}}{e^{\Theta_{K}/T}-1}\right]\;. \tag{10.68}
$$

其输出为

`Vibrational Enthalpy:         12.839 kcal/mol`

转动焓和平动焓是 $RT$ 的整数倍，

<a id="Ch10.E69"></a>
$$
H_{\text{total}}=H_{\text{vib}}+H_{\text{rot}}+H_{\text{trans}}+RT\;, \tag{10.69}
$$

其中最后一项 $RT$ 的贡献来自定义 $H=U+PV$。
$H_{\text{total}}$ 的输出为

`Total Enthalpy:               15.209 kcal/mol`

平动熵和转动熵可以从相应的理想气体配分函数计算得到。

对于在隐式溶剂中执行的热化学计算（使用第 [11.2](../ch11_env/topic_solvation.md) 节中描述的模型），存在一个颇具争议的精妙问题。[[585]](../bib_references/bib.md#bib608)

这涉及是否应当将振动对自由能的贡献包含在内。在几乎所有情况下，连续介质溶剂化模型都是为了使用刚性气相几何结构的溶质分子能够重现实验溶剂化自由能（$\Delta_{\text{solv}}G^{\circ}$）而进行参数化的。如果在隐式溶剂中进行的振动频率计算所得的 $-TS_{\text{vib}}$ 被加入，则可能存在双重计算的问题，而通过改用气相谐振频率来处理溶质或许可以避免这一问题。[[585]](../bib_references/bib.md#bib608)

然而，对于用于训练隐式溶剂模型的小分子数据集而言，这两种方案之间的差异可以忽略不计（$\sim 0.2$ kcal/mol）。[[1165]](../bib_references/bib.md#bib1218)
 只有使用溶液相振动频率，才能获得由溶剂化引起的几何结构变化对 $S_{\text{vib}}$ 的校正，这对于较大分子可能非常重要。
注意 **Q-Chem** 的谐振频率引擎假设的是气相分子（即使在存在连续介质溶剂的情况下），因此在所有情况下都会输出平动和转动对自由能的贡献。这些贡献不应包含在溶液相自由能差中。

## 10.8.1.3 使用分子分段的有限差分频率计算

对于 **Q-Chem** 中未实现解析二阶核导数的电子结构方法，将执行基于核梯度的有限差分 Hessian 计算。Hessian 矩阵元按如下方式计算：

<a id="Ch10.E70"></a>
$$
H_{ij}=\frac{\partial^{2}E}{\partial x_{i}\partial x_{j}}=\frac{g_{i}(x_{j}+\Delta x_{j})-g_{i}(x_{j}-\Delta x_{j})}{2\Delta x_{j}} \tag{10.70}
$$

其中 $g_{i}=\partial E/\partial x_{i}$。构建 Hessian 矩阵总共需要在位移结构处进行 $6N_{\mathrm{atom}}$ 次梯度计算。

默认情况下，$6N_{\mathrm{atom}}$ 次梯度计算以串行方式执行，这对于原子数较多的分子极其低效。利用这些有限差分计算彼此独立的特点，**Q-Chem** 提供了在分子分段（*即*，原子块）中执行这些计算的选项。用户需要使用 *$rem* 变量 FD2ND_BLOCK_SIZE 指定每段中的原子数。
总段数则为 $\lfloor N_{\mathrm{atom}}/\mathrm{blocksize}\rfloor+1$（注意：最后一段中的原子数允许少于用户指定的块大小）。然后用户需要设置并执行一系列输入，其中 FD2ND_BLOCK_INDEX 设置为不同的值（从
0 开始）。注意所有这些作业应使用相同的 FD2ND_BLOCK_SIZE 值。
在大型计算机集群上，这些作业可以轻松同时执行。这些作业会在工作目录下生成文本文件 `grdntDisp.0`、`grdntDisp.1`……以及
`dipoleDisp.0`、`dipoleDisp.1`……注意，如果未自动设置，则需要添加 IDERIV = 1。

在所有分子分段的计算完成后，用户需要执行一个额外的作业，将 FD2ND_BLOCK_INDEX 设置为 $-1$。该作业将收集所有分段的结果（从工作目录中的文本文件），构建 Hessian 矩阵，并完成振动频率分析。这种方法将大大加速大分子的有限差分频率计算。

FD2ND_BLOCK_SIZE

### `FD2ND_BLOCK_SIZE`

> **控制有限差分 Hessian 计算中每段的原子数。**
>
> * **类型**: `INTEGER`
> * **默认值**: `Uninitialized`
> * **选项**:
>     * $n$
>     * 每段包含
>     * $n$
>     * 个原子
> * **建议**: 该值可根据期望的段数进行估算。它应显著小于分子中的总原子数。

FD2ND_BLOCK_INDEX

### `FD2ND_BLOCK_INDEX`

> **标识在给定的有限差分计算中正在处理哪个原子块的标志。**
>
> * **类型**: `INTEGER`
> * **默认值**: `Uninitialized`
> * **选项**:
>     * $0,1,...,N_{\text{frag}}-1$
>     * 第一个碎片的索引为 0，最后一个应为
>     * $N_{\text{frag}}-1$
>     * $-1$
>     * 汇总结果的作业标志。
> * **建议**: 无
