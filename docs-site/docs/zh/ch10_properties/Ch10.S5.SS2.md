## 10.5.2 使用 **MolDen** 和 **MacMolPlt** 可视化轨道

(July 4, 2026)

按需请求时，**Q-Chem** 会生成一个 **MolDen** 输入文件。**MolDen** 是一款可免费获取的分子可视化程序。[[G. Schaftenaar and J. H. Noordik (2000)]](../bib_references/bib.md#bib1258) **MolDen** 可用于查看球棍分子模型（包括几何优化过程的逐步可视化）、分子轨道、振动简正模式以及振动光谱。**MolDen** 还内置了一个功能强大的 *Z*-矩阵编辑器。与 **Q-Chem** 配合使用时，通过 **MolDen** 进行的轨道可视化目前支持 $s$、$p$ 和 $d$ 函数（纯函数或笛卡尔函数），以及纯 $f$ 函数。将 MOLDEN_FORMAT 设置为 TRUE 后，**Q-Chem** 会在日志文件的末尾追加一个 **MolDen** 格式的输入文件。由于某些版本的 **MolDen** 在解析 **Q-Chem** 日志文件本身时会遇到困难，我们建议用户将 **Q-Chem** 日志文件中 **MolDen** 格式的部分剪切并粘贴到一个单独的文件中，供 **MolDen** 读取。

### `MOLDEN_FORMAT`

> **请求生成一个包含 Q-Chem 作业信息的 MolDen 格式输入文件。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * `TRUE`: Append MolDen input file at the end of the Q-Chem output file.
> * **建议**: 无。

**MolDen** 格式的文件也可以被 **MacMolPlt** 读取，这是另一款可免费获取的可视化程序。[[136]](../bib_references/bib.md#bib126)
[[12]](../bib_references/bib.md#bib16)
**MacMolPlt** 生成轨道等值曲面（iso-contour surfaces）的速度比 **MolDen** 快得多，然而在 **MacMolPlt** 中，这些曲面仅对笛卡尔高斯基函数可用，*i.e.*,
PURECART = 2222，而这可能并非默认设置。

???+ example "示例 10.21: 生成用于分子轨道可视化的 MolDen 文件。"
    ```qchem
    $molecule
       0 1
       O
       H  1  0.95
       H  1  0.95  2  104.5
    $end
    
    $rem
       METHOD           hf
       BASIS            cc-pvtz
       PRINT_ORBITALS   true (default is to print 5 virtual orbitals)
       MOLDEN_FORMAT    true
    $end
    ```

对于几何优化和振动频率计算，用户只需将 MOLDEN_FORMAT 设置为 TRUE，相关的几何结构或简正模式信息便会自动出现在 **Q-Chem** 日志文件的 **MolDen** 部分中。

???+ example "示例 10.22: 生成用于逐步查看几何优化过程的 MolDen 文件。"
    ```qchem
    $molecule
       0  1
       O
       H  1  0.95
       H  1  0.95  2  104.5
    $end
    
    $rem
       JOBTYPE         opt
       METHOD          hf
       BASIS           6-31G*
       MOLDEN_FORMAT   true
    $end
    ```
