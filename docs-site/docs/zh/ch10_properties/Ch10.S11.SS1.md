## 10.11.1 介绍

（2026 年 7 月 4 日）

核磁共振（Nuclear Magnetic Resonance, NMR）波谱学对现代化学与生物化学的重要性无论怎样估计都不为过。由于测得的 NMR 信号与结构性质之间并不存在直接关系，因此需要一种可靠的化学位移预测方法；而且，尽管实验技术取得了巨大进步，对观测到的实验谱图的理解与可靠指认往往仍是一项非常困难的任务。正因如此，量子化学方法无论在溶液中还是固体中都能发挥极大的作用。[[1013]](../bib_references/bib.md#bib1051)

自 **Q-Chem** 7.0 版本发布起，新的基于有限差分（finite difference, FD）的 NMR 磁屏蔽计算方法已经可用。当在解析一阶导数上使用有限差分（FD1）时，得益于高效的基于 GIAO 的 RI-JK 和 occ-RI-K 算法（适用于全局杂化和范围分离泛函）以及更好的并行化，FD1-NMR 磁屏蔽计算的效率远高于全解析实现。在效率提升的同时，FD-NMR 功能还支持 GDM 求解器和更高角动量的基函数。

**Q-Chem** 的解析 NMR 程序包的功能包括：

- 采用规范不变原子轨道（GIAO）进行 NMR 化学位移的 restricted Hartree-Fock 和密度泛函理论（DFT）计算。
- 支持线性标度的 CFMM 和 LinK 方法（章节 [4.6](../ch04_scf/sec_O_N.md)）来计算类 Coulomb 矩阵和类交换矩阵。
- 用于线性标度 NMR 计算的基于密度矩阵的耦合微扰 SCF 方法。
- DIIS 加速。
- 支持最高至 $h$ 函数的基组（Basis Set）。
- 支持 LDA、GGA、Meta-GGA、[[923]](../bib_references/bib.md#bib959) 全局杂化以及常见的范围分离泛函（RSH 仅支持 s、p 和 d 基函数）。VV10 是唯一被支持的non-local关联泛函。

NMR 化学位移和间接自旋-自旋耦合常数的计算在章节 [10.11.2](sec_magnetic_NMR.md) 中讨论。此外还可以计算其他磁学性质，如章节 [10.11.4](sec_magnetman.md) 所述，其中包括超精细相互作用张量（电子自旋—核自旋相互作用）以及与电场梯度相关的核四极相互作用。
