## 10.11.1 引言

(July 4, 2026)

核磁共振（Nuclear Magnetic Resonance, NMR）波谱学对现代化学和生物化学的重要性怎么估计都不为过。由于测得的 NMR 信号与结构性质之间不存在直接的对应关系，因此需要一种可靠的方法来预测 NMR 化学位移；尽管实验技术取得了巨大进步，但对观测到的实验谱图进行理解和可靠归属往往仍然是一项 highly difficult 的任务。因此，量子化学方法在溶液和固态体系中都能发挥极大的作用。[[1013]](../bib_references/bib.md#bib1051)

自 **Q-Chem** 7.0 版本发布以来，新增了基于有限差分（Finite Difference, FD）的 NMR 磁屏蔽计算功能。当采用对解析一阶导数进行有限差分（FD1）的方式时，得益于高效的基于规范不变原子轨道（Gauge-Including Atomic Orbital, GIAO）的 RI-JK 和 occ-RI-K 算法（适用于全局杂化泛函和范围分离泛函）的支持以及更好的并行化，FD1-NMR 磁屏蔽计算比全解析实现高效得多。除效率提升之外，FD-NMR 功能还支持 GDM 以及更高角动量的基函数。

**Q-Chem** 的 analyticNMR 程序包具有以下特性：

- •

使用规范不变原子轨道（GIAO）进行限制型 Hartree-Fock 和密度泛函理论（Density Functional Theory, DFT）的 NMR 化学位移计算。
- •

支持线性标度的 CFMM 和 LinK 过程（见第 [4.6](../ch04_scf/sec_O(N).md) 节），用于计算类库仑矩阵和类交换矩阵。
- •

基于密度矩阵的耦合微扰自洽场（Coupled-Perturbed SCF, CPSCF）方法，可实现线性标度的 NMR 计算。
- •

DIIS 加速。
- •

支持最高至 $h$ 函数的基组。
- •

支持 LDA、GGA、Meta-GGA，[[923]](../bib_references/bib.md#bib951)

NMR 化学位移及自旋-自旋耦合常数的解析计算在后续章节中介绍。
