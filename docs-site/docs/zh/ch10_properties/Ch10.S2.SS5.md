## 10.2.5 对称性分解

（2026 年 7 月 4 日）

**Q-Chem** 默认会将自洽场（SCF）波函数的分子轨道对称性与能量写入输出文件。如有需要，还可以对动能与核吸引能进行对称性分解计算。

SYMMETRY_DECOMPOSITION

### `SYMMETRY_DECOMPOSITION`

> **指定要计算的对称性分解类型。**
>
> * **类型**: `INTEGER`
> * **默认值**: `1`
> * **可选取值**:
>     * 0
>     * 不进行对称性分解。
>     * 1
>     * 计算分子轨道（MO）本征值及其对称性（若可获得）。
>     * 2
>     * 对动能矩阵和核吸引矩阵进行对称性分解。
> * **建议**: 无
