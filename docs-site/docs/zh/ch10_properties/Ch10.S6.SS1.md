## 10.6.1 概述

(July 4, 2026)

静电势（electrostatic potential, ESP）对位置的导数给出电场（electric field），电场是一个基本的物理量，已被证明在从振动光谱学到分子及酶催化的众多应用中发挥着重要作用。与 ESP 的情况类似，**Q-Chem** 能够计算核位置或给定网格点上的电场值，该功能同样由 *$rem* 变量 ESP_GRID 控制。当 ESP_EFIELD $>0$ 时，电场的计算即被开启：

ESP_EFIELD

### `ESP_EFIELD`

> **触发在核位置或给定网格点上计算 ESP 和/或电场**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **选项**:
>     * 0
>     * 仅计算 ESP
>     * 1
>     * 同时计算 ESP 和电场
>     * 2
>     * 仅计算电场
> * **建议**: 无

???+ example "示例 10.34: 计算水分子核位置上的电场"
    ```qchem
    $molecule
       0 1
       O    -0.9112629280    1.0922672019    1.0200719528
       H    -1.7568362275    1.5186695533    1.2826042030
       H    -0.5592940377    1.7449530375    0.3694007293
    $end
    
    $rem
       METHOD       b3lyp
       BASIS        cc-pvtz
       ESP_GRID     0
       ESP_EFIELD   2 ! compute E-field on atomic positions
    $end
    ```

**Q-Chem** 6 支持两种基于密度泛函理论（Density Functional Theory, DFT）的电子结构方法，用于评估由化学环境（*e.g.* 溶剂）在“探针（probe）”分子的特定位置（通常是原子位置）所产生的电场（以及 ESP）。这些方法的细节见参考文献 [[1572]](../bib_references/bib.md#bib1637)，其核心是将整个体系的电子密度划分为属于中心体系的部分和属于环境的部分。第一种方法基于 SPADE 划分格式（划分方案）（见第 [11.6.1](../ch11_env/subsec_emb_theory.md) 节）[[253]](../bib_references/bib.md#bib254)，它对标准自洽场（SCF）计算得到的收敛占据分子轨道（MO）进行变换，然后将其分配给体系的不同部分。第二种方法基于使用完全局域分子轨道（absolutely localized molecular orbitals, ALMOs，见第 [12.5.1](../ch12_frag/sect_lp_scf.md) 节）[[683]](../bib_references/bib.md#bib705) 的 DFT 计算，该方法从一开始就对超体系（supersystem）进行碎裂化（fragmentation），碎片分子轨道在被其他碎片极化的过程中进行变分优化。这两种方法随后都利用相应分配的占据分子轨道构造超体系中“环境”部分的电子密度（$\rho_{\mathrm{E}}$），并可以使用环境的电子密度和核电荷来计算中心“探针”体系特定位置处的 ESP 和电场。将嵌入的中心体系及其环境分别记为 S 和 E，则位置 $A\in\text{S}$ 处的 ESP 和电场矢量（$\phi_{A}$ 和 $\mathbf{F}_{\!A}$）可由下式计算

<a id="eq:env_esp"></a>
$$
\phi_{A}=\sum_{B\in\text{E}}\frac{Z_{B}}{|\mathbf{r}_{A}-\mathbf{r}_{B}|}-\int\frac{\rho_{\text{E}}(\mathbf{r})}{|\mathbf{r}_{A}-\mathbf{r}|}\mathrm{d}\mathbf{r} \tag{10.64}
$$

以及

<a id="eq:env_field"></a>
$$
\mathbf{F}_{\!A}=-\bm{\hat{\nabla}}\phi_{A}=\sum_{B\in\text{E}}\frac{Z_{B}(\mathbf{r}_{A}-\mathbf{r}_{B})}{|\mathbf{r}_{A}-\mathbf{r}_{B}|^{3}}-\int\frac{\rho_{\text{E}}(\mathbf{r})(\mathbf{r}_{A}-\mathbf{r})}{|\mathbf{r}_{A}-\mathbf{r}|^{3}}\mathrm{d}\mathbf{r}\;. \tag{10.65}
$$

这些方法目前的实现要求为单次环境 ESP 与电场计算运行两个 **Q-Chem** 作业。在第一个作业中，执行 SCF 或 SCF-MI 计算，并生成分配给环境的占据分子轨道或电子密度；在第二个作业中，读入环境的分子轨道或电子密度，并使用公式 ([10.64](#eq:env_esp)) 和 ([10.65](#eq:env_field)) 计算 ESP 和电场。注意在第二个作业中，嵌入的中心体系（“探针”）用鬼原子（ghost atoms）表示以探测核位置；并且对于 SPADE 和 ALMO，第二个作业的 SCF_GUESS 必须分别设置为 READ 和 READ_DEN。若要在中心体系的核位置处计算势和场，应设置 ESP_GRID = 0；对于其他选项（*e.g.* 在网格点上计算 ESP 及其梯度），应参阅第 [10.5.8](sec_ESP.md) 节中关于 “ESP_GRID” 的文档。

ALMO_EFIELD

### `ALMO_EFIELD`

> **使用基于 ALMO 的划分方案计算环境 ESP/电场**
>
> * **类型**: `BOOLEAN`
> * **默认值**: `FALSE`
> * **选项**:
>     * TRUE
>     * 在作业 1 中，保存由 ALMO 构造的环境电子密度；
>     * 在作业 2 中，读入该电子密度
>     * （必须与
>     * SCF_GUESS
>     * =
>     * READ_DEN
>     * 一起使用）
>     * FALSE
>     * 不执行基于 ALMO 的 ESP/场计算
> * **建议**: 在基于 ALMO 的电场计算中，两个作业均需设置

ALMO_EFIELD_PROBE_FRGM

### `ALMO_EFIELD_PROBE_FRGM`

> **在基于 ALMO 的 ESP 和电场计算中指定探针碎片的索引**
>
> * **类型**: `INTEGER`
> * **默认值**: `1`
> * **选项**:
>     * $n$
>     * 将第
>     * $n$
>     * 个碎片指定为探针
> * **建议**: 无

???+ example "示例 10.34: 使用 SPADE 划分方法计算由环境（第二个 H ${}_{2}$ O 分子）在第一个 H ${}_{2}$ O 原子位置处产生的 ESP 和电场"
    ```qchem
    $molecule
    0 1
    --
    0 1
    O  -1.551007  -0.114520   0.000000
    H  -1.934259   0.762503   0.000000
    H  -0.599677   0.040712   0.000000
    --
    0 1
    O   1.350625   0.111469   0.000000
    H   1.680398  -0.373741  -0.758561
    H   1.680398  -0.373741   0.758561
    $end
    
    $rem
    jobtype  sp
    method   b3lyp
    basis    6-31G(d)
    env_method b3lyp
    gen_scfman_embed true
    spade_partition  true
    scf_convergence  8
    embedding_early_stop true ! skip the embedded SCF
    integral_symmetry    false
    point_group_symmetry false
    $end
    
    @@@
    
    $molecule
    0 1
    @O  -1.551007  -0.114520   0.000000
    @H  -1.934259   0.762503   0.000000
    @H  -0.599677   0.040712   0.000000
    O    1.350625   0.111469   0.000000
    H    1.680398  -0.373741  -0.758561
    H    1.680398  -0.373741   0.758561
    $end
    
    $rem
    method      b3lyp
    basis       6-31G(d)
    scf_guess   read
    skip_scfman true ! generate results directly from the MOs read in
    esp_grid    0
    esp_efield  1    ! compute ESP and E-field on atomic positions
    integral_symmetry    false
    point_group_symmetry false
    $end
    
    ```
