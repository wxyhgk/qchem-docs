## 10.2.1 引言

(July 4, 2026)

**Q-Chem** 默认会执行一些标准的波函数分析。
在 *$rem* 段中设置 WAVEFUNCTION_ANALYSIS = FALSE 将关闭所有波函数分析功能；或者也可以如本节所述，对这些功能进行单独控制。
自然键轨道（Natural Bond Orbital, NBO）分析程序已与 **Q-Chem** 对接，可以执行更复杂的分析；
更多细节参见第 [10.3.1](sect_NBO.md) 节。

### `WAVEFUNCTION_ANALYSIS`

> **控制默认波函数分析任务的执行。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `TRUE`
> * **可选值**:
>     * `TRUE`: 执行默认波函数分析。
>     * `FALSE`: 不执行默认波函数分析。
> * **建议**: 无。该选项对 NBO 分析没有影响。
