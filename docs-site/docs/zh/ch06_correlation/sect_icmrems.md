## 6.21.3 iFCI 的任务控制

（2026 年 7 月 4 日）

### `IFCI_TUPLES`

> **要求解的 $n$ 体展开阶数。注意 $n>2$ 可能带来高昂的计算代价。**
>
> * **类型**：`INTEGER`
> * **默认值**：`必须设置。`
> * **可选值**：
>     * 1
>     * $n=1$
>     * 2
>     * $n=2$
>     * 3
>     * $n=3$
>     * 4
>     * $n=4$
> * **建议**：初始体系分析使用 $n=2$，更高精度使用 $n>2$。

### `IFCI_READ`

> **若已存在 TUPLES_1E_DATA 文件，则利用该文件重启 iFCI 计算。**
>
> * **类型**：`INTEGER`
> * **默认值**：`0`
> * **可选值**：
>     * 0
>     * 从头开始计算
>     * 1
>     * 从先前文件重启
> * **建议**：若不存在先前运行的文件则使用 0；若希望基于先前数据重启则使用 1。

### `IFCI_TRIPLETS`

> **设置要求解的态（自旋多重度）。**
>
> * **类型**：`INTEGER`
> * **默认值**：`0`
> * **可选值**：
>     * 0
>     * 单重态（Singlet）
>     * 1
>     * 三重态（Triplet）
>     * 2
>     * 五重态（Quintet）
> * **建议**：无

### `IFCI_ZETA`

> **每个 iFCI 增量（increment）的收敛阈值。注意其格式为 $\zeta=$ $/10$ 。**
>
> * **类型**：`INTEGER`
> * **默认值**：`55`
> * **可选值**：
>     * 45
>     * 宽松（Loose）
>     * 55
>     * 中等（Moderate）
>     * 65
>     * 严格（Tight）
>     * 75
>     * 更严格（Tighter）
>     * 85
>     * 非常严格（Quite tight）
>     * 95
>     * 最严格（Maximum）
> * **建议**：使用 65，并增大到 75 以检验收敛性。

### `HBCI_EPS1`

> **决定 HBCI 空间的维数。**
>
> * **类型**：`INTEGER`
> * **默认值**：`1000`
> * **可选值**：
>     * $N$
>     * HBCI
>     * $\varepsilon_{1}$
>     * 单位为
>     * $\mu$
>     * E
>     * ${}_{\mathrm{h}}$
> * **建议**：使用默认值，或采用 500 以获得更严格的收敛。

### `IFCI_TUPLE_THRESH`

> **将阈值内的近简并 geminal（孪生函数）收缩为一个体（one body）。**
>
> * **类型**：`INTEGER`
> * **默认值**：`2500`
> * **可选值**：
>     * $n$
>     * 单位为
>     * $\mu$
>     * E
>     * ${}_{\mathrm{h}}$
> * **建议**：使用默认值，除非存在一组高度相关的占据轨道。

### `IFCI_TRIPLES_SCREEN`

> **用于判定一个三体项是否显著的截断阈值（ $\mathcal{C}_{3}$ ）。**
>
> * **类型**：`INTEGER`
> * **默认值**：`1000`
> * **可选值**：
>     * $n$
>     * 其中
>     * $\mathcal{C}_{3}=10^{-\zeta}\times n$
>     * 单位为 E
>     * ${}_{\mathrm{h}}$
> * **建议**：使用默认值，除非希望对给定体系的三重积（triads）采用更宽松（$n$ 更大）或更严格（$n$ 更小）的考虑。设为 0 将计算所有三重积（代价高昂）。

### `IFCI_QUAD_SCREEN`

> **用于判定一个四体项是否显著的截断阈值（ $\mathcal{C}_{4}$ ）。**
>
> * **类型**：`INTEGER`
> * **默认值**：`IFCI_TRIPLES_SCREEN`
> * **可选值**：
>     * $n$
>     * 其中
>     * $\mathcal{C}_{4}=10^{-\zeta}\times n$
>     * 单位为 E
>     * ${}_{\mathrm{h}}$
> * **建议**：与 IFCI_TRIPLES_SCREEN 相同，但需注意 $4$ 体项的计算代价显著更高。

### `IFCI_STATE_ADD`

> **当各态之间存在简并时，为 HBCI 求解器添加额外的态。**
>
> * **类型**：`INTEGER`
> * **默认值**：`10`
> * **可选值**：
>     * $n$
>     * 添加 $n$
>     * mE
>     * ${}_{\mathrm{h}}$
>     * 范围内的态
> * **建议**：使用默认值，除非已知存在简并态。

### `IFCI_PRINT`

> **数值越大，输出信息越多。**
>
> * **类型**：`INTEGER`
> * **默认值**：`2`
> * **可选值**：
>     * 1
>     * 最简输出
>     * 2
>     * 可读输出
>     * 3
>     * 额外输出
>     * 4
>     * 过量输出
>     * 5+
>     * 调试（Bug testing）输出
> * **建议**：推荐 2，1-3 均合适，大于 4 则无必要（请自行斟酌后果）。

### `IFCI_NO_THRESH`

> **在针对各增量（increment）的自然轨道（NO）生成步骤中，等价于 HBCI 的 $\varepsilon_{1}$。**
>
> * **类型**：`INTEGER`
> * **默认值**：`1000`
> * **可选值**：
>     * $n$
>     * 单位为
>     * $\mu$
>     * E
>     * ${}_{\mathrm{h}}$
> * **建议**：设置为与 HBCI_EPS1 相同。

### `IFCI_REF_ITER`

> **使用 HF 或 PP 参考密度。**
>
> * **类型**：`INTEGER`
> * **默认值**：`1`
> * **可选值**：
>     * 0
>     * HF
>     * 1
>     * PP
> * **建议**：使用 0。

### `IFCI_OCC`

> **指定活性占据轨道的数目。**
>
> * **类型**：`INTEGER`
> * **默认值**：`完整价层（Full valence）。`
> * **可选值**：
>     * $n$
>     * 将 $n$
>     * 个轨道纳入活性空间
>     * $-1$
>     * 完整价层
> * **建议**：使用完整价层活性空间。
