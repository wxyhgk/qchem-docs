## 6.13.3 (dT) 与 (fT) 修正

(2026 年 7 月 4 日)

关于以另一种方式引入非迭代 $N^{7}$ 三激发（triples）修正的方法，详见第 [7.9.27](../ch07_excited/sec_SD3.md) 节。这些称为 (dT) 与 (fT) 的方法，其精度与其他三激发修正方法相当。CCSD(dT) 与 CCSD(fT) 分别等价于 Piecuch 及其合作者提出的 CR-CCSD(T)${}_{L}$ 与 CR-CCSD(T)${}_{2}$ 方法。[[1091]](../bib_references/bib.md#bib1136)

!!! note "注意"
    由于违反轨道不变性（orbital invariance），(dT) 修正在某些情况下可能给出虚假（spurious）结果。
    因此不建议使用该方法。
    请改用 (fT) 修正！
