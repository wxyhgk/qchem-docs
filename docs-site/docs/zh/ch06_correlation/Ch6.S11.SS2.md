## 6.11.2 RI-MP3 作业控制

（2026 年 7 月 4 日）

### `MP2_SCALING`

> **对 RI-MP2 相关能贡献进行缩放。**
>
> * **类型**: `INTEGER`
> * **默认值**: `1000000`
> * **可选值**:
>     * $n$: 对应的缩放因子为 $n/10^{6}$
> * **建议**: 使用默认值。

### `MP3_SCALING`

> **对 RI-MP3 相关能贡献进行缩放。**
>
> * **类型**: `INTEGER`
> * **默认值**: `1000000`
> * **可选值**:
>     * $n$: 对应的缩放因子为 $n/10^{6}$
> * **建议**: 使用默认值。
