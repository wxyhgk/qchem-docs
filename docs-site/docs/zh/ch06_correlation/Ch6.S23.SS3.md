## 6.23.3 v2RDM 作业控制

（2026 年 7 月 4 日）

### `RDM_POSITIVITY`

> **指定在 v2RDM 优化中强制执行的 positivity（正性）条件。**
>
> * **类型**: `STRING`
> * **默认值**: `DQG`
> * **选项**:
>     * `DQG,`: 双电子条件
>     * `DQGT1`: 双电子条件加上 T1 部分三电子条件
>     * `DQGT2`: 双电子条件加上 T2 部分三电子条件
>     * `DQGT1T2`: 双电子条件加上 T1 和 T2 部分三电子条件
>     * `DQG3POS`: 双电子条件加上完整的三电子条件
> * **建议**: 若追求高精度，请使用 DQG3POS 或 DQGT2，但对于大活性空间而言此类计算会变得不切实际。对于大活性空间（例如 CAS(n, n) 中 n > 16），请使用 DQG。

### `RDM_CONSTRAIN_SPIN`

> **指示是否强制执行自旋约束。**
>
> * **类型**: `BOOLEAN`
> * **默认值**: `TRUE`
> * **选项**:
>     * `TRUE`: 强制执行自旋约束。
>     * `FALSE`: 不强制执行自旋约束。
> * **建议**: 使用默认值。

### `PDFT_EXCHANGE`

> **指定在 MC-PDFT 计算中使用的交换泛函。**
>
> * **类型**: `STRING`
> * **默认值**: `无默认值`
> * **选项**:
>     * `NAME`: 使用 =
>     * `NAME`: ，其中
>     * `NAME`: 必须是第 5.3.3 节中列出的 LDA 或 GGA 交换泛函之一。该关键字仅在方法设置为 RDM(PDFT) 时生效。
> * **建议**: 一般而言，请参考相关文献以指导选择。

### `PDFT_CORRELATION`

> **指定在 MC-PDFT 计算中使用的关联泛函。**
>
> * **类型**: `STRING`
> * **默认值**: `NONE`
> * **选项**:
>     * `NAME`: 使用 =
>     * `NAME`: ，其中
>     * `NAME`: 是第 5.3.4 节中列出的 LDA 或 GGA 关联泛函之一。该关键字仅在方法设置为 RDM(PDFT) 时生效。
> * **建议**: 一般而言，请参考相关文献以指导选择。

### `RDM_E_CONVERGENCE`

> **原始-对偶（primal-dual）能量差的阈值。**
>
> * **类型**: `INTEGER`
> * **默认值**: `4`
> * **选项**:
>     * $N$: 表示阈值 $10^{-N}$
> * **建议**: 进行梯度计算时应提高（即加大收敛要求）。

### `RDM_EPS_CONVERGENCE`

> **原始约束与对偶约束误差的阈值。**
>
> * **类型**: `INTEGER`
> * **默认值**: `4`
> * **选项**:
>     * $N$: 表示阈值 $10^{-N}$
> * **建议**: 进行梯度计算时应提高（即加大收敛要求）。

### `RDM_MAXITER`

> **BPSDP 求解器中对角化步骤的最大次数。**
>
> * **类型**: `INTEGER`
> * **默认值**: `50000`
> * **选项**:
>     * $N>0$
> * **建议**: 对于难以收敛的计算，应增大该值。

### `RDM_CG_CONVERGENCE`

> **共轭梯度（conjugate gradient）求解器的最小阈值。**
>
> * **类型**: `INTEGER`
> * **默认值**: `12`
> * **选项**:
>     * $N$: 表示阈值 $10^{-N}$
> * **建议**: 应至少为（RDM_EPS_CONVERGENCE + 2）。

### `RDM_CG_MAXITER`

> **BPSDP 算法中每次共轭梯度计算的最大迭代次数。**
>
> * **类型**: `INTEGER`
> * **默认值**: `1000`
> * **选项**:
>     * $N>0$
> * **建议**: 除非出现问题，否则使用默认值。

### `RDM_TAU`

> **BPSDP 求解器中使用的步长参数。**
>
> * **类型**: `INTEGER`
> * **默认值**: `10`
> * **选项**:
>     * $N$: 表示值为 0.1 * $N$
> * **建议**: 对于 $1.0\leq\tau\leq 1.6$，该值应在 10 到 16 之间。

### `RDM_MU_UPDATE_FREQUENCY`

> **更新惩罚参数 $\mu$ 之前所执行的 v2RDM 迭代次数。**
>
> * **类型**: `INTEGER`
> * **默认值**: `200`
> * **选项**:
>     * $N>0$
> * **建议**: 出现收敛问题时可修改。

### `RDM_TPDM_GUESS`

> **RDM（约化密度矩阵）的初始猜测**
>
> * **类型**: `STRING`
> * **默认值**: `HF_GUESS`
> * **选项**:
>     * `HF_GUESS`: 使用 Hartree-Fock 计算得到的 RDM 作为半定规划求解器的初始密度
>     * `RANDOM_GUESS`: 使用随机数作为半定规划求解器的初始密度
> * **建议**: 除非出现收敛问题，否则使用默认值。

### `RDM_DIAGONALIZER`

> **在半定规划（semidefinite programming）内部用于矩阵对角化的算法。**
>
> * **类型**: `INTEGER`
> * **默认值**: `11`
> * **选项**:
>     * `0`: 使用并行 LAPACK 函数 DSYEV
>     * `1`: 使用并行 LAPACK 函数 DSYEVD
>     * `10`: 对串行 LAPACK 函数 DSYEV 进行多次并行调用
>     * `11`: 对串行 LAPACK 函数 DSYEVD 进行多次并行调用
> * **建议**: 使用默认值。在某些情况下（例如低对称性），算法 1 可能更快。

### `RDM_PRINT`

> **控制输出信息的详细程度。**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **选项**:
>     * `0`: 仅输出最少的信息。
>     * `1`: 输出所有迭代的详细信息。
> * **建议**: 使用 1 来分析收敛问题。

### `RDM_ORBOPT_GRADIENT_CONVERGENCE`

> **轨道优化过程中轨道梯度的阈值。**
>
> * **类型**: `INTEGER`
> * **默认值**: `4`
> * **选项**:
>     * $N$: 表示阈值 $10^{-N}$
> * **建议**: 进行梯度计算时应收紧（即加大收敛要求）。

### `RDM_ORBOPT_ENERGY_CONVERGENCE`

> **轨道优化过程中能量收敛的阈值。**
>
> * **类型**: `INTEGER`
> * **默认值**: `8`
> * **选项**:
>     * $N$: 表示阈值 $10^{-N}$
> * **建议**: 进行梯度计算时应收紧（即加大收敛要求）。

### `RDM_ORBOPT_MAXITER`

> **每次调用轨道优化例程时执行轨道优化步骤的最大次数。**
>
> * **类型**: `INTEGER`
> * **默认值**: `20`
> * **选项**:
>     * $N>0$
> * **建议**: 除非出现收敛问题，否则使用默认值。

### `RDM_ORBOPT_FREQUENCY`

> **调用轨道优化例程之前所执行的 v2RDM 迭代次数。**
>
> * **类型**: `INTEGER`
> * **默认值**: `500`
> * **选项**:
>     * $N>0$
> * **建议**: 除非出现收敛问题，否则使用默认值。
