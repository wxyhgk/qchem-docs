## 12.14.2 作业控制变量

（2026 年 7 月 4 日）

通过在 *$rem* 区段中设置 AIFDEM = TRUE 即可请求一次基础的 AIFDEM 计算。
额外的作业控制变量用于决定哪些类型的态被包含在激子位（exciton-site）基中，
以及用于截断式 ([12.80](Ch12.S14.SS1.md#eq:CIS_for_AIFDEM)) 中展开式的 NTO 阈值。
这些变量以及其他若干变量在下文中进行说明。

### `AIFDEM`

> **执行一次 AIFDEM 计算。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * `FALSE`: 不执行 AIFDEM 计算。
>     * `TRUE`: 执行 AIFDEM 计算。
> * **建议**: False

### `AIFDEM_NTOTHRESH`

> **控制激子位基态中保留多少个 NTO。**
>
> * **类型**: `INTEGER`
> * **默认值**: `99`
> * **选项**:
>     * $n$: 保留足够数量的 NTO，以恢复式 ( 12.80 ) 中原始 CIS 或 TDDFT 向量范数的
>     * $n$: %。
> * **建议**: 对于有机分子，$85\%$ 的阈值能在计算时间和精度之间取得良好的平衡。

### `AIFDEM_EMBED_RANGE`

> **指定用于电荷嵌入的 QM 区域大小**
>
> * **类型**: `INTEGER`
> * **默认值**: `FULL_QM`
> * **选项**:
>     * `FULL_QM`: 不进行电荷嵌入。
>     * `0`: 仅将激发片段按 QM 处理。
>     * $n$: 距离激发片段的范围（单位为 Å），在此范围内的其他片段按 QM 处理。
> * **建议**: 取最小阈值零通常既能保持精度，又能显著减少计算时间。

### `AIFDEM_CTSTATES`

> **在 AIFDEM 基中包含类电荷转移（charge-transfer-like）的阳离子/阴离子对态。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * `TRUE`: 包含 CT 态。
>     * `FALSE`: 不包含 CT 态。
> * **建议**: 若需要在基中包含 CT 态，则使用此项。

### `AIFDEM_SINGFIS`

> **在 AIFDEM 基中包含多激子（multi-exciton）态。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * `TRUE`: 包含多激子态。
>     * `FALSE`: 不包含多激子态。
> * **建议**: 若需要在基中包含多激子态，则使用此项。此选项要求在 $rem 区段中同时使用 AIFDEM_SEGSTART 和 AIFDEM_SEGEND。

对于大型体系的计算，可能希望将 AIFDEM 矩阵元的计算拆分为若干批次。用户可以使用以下变量指定某次计算所对应第一个和最后一个矩阵元。

### `AIFDEM_SEGSTART`

> **指示要计算的第一个矩阵元的索引。**
>
> * **类型**: `INTEGER`
> * **默认值**: `NONE`
> * **选项**:
>     * $n$: 待计算分块的第一个矩阵元。
> * **建议**: 需与 AIFDEM_SEGEND 配合使用

### `AIFDEM_SEGEND`

> **指示要计算的最后一个矩阵元的索引。**
>
> * **类型**: `INTEGER`
> * **默认值**: `NONE`
> * **选项**:
>     * $n$: 待计算分块的最后一个矩阵元。
> * **建议**: 需与 AIFDEM_SEGSTART 配合使用

在按批次计算 AIFDEM 矩阵元时，可以先运行一个仅执行片段 SCF 计算的作业，从而避免每个作业都重新运行片段 SCF 计算。这些结果会保存在暂存（scratch）目录中，随后可被后续计算读取。以下变量用于控制此功能。

### `AIFDEM_FRGM_WRITE`

> **仅执行片段 SCF 计算。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * `TRUE`: 仅执行片段 SCF 计算，不计算矩阵元。
>     * `FALSE`: 按其他 $rem 变量的指定执行常规 AIFDEM 计算。
> * **建议**: 无

### `AIFDEM_FRGM_READ`

> **跳过片段 SCF 计算。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * `TRUE`: 跳过片段 SCF 计算，仅计算矩阵元。
>     * `FALSE`: 按其他 $rem 变量的指定执行常规 AIFDEM 计算。
> * **建议**: 需要提前运行一次用于计算片段 SCF 数据的作业。
