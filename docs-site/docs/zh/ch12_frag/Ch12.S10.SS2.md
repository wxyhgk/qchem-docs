## 12.10.2 理论

(July 4, 2026)

XSAPT 的零级哈密顿量取由 XPol 流程定义的碎片 Fock 算符之和，而微扰则是通常的 SAPT 分子间微扰
[式 ([12.56](Ch12.S9.SS1.md#eq:pairwise_perturbation))] 减去包含在 XPol 碎片 Fock 算符中的分子间相互作用。
随后对每一对单体，使用该修正后的微扰结合式 ([12.61](Ch12.S9.SS1.md#eq:SAPT_interaction))
计算标准的 SAPT0 修正（参见第 [12.9](topic_sapt.md) 节）。由此得到二聚体相互作用能 $E_{\mathrm{int}}^{AB}$。XSAPT 的总能量为[[560]](../bib_references/bib.md#bib574)

<a id="eq:XSAPT_total_E"></a>
$$
E_{\rm XSAPT}=\sum_{A}\left(\sum_{a}\Bigl{[}2\,\epsilon_{a}^{A}-\mathbf{c}_{a}^{\dagger}(\mathbf{J}^{A}-\tfrac{1}{2}\mathbf{K}^{A})\mathbf{c}_{a}\Bigr{]}+E_{\mathrm{nuc}}^{A}+\sum_{B>A}E_{\mathrm{int}}^{AB}\right)\;, \tag{12.67}
$$

它等于 XPol 单体能量之和加上成对的 SAPT 修正。在该表达式中，我们消除了 Hartree-Fock 理论中双电子相互作用的重复计数，
实际上是将*碎片内*（intrafragment）微扰处理到一阶。将其推广到用 Kohn-Sham 描述单体的情形非常直接，
从而把 SAPT0(KS) 方法扩展到大于二聚体的团簇体系。

由于零级哈密顿量中包含了多体极化，后续的 SAPT 修正在能量分解分析的意义上就有所减弱。例如，
XSAPT 中的一阶静电修正*并非*总的静电能，因为前者修正的是零级近似静电处理（*即*，静电嵌入）中的误差。
为了恢复 XSAPT 静电项的部分物理意义，可以从 SAPT 中得到的一阶静电能中减去 XPol 嵌入势，
从而得到“修正后的”静电能，实际上就是把零级修正从一阶静电项中移除。色散修正的“污染”可能较小，
因为 XSAPT 对传统 SAPT 微扰的所有修改都是单电子算符，因此成对色散修正与传统 SAPT 对应项的差别
仅体现在分子轨道（MO）受到静电嵌入的微扰上。在解读 XSAPT 计算输出时应牢记这一点，
不过 Lao 和 Herbert[[760]](../bib_references/bib.md#bib793) 随后提出了 XSAPT 的多体能量分解方案，
将传统的 SAPT 能量分解推广到包含两个以上单体的体系。（上述污染问题可以通过成对的
$\delta_{\mathrm{int}}^{\rm HF}$ 修正来规避，即将 XSAPT 结果与基于气相单体的传统 SAPT 进行对比。）

通过在 *$rem* 区段中设置 JOBTYPE = XSAPT 来请求进行 XSAPT 计算。XPol 电荷嵌入的选择由
*$xpol* 输入区段中的 **embed** 和 **charges** 关键字控制；参见第 [12.8](sect_xpol.md) 节以及下面给出的示例。
SAPT 部分的额外作业控制选项在 *$sapt* 输入区段中指定，如第 [12.9](topic_sapt.md) 节所述。
使用 **Q-Chem** 的 XSAPT 代码的研究人员被要求引用文献 [[560]](../bib_references/bib.md#bib574)。
关于该理论的更多讨论可在其他文献中找到。[[621]](../bib_references/bib.md#bib643)

    ```qchem
       H  -2.979488 -0.258829  0.000000
       H  -0.498833  1.107195  0.000000
    -- formic acid
       0  1
       C  1.888896  0.179692  0.000000

       O  1.170435  1.166590  0.000000

    $end
    ```

后一个示例本质上就是传统的 SAPT0（二聚体）计算，只是其零级单体波函数由电荷嵌入的 XPol 计算得到。
下一个示例对应于真正“扩展”的 SAPT 计算，*即*包含两个以上单体的计算。
