## 12.14.3 示例

(July 4, 2026)

对于电荷嵌入的 AIFDEM 计算，需在 *$rem* 区段中设置 XPOL = TRUE，
然后通过 *$xpol* 输入区段选择嵌入电荷的类型，具体说明见第 [12.8](sect_xpol.md) 节，
并在以下示例中进行了演示。

???+ example "示例 12.50: 单线态激发态计算示例，体系为 (H ${}_{2}$ O) ${}_{4}$。使用 XPol 生成带有 ChElPG 电荷的单体波函数，并采用最小 QM 电荷嵌入的激子模型，每个片段包含三个激发态。"
    ```qchem
    $molecule
    0 1
    --H2O 0
       0 1
       O          1.74078        1.59716       -1.49814
       H          2.22908        2.18316       -2.08914
       H          0.88038        2.04726       -1.32684
    --H2O 1
       0 1
       O          1.31998       -1.18934       -1.91734
       H          1.49988       -0.22974       -1.89044
       H          1.69058       -1.52594       -1.07704
    --H2O 2
       0 1
       O         -0.68982        2.59476       -0.72224
       H         -1.14372        3.37086       -1.07364
       H         -1.35592        1.84986       -0.78334
    --H2O 3
       0 1
       O         -1.27512       -1.77394       -1.69524
       H         -0.32252       -1.52884       -1.85604
       H         -1.53992       -2.30454       -2.45644
    $end
    
    $rem
       BASIS                aug-cc-pvdz
       EXCHANGE             HF
       CIS_N_ROOTS          3
       CIS_TRIPLETS         FALSE
       XPOL                 TRUE
       AIFDEM               TRUE
       AIFDEM_EMBED_RANGE   0
       AIFDEM_NTOTHRESH     90
       NTO_PAIRS            1
    $end
    
    $xpol
      embed   charges
      charges CHELPG
    $end
    ```

多激子关键字 AIFDEM_SINGFIS 用于启用多激子态，
即 $|^{1}(\Phi_{\!A}^{\text{T}}\Phi_{\!B}^{\text{T}})\Phi_{\!C}\ldots\rangle$。下面的示例对此进行了说明，
同时展示了如何使用 AIFDEM_SEGSTART 和 AIFDEM_SEGEND 将矩阵元的计算拆分为多个区段。
对于多激子计算而言，这种拆分是必需的。

???+ example "示例 12.51: 基组中包含多激子态的 AIFDEM 示例。"
    ```qchem
    $rem
    BASIS         aug-cc-pvdz
    EXCHANGE      HF
    CIS_N_ROOTS   3
    CIS_SINGLETS  TRUE
    CIS_TRIPLETS  TRUE
    XPOL          TRUE
    AIFDEM        TRUE
    AIFDEM_EMBED_RANGE 0
    AIFDEM_NTOTHRESH   90
    NTO_PAIRS          1
    AIFDEM_SINGFIS     TRUE
    AIFDEM_CTSTATES    TRUE
    SCF_PRINT_FRGM     true
    AIFDEM_SEGSTART    1
    AIFDEM_SEGEND      2
    $end
    
    $molecule
    0 1
    -- H2O 0
    0 1
    O 1.74078 1.59716 -1.49814
    H 2.22908 2.18316 -2.08914
    H 0.88038 2.04726 -1.32684
    -- H2O 1
    0 1
    O 1.31998 -1.18934 -1.91734
    H 1.49988 -0.22974 -1.89044
    H 1.69058 -1.52594 -1.07704
    $end
    
    $xpol
    embed   charges
    charges chelpg
    $end
    ```

若要计算哈密顿矩阵与重叠矩阵的 AIFDEM 导数 $\mathbf{H}^{[x]}$ 和 $\mathbf{S}^{[x]}$，
用户应提交标准的 AIFDEM 作业，并额外设置 CIS_STATE_DERIV = 1。目前，AIFDEM
导数尚不支持电荷嵌入，因此这些作业中必须省略关键字
AIFDEM_EMBED_RANGE，这也意味着片段无法使用 XPol 波函数。
此外，每个片段仅支持一个激发态，因此必须设置 CIS_N_ROOTS = 1。

AIFDEM 哈密顿矩阵与重叠矩阵的导数会输出到输出文件中，
按属于同一个原子的三个笛卡尔坐标为一组进行排列。为便于使用，
正交化后的 AIFDEM 哈密顿矩阵元素会保存在临时目录 `$QCSCRATCH/aifdem_deriv` 中。
其组织方式为：每个唯一矩阵元素的导数按原子笛卡尔坐标的顺序
分别存储于独立的文件中。这些文件可用于在外部计算激子/声子耦合常数。

???+ example "示例 12.52: 氦原子链的基础 AIFDEM 导数计算。"
    ```qchem
    $molecule
    0 1
    --frgm 0
    0 1
    He    0.000   0.000   0.000
    He    0.000   0.000   1.400
    --frgm 1
    0 1
    He    0.000   0.000   2.800
    He    0.000   0.000   4.200
    $end
    
    $rem
       BASIS             =  cc-pvdz
       EXCHANGE          =  hf
       AIFDEM            =  true
       CIS_N_ROOTS       =  1
       CIS_SINGLETS      =  true
       CIS_TRIPLETS      =  false
       CIS_STATE_DERIV   =  1
       NTO_PAIRS         =  1
       MEM_TOTAL         =  1000
       MEM_STATIC        =  1000
       MAX_CIS_CYCLES    =  200
       MAX_SCF_CYCLES    =  200
       THRESH            =  10
       AIFDEM_NTOTHRESH  =  100
    $end
    ```
