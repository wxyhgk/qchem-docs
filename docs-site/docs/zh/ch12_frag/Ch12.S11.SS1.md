## 12.11.1 概述

（2026 年 7 月 4 日）

文献中存在许多将分子间相互作用能的量子化学计算分解为具有物理意义组分的方法，但电荷转移（charge-transfer, CT）贡献的定义已被证明尤其难以令人满意地界定，并且通常强烈依赖于基组（basis set）的选择，[[1180]](../bib_references/bib.md#bib1233)
 因为当基组趋于完备时，单体 $A$ 上的虚拟轨道开始显著地延伸到单体 $B$ 上，于是极化（localized 于 $A$ 的激发，由 $B$ 的扰动影响所引入）与 CT（从 $A$ 到 $B$ 的激发）之间的界限变得模糊。[[763]](../bib_references/bib.md#bib797)
 这种歧义使得依赖于轨道的 CT 定义高度取决于原子轨道基组的选择。另一方面，约束密度泛函理论（constrained density functional theory, cDFT，第 [5.11](../ch05_dft/topic_cdft.md) 节），[[659]](../bib_references/bib.md#bib683)
 其可以基于“预分子”（promolecule）密度定义一个无 CT 的参考态，从而给出一个几乎不依赖于基组、并且在简单情形下符合化学直觉的 CT 定义。[[763]](../bib_references/bib.md#bib797)

对于分子间相互作用，cDFT 对 CT 的定义可以与基于对称适应微扰理论（symmetry-adapted perturbation theory, SAPT，第 [12.9](topic_sapt.md) 节）的相互作用能其余组分（静电作用、诱导作用、Pauli 排斥以及范德华相互作用）的定义相结合。在传统 SAPT 中，CT 相互作用能包含在诱导能（也称为极化能）之内，因此诱导能本身高度依赖于基组。然而，利用 cDFT 定义 CT 组分并将其从 SAPT 诱导能中扣除后，CT 与剩余的诱导能都在很大程度上与基组无关。[[763]](../bib_references/bib.md#bib797)
 因此 SAPT/cDFT 提供了一种稳定且具有物理依据的能量分解。

尽管 cDFT 对 CT 的定义只表现出非常微弱的基组依赖性，但其定量细节确实取决于 cDFT 中的电荷约束相对于碎片布居（fragment populations）如何定义（第 [5.11](../ch05_dft/topic_cdft.md) 节）。对于 SAPT/cDFT，原子的 Becke[[94]](../bib_references/bib.md#bib73)
 和基于碎片的 Hirshfeld[[1160]](../bib_references/bib.md#bib1214)
（FBH）电荷划分方法均可用。前者涉及构造原子胞（atomic cell）函数，其本质上是以每个原子为中心的平滑化 Voronoi 多面体。一个切换函数（switching function）定义了原子 $a$ 的原子胞，该函数在原子 $a$ 的核附近从 $\approx 1$ 迅速下降到在其他任何核附近的 $\approx 0$。Becke[[94]](../bib_references/bib.md#bib73)
 定义了作为切换函数乘积的原子胞函数 $P_{a}(\textbf{r})$，通过对 $a\in A$ 的原子求和，可以用来定义单体 $A$ 的 cDFT 积分权重：

<a id="eq:becky_weights"></a>
$$
w^{\rm Becke}_{A}(\textbf{r})=\frac{\sum_{a\in A}P_{a}(\textbf{r})}{\sum_{b}P_{b}(\textbf{r})}\;. \tag{12.70}
$$

分母中的求和遍历两个单体 $A$ 和 $B$ 中的所有原子。然而，Becke 布居根植于一种定义略显任意的拓扑结构，部分基于假设的原子半径；而 FBH 划分则从孤立单体密度 $\widetilde{\rho}_{A}(\mathbf{r})$ 和 $\widetilde{\rho}_{B}(\mathbf{r})$ 中获得其物理意义。单体 $A$ 的 cDFT 权重函数为[[1160]](../bib_references/bib.md#bib1214)

<a id="eq:fbh_weights"></a>
$$
w_{A}^{\rm FBH}(\mathbf{r})=\frac{\widetilde{\rho}_{A}(\mathbf{r})}{\widetilde{\rho}_{A}(\mathbf{r})+\widetilde{\rho}_{B}(\mathbf{r})}\;, \tag{12.71}
$$

这与用于定义原子 Hirshfeld 布居（第 [10.2.2](../ch10_properties/subsec_pop_anal.md) 节）的“stockholder”格式相同，但此处应用于整个单体。用 cDFT 的术语来说，该表达式中的分母被称为二聚体 $A+B$ 的*预分子*（promolecule）密度。为了设置分子碎片约束，只需保留 *$cdft* 输入节中的现有语法（如第 [5.11](../ch05_dft/topic_cdft.md) 节所述），并指定给定分子碎片内的所有原子即可。

由于 Becke 布居根植于一种部分基于假设原子半径的拓扑方案，强烈建议当 CDFT_POP 设置为 BECKE 时，将 rem 变量 BECKE_SHIFT 设置为使用经验导出的 Bragg-Slater 半径[[1268]](../bib_references/bib.md#bib1321)
 或基于普适密度判据（universal density criterion）*从头算*（*ab initio*）导出的半径（详见第 [10.2.2](../ch10_properties/subsec_pop_anal.md) 节）。
使用 UNSHIFTED（默认）方案可能导致极不物理的结果，包括电荷转移矢量指向相反方向。

要执行 SAPT/cDFT 能量分解分析，用户必须请求一次常规 SAPT 或 XSAPT 计算（JOBTYPE = XSAPT），并另外在 *$sapt* 输入节中指定关键字 **CDFT-EDA**。
使用本方法的用户被要求引用文献 [[763]](../bib_references/bib.md#bib797)。

### `CDFT-EDA`

> **请求基于 SAPT/cDFT 的能量分解分析。输入段：$sapt**
>
> * **类型**: `None`
> * **默认值**: `未指定`
> * **选项**:
>     * 若设置了该关键字,则执行分析。
> * **建议**: 无

如下例所示,还需要一个 *$cdft* 输入段,用于为计算的 cDFT 部分指定单体的电荷与自旋。可以设置 CDFT_POP 变量(在 *$rem* 段中),以指定 cDFT 的电子计数机制。选项 Either 为使用原子 Becke 布居数(与传统 cDFT 计算[[659]](../bib_references/bib.md#bib683) 一致),并对每个单体求和;或者使用基于片段的 Hirshfeld 划分方法,该方法利用单体的前分子(pro-molecule)密度来获得整分子版本的 Hirshfeld 原子电荷。

CDFT_POP

### `CDFT_POP`

> **设置 SAPT/cDFT 中 cDFT 的电荷划分方案**
>
> * **类型**: `STRING`
> * **默认值**: `FBH`
> * **选项**:
>     * FBH
>     * 基于片段的 Hirshfeld 划分(Fragment-Based Hirshfeld partitioning)
>     * BECKE
>     * 原子 Becke 划分(Atomic Becke partitioning)
> * **建议**: 无

???+ example "示例 12.45: 使用 AO-SAPT+ ai D3/cDFT 对水二聚体进行能量分解分析。需要 $cdft 输入段来为计算的 cDFT 部分指定单体的电荷与自旋。"
    ```qchem
    $molecule
    0 1
    --
       0 1
       O   -0.702196054  -0.056060256   0.009942262
       H   -1.022193224   0.846775782  -0.011488714
       H    0.257521062   0.042121496   0.005218999
    --
    0 1
       O    2.220871067   0.026716792   0.000620476
       H    2.597492682  -0.411663274   0.766744858
       H    2.593135384  -0.449496183  -0.744782026
    $end
    
    $rem
       JOBTYPE            XSAPT
       EXCHANGE           gen
       BASIS              aug-cc-pvdz
       LRC_DFT            true
       CDFT_POP           FBH ! Fragment-Based Hirshfeld charge partitioning
    $end
    
    $xpol
      embed     none
      print     3
      dft-lrc
    $end
    
    $sapt
      algorithm     AO
      Dispersion    aiD3
      order         2
      basis         dimer
      cdft-eda
      print         3
    $end
    
    $xc_functional
       x   wPBE   1.0
       c    PBE   1.0
    $end
    
    $lrc_omega
       500
       500
    $end
    
    $cdft
       0
       1 1 3
       0
       1 1 3 s
    $end
    ```
