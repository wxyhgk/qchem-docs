## 12.11.1 概述

（2026 年 7 月 4 日）

文献中存在许多将分子间相互作用能的量子化学计算分解为具有物理意义各分量的方案，但电荷转移（Charge Transfer, CT）分量的定义一直难以给出令人满意的界定，且通常强烈依赖于基组（Basis Set）的选择。[[1180]](../bib_references/bib.md#bib1233) 这是因为随着基组趋于完备，单体 $A$ 的虚轨道开始显著延伸至单体 $B$ 上，从而使极化（局域在 $A$ 上的激发，由 $B$ 的微扰影响引入）与 CT（从 $A$ 到 $B$ 的激发）之间的区别变得模糊。[[763]](../bib_references/bib.md#bib797) 这种模糊性使得依赖轨道的 CT 定义高度依赖于原子轨道基组的选择。另一方面，约束密度泛函理论（constrained Density Functional Theory, cDFT，见第 [5.11](../ch05_dft/topic_cdft.md) 节）[[659]](../bib_references/bib.md#bib683) 通过基于"准分子"（promolecule）密度定义一个无 CT 参考态，提供了一种几乎不依赖基组、并且在简单情形下符合化学直觉的 CT 定义。[[763]](../bib_references/bib.md#bib797)

对于分子间相互作用，cDFT 的 CT 定义可以与基于对称匹配微扰理论（Symmetry-Adapted Perturbation Theory, SAPT，见第 [12.9](topic_sapt.md) 节）的相互作用能其余分量（静电作用、诱导作用、Pauli 排斥以及 van der Waals 相互作用）的定义相结合。在传统 SAPT 中，CT 相互作用能包含在诱导能（也称极化能）之内，因此诱导能本身也高度依赖于基组。然而，利用 cDFT 定义 CT 分量，并将其从 SAPT 诱导能中扣除后，CT 能与剩余的诱导能都基本上不依赖基组。[[763]](../bib_references/bib.md#bib797) 因此，SAPT/cDFT 提供了一种稳定且具有物理动机的能量分解方案。

虽然 cDFT 的 CT 定义仅表现出非常温和的基组依赖性，但其定量细节确实取决于 cDFT 中的电荷约束如何相对于片段布居来定义（见第 [5.11](../ch05_dft/topic_cdft.md) 节）。对于 SAPT/cDFT，可用的电荷分割方法包括原子 Becke 方法[[94]](../bib_references/bib.md#bib73) 和基于片段的 Hirshfeld（Fragment-Based Hirshfeld, FBH）方法[[1160]](../bib_references/bib.md#bib1214)。前者需要构建原子胞函数，这些函数实质上是以每个原子为中心的平滑 Voronoi 多面体。切换函数定义原子 $a$ 的原子胞，其在原子 $a$ 核附近取值 $\approx 1$，而在任何其他核附近迅速降为 $\approx 0$。Becke[[94]](../bib_references/bib.md#bib73) 定义的原子胞函数 $P_{a}(\textbf{r})$ 是切换函数的乘积，通过对原子 $a\in A$ 求和即可用于定义单体 $A$ 的 cDFT 积分权重：

<a id="eq:becky_weights"></a>

$$
w^{\rm Becke}_{A}(\textbf{r})=\frac{\sum_{a\in A}P_{a}(\textbf{r})}{\sum_{b}P_{b}(\textbf{r})}\;. \tag{12.70}
$$

分母中的求和遍及两个单体 $A$ 和 $B$ 中的所有原子。然而，Becke 布居植根于一种某种程度上 arbitrarily 定义的拓扑方案（部分基于假定的原子半径），而 FBH 分割则从孤立单体密度 $\widetilde{\rho}_{A}(\mathbf{r})$ 和 $\widetilde{\rho}_{B}(\mathbf{r})$ 中汲取物理意义。单体 $A$ 的 cDFT 权重函数为[[1160]](../bib_references/bib.md#bib1214)

<a id="eq:fbh_weights"></a>

$$
w_{A}^{\rm FBH}(\mathbf{r})=\frac{\widetilde{\rho}_{A}(\mathbf{r})}{\widetilde{\rho}_{A}(\mathbf{r})+\widetilde{\rho}_{B}(\mathbf{r})}\;, \tag{12.71}
$$

这与用于定义原子 Hirshfeld 布居的"股东"（stockholder）方案相同（见第 [10.2.2](../ch10_properties/subsec_pop_anal.md) 节），只是此处应用于整个单体。用 cDFT 的语言来说，该表达式中的分母应称为二聚体 $A+B$ 的*准分子*（promolecule）密度。要设置分子片段约束，只需保留 *$cdft* 输入段中现有的语法（如第 [5.11](../ch05_dft/topic_cdft.md) 节所述），并指定给定分子片段内的所有原子。

由于 Becke 布居植根于一种部分基于假定原子半径的拓扑方案，因此强烈建议：若 CDFT_POP 设为 BECKE，则 rem 变量 BECKE_SHIFT 应设置为使用经验推导的 Bragg-Slater 半径[[1268]](../bib_references/bib.md#bib1321)，或基于普适密度判据的 *ab initio* 推导半径[[1034]](../bib_references/bib.md#bib1077)（更多细节见第 [10.2.2](../ch10_properties/subsec_pop_anal.md) 节）。使用 UNSHIFTED（默认）方案可能导致严重非物理的结果，包括电荷转移矢量方向相反的情况。

要执行 SAPT/cDFT 能量分解分析，用户必须请求一次常规的 SAPT 或 XSAPT 计算（JOBTYPE = XSAPT），并在 *$sapt* 输入段中额外指定关键字 **CDFT-EDA**。使用此方法的用户被要求引用文献 [[763]](../bib_references/bib.md#bib797)。

### `CDFT-EDA`

> **请求进行基于 SAPT/cDFT 的能量分解分析。输入部分：$sapt**
>
> * **类型**： `None`
> * **默认值**： `Not specified`
> * **选项**：
>     * 设置该关键字即执行分析。
> * **建议**： 无

如下方示例所示，还需要一个 *$cdft* 输入部分，用于为计算中的 cDFT 部分指定各单体的电荷和自旋。
可以设置 CDFT_POP 变量（在 *$rem* 部分中），以指定 cDFT 的电子计数机制。可选方案为：使用原子 Becke 布居数（Becke populations，如传统 cDFT 计算中所采用的[[659]](../bib_references/bib.md#bib683)
），并对每个单体求和；或者使用基于片段的 Hirshfeld 划分（Hirshfeld partitioning），其中利用各单体的原分子（promolecule）密度来获得整分子版本的 Hirshfeld 原子电荷。

### `CDFT_POP`

> **设置 SAPT/cDFT 中 cDFT 的电荷划分方案**
>
> * **类型**： `STRING`
> * **默认值**： `FBH`
> * **选项**：
>     * FBH
>     * 基于片段的 Hirshfeld 划分（Fragment-Based Hirshfeld partitioning）
>     * BECKE
>     * 原子 Becke 划分（Atomic Becke partitioning）
> * **建议**： 无

???+ example "示例 12.45: 使用 AO-SAPT+ ai D3/cDFT 对水二聚体进行能量分解分析。计算中的 cDFT 部分需要 $cdft 输入部分来指定各单体的电荷和自旋。"
    ```qchem
    $molecule
    0 1
    --
       0 1
       O   -0.702196054  -0.056060256   0.009942262
       H   -1.022193224   0.846775782  -0.011488714
       H    0.257521062   0.042121496   0.005218999
    --
    0 1
       O    2.220871067   0.026716792   0.000620476
       H    2.597492682  -0.411663274   0.766744858
       H    2.593135384  -0.449496183  -0.744782026
    $end
    
    $rem
       JOBTYPE            XSAPT
       EXCHANGE           gen
       BASIS              aug-cc-pvdz
       LRC_DFT            true
       CDFT_POP           FBH ! Fragment-Based Hirshfeld charge partitioning
    $end
    
    $xpol
      embed     none
      print     3
      dft-lrc
    $end
    
    $sapt
      algorithm     AO
      Dispersion    aiD3
      order         2
      basis         dimer
      cdft-eda
      print         3
    $end
    
    $xc_functional
       x   wPBE   1.0
       c    PBE   1.0
    $end
    
    $lrc_omega
       500
       500
    $end
    
    $cdft
       0
       1 1 3
       0
       1 1 3 s
    $end
    ```
