## 12.13.2 作业控制

（2026 年 7 月 4 日）

若要执行 GMBE(1) 计算，请在 *$rem* 部分设置 GMBE_INT =
TRUE。应用于各个片段（fragments）的理论级别将与 *$rem* 部分中指定的方法相对应。使用 **Q-Chem** 的 GMBE 实现的研究人员被要求引用文献 [[70]](../bib_references/bib.md#bib55)
 和 [[1169]](../bib_references/bib.md#bib1222)
。

以下关键字用于控制 **Q-Chem** 中的 GMBE 计算。它们应在输入文件的 *$rem* 部分中指定。

### `GMBE_INT`

> **执行 GMBE 计算。**
>
> * **类型**: `BOOLEAN`
> * **默认值**: `FALSE`
> * **选项**:
>     * `TRUE`: 执行 GMBE。
>     * `FALSE`: 不执行 GMBE。
> * **建议**: 无（NONE）

### `GMBE_METHOD`

> **指定执行基于能量的 GMBE（GMBE-EB）还是基于密度矩阵的 GMBE（GMBE-DM）。**
>
> * **类型**: `INTEGER`
> * **默认值**: `1`
> * **选项**:
>     * `1`: 执行 GMBE-EB。
>     * `2`: 执行 GMBE-DM。
> * **建议**: 无（NONE）

### `GMBE_ALGO`

> **指定用于确定原始片段（primitive fragments）的截断距离判据。**
>
> * **类型**: `INTEGER`
> * **默认值**: `1`
> * **选项**:
>     * `1`: 最小距离（Minimum distance）
>     * `2`: 重原子距离（Heavy-atoms distance）
> * **建议**: 无（NONE）

### `GMBE_PRIMARY`

> **指定用于确定原始片段的主截断距离。GMBE_PRIMARY 的输入值为期望的截断距离（单位为 Å）乘以 1000。例如，若要使用 2.00 Å 的截断距离，则将 GMBE_PRIMARY 设置为 2000。同理，若 GMBE_PRIMARY = 3500，则截断距离为 3.5 Å。**
>
> * **类型**: `INTEGER`
> * **默认值**: `3000`
> * **选项**:
>     * 期望的截断值为
>     * $n$: = 1000 $d$，其中 $d$ 为以 Å 为单位的截断距离。
> * **建议**: 无（NONE）

### `GMBE_MAX_PRIM_CARD`

> **设置原始片段的最大基数（cardinality）。**
>
> * **类型**: `INTEGER`
> * **默认值**: `5`
> * **选项**:
>     * $n$: 表示原始片段的最大基数。
> * **建议**: 无（NONE）

### `MBEDM_PURE`

> **对 GMBE 密度矩阵执行 McWeeny 纯化处理 936 McWeeny R. Rev. Mod. Phys. (1960) , 32 , pp. 335 . 链接。**
>
> * **类型**: `BOOLEAN`
> * **默认值**: `FALSE`
> * **选项**:
>     * `TRUE`: 对 GMBE 密度矩阵执行 McWeeny 纯化处理。
>     * `FALSE`: 不对 GMBE 密度矩阵执行 McWeeny 纯化处理。
> * **建议**: 无（NONE）

### `GMBE_DM_GUESS_ONLY`

> **直接使用 GMBE-DM 密度矩阵计算体系的总能量。启用此选项将跳过自洽场（SCF）迭代，从而避免进一步收敛到超体系（supersystem）结果。**
>
> * **类型**: `BOOLEAN`
> * **默认值**: `FALSE`
> * **选项**:
>     * `TRUE`: 不执行 SCF 迭代，直接使用 GMBE-DM 密度矩阵计算体系的总能量。
>     * `FALSE`: 以 GMBE-DM 密度矩阵作为初始猜测执行 SCF 迭代。
> * **建议**: 无（NONE）

### `GMBE_PRINT_LEVEL`

> **控制输出文件中打印的详细程度**
>
> * **类型**: `INTEGER`
> * **默认值**: `1`
> * **选项**:
>     * `1`: 最小输出
>     * `2`: 详细输出
> * **建议**: 无（NONE）

    SCF_CONVERGENCE    7
    MAX_SCF_CYCLES     200
