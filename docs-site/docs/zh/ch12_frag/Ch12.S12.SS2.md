## 12.12.2 作业控制

(July 4, 2026)

MBE($n$) 计算通过在 *$rem* 区段中设置 MANY_BODY_INT =
TRUE 来请求。用于片段（fragments）的理论级别为 *$rem* 区段中
指定的任意级别。使用 **Q-Chem** 的 MBE 代码的研究人员被要求引用
文献 [[1173]](../bib_references/bib.md#bib1226)
。此外，对于 MBCP($n$) 方法，请引用
文献 [[1171]](../bib_references/bib.md#bib1223)
。

MBE($n$) 计算通过在 *$rem* 区段中设置 MANY_BODY_INT = TRUE
来请求。用于片段的理论级别为 *$rem* 区段中指定的任意级别。
使用 **Q-Chem** 的 MBE 代码的研究人员被要求引用文献 [[1173]](../bib_references/bib.md#bib1226)
。
此外，对于 MBCP($n$) 方法，请引用文献 [[1171]](../bib_references/bib.md#bib1223)
。

### `MANY_BODY_INT`

> **执行 MBE 计算。**
>
> * **类型**: `BOOLEAN`
> * **默认值**: `FALSE`
> * **选项**:
>     * `TRUE`: 执行 MBE 计算。
>     * `FALSE`: 不执行 MBE 计算。
> * **建议**: NONE

其他 MBE 专用选项，例如展开的阶数 ($n$)，
在 *$mbe* 输入区段中指定，如下文所述。

### `Order`

> **指定多体展开（many-body expansion）的阶数。INPUT SECTION: $mbe**
>
> * **类型**: `INTEGER`
> * **默认值**: `None`
> * **选项**:
>     * $n$: 执行 MBE(
>     * $n$: ) 计算。
> * **建议**: 可选阶数为 $n\leq 5$。

### `Embed`

> **指定 EE-MBE( $n$ ) 的嵌入方法。INPUT SECTION: $mbe**
>
> * **类型**: `STRING`
> * **默认值**: `None`
> * **选项**:
>     * `None`: 不使用嵌入。
>     * `Charges`: 使用原子点电荷。
>     * `Density`: 使用单体（monomer）密度的完全库仑嵌入（Coulomb embedding）。
> * **建议**: 使用原子点电荷需要一个 $mbe_charges 区段来指定电荷。

**Q-Chem** 对使用原子点电荷的 EE-MBE($n$) 的实现设计为配合
*$mbe_charges* 输入区段使用，以指定固定的嵌入电荷。
（使用这些电荷的目的是通过捕捉多体极化效应来加速 MBE 的收敛，
从而使高阶 $n$ 体项变小，不过即使使用了嵌入电荷，
三体和四体项仍不可忽略。[[1174]](../bib_references/bib.md#bib1227)
）
*$mbe_charges* 区段的格式只是一个电荷列表，其顺序与
*$molecule* 区段中原子的顺序保持一致。下面给出一个示例。

多体 Counterpoise 校正（many-body counterpoise corrections）通过在
*$mbe* 输入区段中的两个关键字来请求：**BSSE_Type** 和 **BSSE_Order**。
这两个关键字仅实现到 $n=3$，因为 $n=2$ 项的贡献占绝大部分。[[846]](../bib_references/bib.md#bib881)

### `BSSE_Order`

> **执行 MBCP( $n$ ) 或 VMFC( $n$ ) 类型的多体 Counterpoise 校正。INPUT SECTION: $mbe**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **选项**:
>     * `0`: 不执行 Counterpoise 校正。
>     * $n$: 执行在阶数
>     * $n$: 处截断的 Counterpoise 校正。
> * **建议**: 可选阶数为 $n\leq 3$。使用关键字 BSSE_Type 在 MBCP 和 VMFC 之间选择。

### `BSSE_Type`

> **选择多体 Counterpoise 校正的类型，MBCP( $n)$ 或 VMFC( $n$ )。INPUT SECTION: $mbe**
>
> * **类型**: `STRING`
> * **默认值**: `MBCP`
> * **选项**:
>     * `MBCP`: 使用 MBCP(
>     * $n$: )。
>     * `VMFC`: 使用 VMFC(
>     * $n$: )。
> * **建议**: 两种方法在 $n=2$ 时等价，但在 $n\geq 3$ 时不同。MBCP( $n$ ) 包含的项数更少，但与形式上更完备的 VMFC( $n$ ) 方法相比，通常能提供相当的结果。

    ```qchem
       O -1.126149 -1.748387 -0.423240

    --
       0 1
       O -0.254210 1.611495 -1.293845
       H -1.001520 1.163510 -1.690129
       H -0.153399 2.411746 -1.809248
    --
       0 1
       O 1.694541 -0.226287 1.705739
       H 0.785920 0.073487 1.677909
       H 2.047134 0.150917 2.511706
    --
       0 1
       O -0.864533 0.522472 1.218817
       H -0.694120 1.093542 0.469789
       H -1.131418 -0.310426 0.829702

    $rem
    point_group_symmetry False

       BASIS             cc-pVDZ

    ```
