## 12.9.2 SAPT 计算的任务控制

（2026 年 7 月 4 日）

**Q-Chem** 对 SAPT0 的实现从一开始就被设计为对 XPol 计算的校正项，由此得到第 [12.10](sect_XSAPT.md) 节所描述的 "XSAPT" 方法。因此，即便是传统的 SAPT0 计算，也是通过设置 JOBTYPE = XSAPT 来请求的。不过，XSAPT 计算基于单体的 XPol 波函数，能够捕捉由两个以上单体组成的体系中的多体极化效应（见第 [12.10](sect_XSAPT.md) 节），而传统的 SAPT 计算则取而代之基于气相（gas-phase）单体波函数。这可以通过关闭 XPol 电荷嵌入（charge embedding）来实现，*即*在第 [12.8](sect_xpol.md) 节引入的 *$xpol* 段中设置 **embed** = **none**。

能量各分量会在 SAPT 任务结束时分别打印。若 EXCHANGE = HF，则关闭 XPol 嵌入的 XSAPT 计算对应于一次 SAPT0 计算。或者，如果在 *$rem* 段中请求了密度泛函理论（Density Functional Theory, DFT）层面的方法，则 JOBTYPE = XSAPT 将执行一次 SAPT(KS) 计算，*即*基于单体 Kohn-Sham 描述的计算。

!!! note "注意"
    (1) 当使用投影（伪正则化，pseudocanonicalized）基组时，SAPT(KS) 计算尚不支持meta-GGA 泛函。使用单体基组或二聚体基组时，SAPT(KS) 计算可以配合 meta-GGA 泛函进行。
    (2) 闭壳层与开壳层（非限制型，unrestricted）SAPT(KS) 计算均可用。
    (3) SAPT(KS) *不支持*冻结轨道（frozen orbitals）。
    (4) 支持带 PCM 边界条件的 SAPT 计算。


SAPT 计算的其余任务控制选项通过 *$sapt* 输入段中的各关键字来指定，详见下文。使用 **Q-Chem** 的 SAPT 代码的研究人员被要求引用文献 [[621]](../bib_references/bib.md#bib643)。

### `Algorithm`

> **指定所使用的 SAPT 算法。输入段：$sapt**
>
> * **类型**：`STRING`
> * **默认值**：`MO`
> * **可选值**：
>     * MO
>     * 传统的基于分子轨道（molecular orbital）的算法
>     * RI-MO
>     * 采用分辨恒等（resolution-of-identity, RI）近似、基于分子轨道的算法
>     * AO
>     * 基于原子轨道（atomic orbital）的算法。
> * **建议**：标准的基于分子轨道的算法对应于式 ( 12.65 ) 的类似 MP2 的实现，而 RI-MO 算法对应于类似 RI-MP2 的实现。只要辅助基组（auxiliary basis set）与主基组相匹配，RI 实现通常要快得多，且引入的误差可以忽略不计（与标准实现相比）。（辅助基组必须使用 $rem 段中的 AUX_BASIS 指定。）基于原子轨道（AO）的算法并不实现式 ( 12.65 )，仅 intended 供 XSAPT(KS)+ *ai*D 计算使用；见第 12.10.3 节。

### `Exchange`

> **指定如何计算一阶交换（first-order exchange）相互作用。输入段：$sapt**
>
> * **类型**：`STRING`
> * **默认值**：`S_Squared`
> * **可选值**：
>     * S_Squared
>     * 使用单交换（single-exchange）（"
>     * $S^{2}$
>     * "）近似。
>     * S_Inverse
>     * 计算精确的一阶交换。
> * **建议**：除可能在极短的分子间距离处外，单交换近似预计是足够精确的，且计算起来稍快一些。

### `Basis`

> **控制用于计算 SAPT 校正项的基组。输入段：$sapt**
>
> * **类型**：`STRING`
> * **默认值**：`monomer`
> * **可选值**：
>     * monomer
>     * 使用以单体为中心的基组（monomer-centered basis set, MCBS）。
>     * dimer
>     * 使用以二聚体为中心的基组（dimer-centered basis set, DCBS）。
>     * projected
>     * 使用投影（伪正则化）基组。
> * **建议**：在传统 SAPT 中，DCBS（其中单体波函数使用二聚体基组迭代至收敛）是首选方案，尽管它比 MCBS（单体波函数仅使用单体基组）代价更高。在 XPol 电荷嵌入下，DCBS 没有明确定义，因此不可用。投影基组是传统 SAPT 计算中对 DCBS 的一种高效近似，621 Jacobson L. D., Herbert J. M. J. Chem. Phys. (2011) , 134 , pp. 094118 . Link，并且可用于 XPol 嵌入。

### `CPHF`

> **请求将二阶校正项 $E_{\mathrm{ind}}^{(2)}$ 与 $E_{\mathrm{exch\mbox{-}ind}}^{(2)}$ 替换为其无穷阶 "响应（response）" 对应项 $E_{\mathrm{ind,resp}}^{(2)}$ 与 $E_{\mathrm{exch\mbox{-}ind,resp}}^{(2)}$ 。输入段：$sapt**
>
> * **类型**：`None`
> * **默认值**：`Not specified`
> * **可选值**：
>     * 若给出该关键字，则计算响应量（response quantities）。
> * **建议**：计算响应校正项需要对每一对单体求解耦合微扰 HF（CPHF）方程，代价 somewhat 昂贵，但可能提高精度，尤其是当单体具有极性且诱导（induction）贡献较大时。

### `DSCF`

> **请求计算 $\delta E_{\mathrm{int}}^{\rm HF}$ 修正 输入段：$sapt**
>
> * **类型**: `None`
> * **默认值**: `未指定`
> * **选项**:
>     * 若: 存在该关键字， 则计算 $\delta E_{\mathrm{int}}^{\rm HF}$ 修正。
> * **建议**: 计算 $\delta E_{\mathrm{int}}^{\rm HF}$ 需要对整个（超）体系进行一次 SCF 计算。在 SAPT0 计算的语境下，该修正本质上给出的是相互作用能的“Hartree-Fock 加色散（Hartree-Fock plus dispersion）”估计。

### `Print`

> **指定 XPol 程序的输出详细程度。 输入段：$sapt**
>
> * **类型**: `INTEGER`
> * **默认值**: `1`
> * **选项**:
>     * $n$: 期望的输出级别
> * **建议**: 数值越大，输出的附加信息越多

    ```qchem
      algorithm   ri-mo
      basis       dimer
    $end
    ```
