## 12.5.2 Roothaan 步修正与 FRAGMO 初始猜测

（2026 年 7 月 4 日）

对于片段之间存在显著电荷转移（charge-transfer）的体系（*e.g.*，水团簇中的氢键结合能），局域投影 SCF（Locally-projected SCF）无法定量复现完整 SCF 的分子间相互作用能。若将局域投影 SCF-MI 迭代方案与电荷转移微扰修正相结合，则可在分子间结合能上获得良好的精度。[[683]](../bib_references/bib.md#bib705)
为了考虑电荷转移效应，在局域投影 SCF 方程收敛之后，需对整个 Fock 矩阵执行一次对角化，并将最终能量计算为对局域投影 SCF 能量的无穷阶微扰修正。这一流程被称为单 Roothaan 步（Roothaan-step, RS）修正。[[683]](../bib_references/bib.md#bib705)
当 FRGM_LPCORR 设置为 RS 时即执行该操作。为加速电荷转移修正的求值，可以通过求解线性化的单激发振幅方程来计算能量的二阶微扰修正。该算法称为近似 Roothaan 步（approximate Roothaan-step）修正，可通过将 FRGM_LPCORR 设置为 ARS 来启用。

对于弱相互作用片段组成的体系，经 ARS 与 RS 修正后的能量都非常接近完整 SCF 能量，但计算代价却低于完整的 SCF 计算。若要检验 ARS 与 RS 方法的精度，可以在同一个作业中通过微扰修正同时完成完整 SCF 计算，方法是将 FRGM_LPCORR 设置为 RS_EXACT_SCF 或 ARS_EXACT_SCF。也可以通过将 FRGM_LPCORR 设置为 EXACT_SCF，仅求值完整 SCF 修正。

ARS 方法中线性单激发振幅方程的迭代求解由下述一组 NVO 关键字控制。

*限制条件。* 局域投影方法只能求值单点 HF 与 DFT 能量。几何优化可使用数值梯度来执行。绝对局域分子轨道（absolutely-localized molecular orbitals）上未实现波函数关联方法（MP2、CC，*etc.*）。SCF_ALGORITHM 只能设置为 DIIS，不过在孤立片段上可以使用所有 SCF 收敛算法（在 *$rem_frgm* 段中设置 SCF_ALGORITHM）。

    ```qchem
    $molecule
       0 1
       --
       0 1
       O      -1.56875     0.11876     0.00000
       H      -1.90909    -0.78106     0.00000
       H      -0.60363     0.02937     0.00000
       --
       0 1
       O       1.33393    -0.05433     0.00000
       H       1.77383     0.32710    -0.76814
       H       1.77383     0.32710     0.76814
    $end
    
    $rem
       METHOD          HF
       BASIS           AUG-CC-PVTZ
       FRGM_METHOD     GIA
       FRGM_LPCORR     RS_EXACT_SCF
    $end
    
    $rem_frgm
       SCF_CONVERGENCE 2
       THRESH          5
    $end
    ```

对于某些体系，无需将 SCF-MI 计算收敛，直接把 RS 或 ARS 电荷转移修正应用于 FRAGMO 初始猜测，也能在分子间相互作用能上获得良好精度。将 FRGM_METHOD 设置为 NOSCF_RS 或 NOSCF_ARS，可分别请求单 Roothaan 修正或近似 Roothaan 修正。若要得到略好的能量估计，将 FRGM_METHOD 设置为 NOSCF_DRS 或 NOSCF_RS_FOCK。在 NOSCF_RS_FOCK 情形下，先执行与 NOSCF_RS 方法相同的步骤，随后再进行一次 Fock 矩阵构建并计算正确的 SCF 能量。在双 Roothaan 步（double Roothaan-step）修正情形下，即 NOSCF_DRS，先执行与 NOSCF_RS_FOCK 相同的步骤，随后再进行一次对角化。NOSCF_DRS 方法的最终能量以微扰修正的方式求值，类似于单 Roothaan 步修正。

直接应用于 FRAGMO 猜测的电荷转移修正被纳入 **Q-Chem**，用于检验局域投影 SCF 方法的精度与性能。不过对于某些体系，这些方法只需花费一次（或两次）SCF 步的代价，即可给出结合能的合理估计。
