## 12.15.2 任务控制

（2026 年 7 月 4 日）

除了第 [7.3.6](../ch07_excited/subsec_TDDFT-Control.md) 节中描述的常规 TDDFT 任务控制变量之外，还有若干用于请求 TDDFT(MI) 的变量。请注意，该方法仅支持单点能计算（不支持梯度计算）。

### `TDDFT_MI`

> **执行 TDDFT(MI) 计算**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * `FALSE`: 不执行 TDDFT(MI) 计算
>     * `TRUE`: 执行 TDDFT(MI) 计算
> * **推荐值**: False

### `MI_ACTIVE_FRAGMENT`

> **设置活性片段（active fragment）**
>
> * **类型**: `INTEGER`
> * **默认值**: `NO DEFAULT`
> * **选项**:
>     * $n$: 指定在哪个片段上执行 TDDFT 计算，用于 LEA-TDDFT(MI)。
> * **推荐值**: None

### `MI_LEA`

> **控制 LEA-TDDFT(MI) 方法**
>
> * **类型**: `INTEGER`
> * **默认值**: `NO DEFAULT`
> * **选项**:
>     * `0`: LEA0 方法
>     * `1`: LEA-Q 方法
>     * `2`: LEAc 方法
> * **推荐值**: 1
