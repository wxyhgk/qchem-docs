## 12.3.1 概述

（2026 年 7 月 4 日）

通过将各个孤立片段（fragment）上已收敛的分子轨道叠加起来，可以为分子体系生成一个准确的初始猜测。该初始猜测通过将 SCF_GUESS 关键字指定为 FRAGMO 选项来请求使用，并且既可用于常规自洽场（SCF）方法，也可用于局域投影 SCF 方法。与 SAD 相比，使用 FRAGMO 可以显著减少 SCF 迭代次数。对于采用大基组（Basis Set）的多片段体系作业，这可带来可观的时间节省。[[682]](../bib_references/bib.md#bib706)
 与 SAD 猜测不同，FRAGMO 猜测是幂等的（idempotent）。

为了在各个孤立片段上收敛分子轨道，程序会为每个片段执行一个子 **Q-Chem** 作业。子作业的 *$rem* 变量从父作业的 *$rem* 部分继承。若将 SCF_PRINT_FRGM 设置为 TRUE，则子作业的输出会被重定向到父作业的输出文件中；否则输出将被抑制。

用于控制子 **Q-Chem** 进程的额外关键字可以设置在父输入文件的 *$rem_frgm* 部分中。该部分的结构与 *$rem* 部分相同。*$rem_frgm* 部分中的选项会覆盖父作业的选项。*$rem_frgm* 旨在指定控制孤立片段上 SCF 例程的关键字。请谨慎使用 *$rem_frgm* 部分中的关键字。*$rem* 变量 FRGM_METHOD、FRGM_LPCORR、JOBTYPE、BASIS、PURECART、ECP 不允许出现在 *$rem_frgm* 中，若出现将被忽略。*$rem* 变量 FRGM_METHOD、FRGM_LPCORR、JOBTYPE 和 SCF_GUESS 不会从父作业继承。

当 GEN_SCFMAN = TRUE 时，同样支持使用 FRAGMO 猜测。该功能已扩展以支持更多 SCF 轨道类型（R/U/RO/G）。同时，如果这些作业在片段层面没有任何差异，用户可以直接读取先前生成的 FRAGMO 猜测而无需重新计算。这在某些场景下尤为有用，例如扫描分子间复合物的势能曲线，或重启能量分解分析（EDA）作业。此行为由 *$rem* 变量 FRAGMO_GUESS_MODE 控制。

FRAGMO_GUESS_MODE

### `FRAGMO_GUESS_MODE`

> **决定本作业中如何处理 FRAGMO 猜测（仅适用于 gen_scfman）**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **选项**:
>     * 0
>     * 依次生成并运行各片段作业，最后收集其结果作为
>     * FRAGMO
>     * 猜测。
>     * 1
>     * 在本作业的临时（scratch）目录下的 “FrgX" 文件夹中生成各片段的输入文件，
>     * 然后终止运行。
>     * 此后用户可以利用排队系统，以 “FrgX" 作为其临时文件夹来同时运行这些作业
>     * （需通过脚本处理）。
>     * 2
>     * 读取已有的片段数据。
> * **建议**：如果各片段的计算代价较为均衡，可考虑使用 “1"。当 FRAGMO 猜测已预先计算好时，使用 “2"。

示例）。"

    ```qchem
    --
    0 1
    O           2.701100   -0.077292   -0.273980

    H           1.328156   -1.800266   -2.490761
    H           2.384794   -1.339543   -3.467573
    ```

???+ example "示例 12.12.4：在 GEN_SCFMAN 中使用 FRAGMO 猜测进行 ROSCF 计算。第一个片段为 RO（限制性开壳层），第二个片段为闭壳层，而超大体系（super-system）同样采用 RO 计算。第二个作业中的复合物改变了片段间距，因此可以利用第一个作业生成的 FRAGMO 猜测。注意需要设置 ROSCF = TRUE，以保证对片段与超大体系的处理方式保持一致。"
    ```qchem
    $molecule
    1 2
    --
    0 2
    C1
    H1 C1 1.09267
    H2 C1 1.09267 H1 107.60335
    H3 C1 1.09267 H2 107.60335 H1 115.692
    --
    1 1
    Na C1 scan    H3 111.28008 H2 -122.154
    
    scan = 2.0
    $end
    
    $rem
       METHOD           b3lyp
       BASIS            6-31g
       GEN_SCFMAN       true
       UNRESTRICTED     false
       SCF_CONVERGENCE  8
       ROSCF            true
       SCF_GUESS        fragmo
       THRESH           14
       INTEGRAL_SYMMETRY    false
       POINT_GROUP_SYMMETRY false
    $end
    
    @@@
    ```
