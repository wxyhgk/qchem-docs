## 12.4.1 概述

（2026 年 7 月 4 日）

基组重叠误差（basis set superposition error, BSSE）的评估可以在 **Q-Chem** 中自动完成。若要计算经 BSSE 校正的结合能，请在 *$molecule* 段中指定各碎片（fragment），并将 JOBTYPE 设置为 BSSE。BSSE 任务并不局限于自洽场（SCF）能量，也可以在任意理论层次上对多碎片体系进行评估。**Q-Chem** 会按照 *$molecule* 段中的指定将体系拆分为若干碎片，并执行一系列任务：(a) 各个孤立碎片，(b) 各个孤立碎片但将体系中其余原子替换为虚原子（ghost atom），以及 (c) 完整体系。**Q-Chem** 会保存所有计算得到的能量，并输出未校正的以及经反自旋叠加（counterpoise, CP）校正后的相互作用能。可以使用 *$rem_frgm* 段来控制碎片上的计算，但务必保证碎片与完整体系被同等对待。也就是说，所有影响最终能量的数值方法和收敛阈值（例如 SCF_CONVERGENCE、THRESH、PURECART、XC_GRID）在碎片与完整体系之间应当保持一致。除非绝对必要，请避免在 BSSE 任务中使用 *$rem_frgm*。

???+ example "示例 12.5: 在 (i) B3LYP-D3(BJ)/6-31+G(d)、(ii) MP2/6-31++G(d,p) 层次上评估水三聚体的反自旋叠加（CP）校正分子间相互作用能"
    ```qchem
    $molecule
     0 1
     --
     0 1
     O          -0.089523    0.063946    0.086866
     H           0.864783    0.058339    0.103755
     H          -0.329829    0.979459    0.078369
     --
     0 1
     O           2.632273   -0.313504   -0.750376
     H           3.268182   -0.937310   -0.431464
     H           2.184198   -0.753305   -1.469059
     --
     0 1
     O           0.475471   -1.428200   -2.307836
     H          -0.011373   -0.970411   -1.626285
     H           0.151826   -2.317118   -2.289289
     $end
    
     $rem
     JOBTYPE         BSSE
     METHOD          B3LYP
     DFT_D           D3_BJ
     BASIS           6-31+G(d)
     SCF_CONVERGENCE 8
     INTEGRAL_SYMMETRY    FALSE
     POINT_GROUP_SYMMETRY FALSE
    $end
    
    @@@
    ```
