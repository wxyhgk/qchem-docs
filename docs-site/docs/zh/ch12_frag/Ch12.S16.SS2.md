## 12.16.2 作业控制

（2026 年 7 月 4 日）

除了第 [7.2.4](../ch07_excited/sec_CIS-jobcontrol.md) 节中描述的标准 CIS（组相互作用单激发，Configuration Interaction Singles）作业控制变量之外，还有一些额外的 *$rem* 变量需要为 ALMO-CIS/ALMO-CIS+CT 计算进行指定。

LOCAL_CIS

### `LOCAL_CIS`

> **启用 ALMO-CIS/TDA 或 ALMO-CIS/TDA+CT 计算。**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **选项**:
>     * 0
>     * 常规 CIS/TDDFT 计算
>     * 1
>     * 不使用 RI（Resolution of Identity，分辨率恒等近似）的 ALMO-CIS/TDA
>     * 2
>     * 使用 RI 的 ALMO-CIS
> * **建议**: 运行全谱 ALMO-CIS 计算时使用 2（ EIGSLV_METH = 0）；运行 ALMO-CIS/TDA 迭代版本时使用 1（ EIGSLV_METH = 1）

EIGSLV_METH

### `EIGSLV_METH`

> **控制求解 ALMO-CIS 本征方程的方法**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **选项**:
>     * 0
>     * 显式构建哈密顿量后进行对角化（全谱）
>     * 1
>     * 使用 Davidson 方法（目前仅对限制（restricted）情形可用）
> * **建议**: 无；对 ALMO-TDA 计算使用 1（0 不可用）

NN_THRESH

### `NN_THRESH`

> **相邻片段（其间发生 CT 电荷转移激发）的距离截断值。**
>
> * **类型**: `INTEGER`
> * **默认值**: `0`
> * **选项**:
>     * 0
>     * 不包含片段间跃迁（ALMO-CIS/TDA）
>     * $n$
>     * 包含片段对之间距离小于
>     * $n$
>     * $a_{0}$
>     * 的各对片段间的片段间激发（ALMO-CIS/TDA+CT）
> * **建议**: 无

???+ example "示例 12.53: 对氦二聚体所有 $n=2$ 态进行 ALMO-CIS+CT 计算（ $r_{\mathrm{cut}}=10$ $a_{0}$ ）。"
    ```qchem
    $molecule
    0 1
    --
       0 1
       He      2.8    0.     0.
    --
       0 1
       He      0.     0.     0.
    $end
    
    $rem
       BASIS          gen
       AUX_BASIS      rimp2-cc-pvdz
       PURECART       1111
       METHOD         hf
       FRGM_METHOD    stoll
       CIS_N_ROOTS    8
       CIS_TRIPLETS   false
       LOCAL_CIS      2 ! use RI for ALMO-CIS
       NN_THRESH      10
       POINT_GROUP_SYMMETRY false
       INTEGRAL_SYMMETRY    false
    $end
    
    $rem_frgm
       cis_n_roots 0
    $end
    
    $basis
    ****
    HE   0
    S    3    1.000000
    3.84216340D+01    2.37660000D-02
    5.77803000D+00    1.54679000D-01
    1.24177400D+00    4.69630000D-01
    S    1    1.000000
    2.97964000D-01    1.00000000D+00
    SP   1    1.000000
    4.80000000D-02    1.00000000D+00   1.00000000D+00
    ****
    $end
    ```
