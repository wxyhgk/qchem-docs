## 12.8.1 理论

(July 4, 2026)

XPol 是一种近似的、基于片段的分子轨道方法，其开发初衷是作为一种“下一代”力场。[[428]](../bib_references/bib.md#bib436)
该方法的基本思想是将分子液体、固体或团簇视为一组片段的集合，其中每个片段就是一个分子。分子内相互作用采用自洽场（Self-Consistent Field, SCF）方法（Hartree-Fock 或密度泛函理论（Density Functional Theory, DFT））处理，但每个片段都嵌入在代表与其他片段静电相互作用的点电荷场中。这些电荷通过电荷分析程序（例如 Mulliken、Löwdin 或 ChElPG；见第 [10.2.2](../ch10_properties/subsec_pop_anal.md) 节）将每个片段的电子密度坍缩到一组以原子为中心的点电荷上，并以自洽方式更新。这一方法以随片段数目线性标度的代价纳入了多体极化效应，但忽略了总电子波函数的反对称性要求。因此，分子间交换排斥被忽略，色散作用同样被忽略，因为色散本质上是一种电子相关效应。正因如此，XPol 对极化的处理必须辅以经验性的 Lennard–Jones 型分子间势能，才能获得有意义的优化几何结构、振动频率或动力学结果。

XPol 方法基于这样一个 *ansatz*（假设）：整个体系的波函数可以写成各片段波函数的直积，

<a id="eq:hartree_pdt"></a>
$$
|\Psi\rangle=\prod_{A}^{N_{\mathrm{frag}}}|\Psi_{\!A}\rangle, \tag{12.46}
$$

其中 $N_{\mathrm{frag}}$ 是片段数目。这里我们假设片段均为分子，且共价键保持完整。片段波函数对于同一片段内电子的交换是反对称的，但对于不同片段之间的电子交换则不然。对于用 Hartree-Fock 理论描述的闭壳层片段，XPol 总能量为[[1505]](../bib_references/bib.md#bib1565)

<a id="eq:E_xpol"></a>
$$
E_{\rm XPol}=\sum_{A}\left[2\sum_{a}\mathbf{c}_{a}^{\dagger}\left(\mathbf{h}^{A}+\mathbf{J}^{A}-\tfrac{1}{2}\mathbf{K}^{A}\right)\mathbf{c}_{a}+E_{\mathrm{nuc}}^{A}\right]+E_{\mathrm{embed}}. \tag{12.47}
$$

方括号中的项就是片段 $A$ 的普通 Hartree-Fock 能量表达式。因此，$\mathbf{c}_{a}$ 是占据分子轨道（MO）$a\in A$ 的展开系数向量（在原子轨道（AO）基下）；$\mathbf{h}^{A}$ 由单电子积分构成；$\mathbf{J}^{A}$ 和 $\mathbf{K}^{A}$ 则分别是用片段 $A$ 的密度矩阵构造的库仑矩阵和交换矩阵。式 ([12.47](#eq:E_xpol)) 中的附加项，

<a id="eq:E_QMMM"></a>
$$
E_{\mathrm{embed}}=\tfrac{1}{2}\sum_{A}\sum_{B\neq A}\sum_{J\in B}\left(-2\sum_{a}\mathbf{c}_{a}^{\dagger}\mathbf{I}_{J}\mathbf{c}_{a}+\sum_{I\in A}L_{IJ}\right)q_{J}, \tag{12.48}
$$

来源于静电嵌入。矩阵 $\mathbf{I}_{J}$ 由其 AO 矩阵元定义，

<a id="eq:I"></a>
$$
\left(\mathbf{I}_{J}\right)_{\mu\nu}=\left\langle\mu\left|\frac{1}{\bigl{|}\vec{r}-\vec{R}_{J}\bigr{|}}\right|\nu\right\rangle, \tag{12.49}
$$

而 $L_{IJ}$ 由下式给出

<a id="eq:L"></a>
$$
L_{IJ}=\frac{Z_{I}}{\bigl{|}\vec{R}_{I}-\vec{R}_{J}\bigr{|}}. \tag{12.50}
$$

根据式 ([12.47](#eq:E_xpol)) 和 ([12.48](#eq:E_QMMM))，每个片段都嵌入在由其他所有片段上的一组点电荷 $\{q_{J}\}$ 所产生的静电势中；式 ([12.48](#eq:E_QMMM)) 中的因子 $1/2$ 用于避免重复计数。片段间的交换相互作用被忽略，片段间的静电相互作用则近似为某个片段的电荷密度与其他片段上点电荷之间的相互作用。

关键在于，向量 $\mathbf{c}_{a}$ 是在正交定域分子轨道（Absolutely Localized Molecular Orbital, ALMO）*ansatz* 下构造的，[[683]](../bib_references/bib.md#bib705)
即每个片段的 MO 仅由定位于同一片段原子上的那些 AO 展开表示。这一选择使方法的计算代价随 $N_{\mathrm{frag}}$ 线性增长，并且从构造上就排除了基组重叠误差（basis set superposition error）。在紧凑基组中，ALMO *ansatz* 还排除了片段间的电荷转移。

Xie 等人[[1503]](../bib_references/bib.md#bib1564)
最初提出的 XPol 方法在式 ([12.48](#eq:E_QMMM)) 的嵌入电荷 $q_{J}$ 中使用 Mulliken 电荷，尽管也可以设想其他电荷方案。在非极小基组中，Mulliken 电荷的使用伴随着严重的收敛问题，[[621]](../bib_references/bib.md#bib643)
因此 **Q-Chem** 的 XPol 实现提供了替代方案，可选用 Löwdin 电荷、Charge Model 5（CM5）电荷[[911]](../bib_references/bib.md#bib945)
或 ChElPG 电荷[[159]](../bib_references/bib.md#bib152)
，后者如第 [10.2.2](../ch10_properties/subsec_pop_anal.md) 节所述，是由静电势导出的。ChElPG 电荷被发现稳定且鲁棒，尽管与 Mulliken 或 Löwdin 电荷相比计算代价略高。[[621]](../bib_references/bib.md#bib643)
现有算法可以采用以原子为中心的 Lebedev 网格而非传统笛卡尔网格来计算 ChElPG 电荷（见第 [10.2.2](../ch10_properties/subsec_pop_anal.md) 节），[[590]](../bib_references/bib.md#bib612)

该算法使用的网格点少得多，因此对于需要迭代更新这些电荷的 XPol/ChElPG 方法，可显著提升性能。相较于 ChElPG 电荷，CM5 电荷是一种更具成本效益且略微更准确的替代方案。[[845]](../bib_references/bib.md#bib882)

CM5 电荷的导数比 ChElPG 的导数计算起来便宜得多，而由于 XPol 必须迭代更新电荷，采用 CM5 电荷可使总代价大幅降低。

使用 **Q-Chem** XPol 代码的研究人员被要求引用文献 [[621]](../bib_references/bib.md#bib643)
。
