## 8.10.2 ECP 拟合

(2026 年 7 月 4 日)

有效核势（Effective Core Potential, ECP）矩阵元可以说是目前存在的最困难的一电子积分。事实上，使用当前的方法，计算 ECP 积分所花费的时间可能超过计算数量多得多的电子排斥积分所花费的时间。**Q-Chem** 5.0 实现了一套最先进的 ECP 计算方案[[933]](../bib_references/bib.md#bib972)

基于高效的递推关系与上界。
该方法依赖于受限的径向势 $U_{\ell}(r)$，其中径向幂次始终为零，*即* $n=0$。虽然这对于某些 ECP（例如 Stuttgart-Bonn 基组）是成立的，但许多其他 ECP 的径向势包含 $n=-2$ 和 $n=-1$ 项。为了克服这一挑战，我们仅使用 $n=0$ 项来拟合这些 ECP 径向势。每个 $n=-2$ 和 $n=-1$ 项都被展开为三个 $n=0$ 项之和，每个项具有独立的收缩系数 $D_{\ell_{k}}$ 和高斯指数 $\eta_{\ell_{k}}$。高斯指数由预定方案给出，收缩系数则在最小二乘拟合过程中计算得到。ECP 拟合引入的误差微不足道，并且与其他 ECP 方法中存在的数值积分引入的误差处于同一量级。对于内置的 ECP，每个 ECP 的拟合变体现在均在 `$QCAUX` 目录中提供，例如 `fit-LANL2DZ`。对于包含 $n=-2$ 或 $n=-1$ 项的用户自定义 ECP，**Q-Chem** 将在运行时通过额外的 rem 关键字 `ECP_FIT = TRUE` 执行拟合。
