## 13.5.3.1 隐式溶剂化

通过在 NEO 框架内应用各种隐式溶剂化模型（第 [11.2](../ch11_env/topic_solvation.md) 节），可以将体相溶剂效应直接纳入 NEO 计算中。[[1470]](../bib_references/bib.md#bib1531)

极化连续介质模型（Polarizable Continuum Model, PCM）是隐式溶剂化模型的一大族，其本身包含若干不同的形式化方案：[[756]](../bib_references/bib.md#bib789)

C-PCM，[[1375]](../bib_references/bib.md#bib1436)
 IEF-PCM，[[245]](../bib_references/bib.md#bib245)

SS(V)PE，[[245]](../bib_references/bib.md#bib245)
 等等。[[569]](../bib_references/bib.md#bib580)

在 PCM 方法中，溶质分子被置于一个嵌入介电连续介质溶剂中的空腔内，空腔表面被离散化为 $i$ 个面元（tesserae）网格点。溶剂响应由每个面元网格点 $\mathbf{s}_{i}$ 处的部分电荷 $q_{i}$ 来表示。[[1363]](../bib_references/bib.md#bib1425)

在每一次自洽场（SCF）迭代中，当前的电子密度与质子密度连同固定的经典原子核共同定义了溶质的电荷分布。该电荷分布在每个面元网格点处产生溶质的静电势 $V_{i}$：

<a id="eq:neo-esp-fixed"></a>
$$
V_{i}=\sum_{A}\frac{Z_{A}}{\left|\mathbf{R}_{A}-\mathbf{s}_{i}\right|}-\sum_{\mu\nu}P_{\mu\nu}^{\text{e}}\int d\mathbf{r}_{\text{e}}\frac{\phi_{\mu}^{\text{e}}\left(\mathbf{r}_{\text{e}}\right)\phi_{\nu}^{\text{e}}\left(\mathbf{r}_{\text{e}}\right)}{\left|\mathbf{r}_{\text{e}}-\mathbf{s}_{i}\right|}+\sum_{\mu^{\prime}\nu^{\prime}}P_{\mu^{\prime}\nu^{\prime}}^{\text{p}}\int d\mathbf{r}_{\text{p}}\frac{\phi_{\mu^{\prime}}^{\text{p}}\left(\mathbf{r}_{\text{p}}\right)\phi_{\nu^{\prime}}^{\text{p}}\left(\mathbf{r}_{\text{p}}\right)}{\left|\mathbf{r}_{\text{p}}-\mathbf{s}_{i}\right|}\;. \tag{13.83}
$$

随后，利用溶质静电势按标准 PCM 方法计算 $q_{i}$。一旦获得这组面元电荷，它们便作为附加的一电子（一质子）贡献被纳入电子（质子）Fock 矩阵或相应的 Kohn-Sham（KS）矩阵中：

<a id="Ch13.E84"></a>
$$
\displaystyle F^{\text{e},\text{solv}}_{\mu\nu} \tag{13.84a}
$$

其中 $F^{\text{e},\text{0}}_{\mu\nu}$ 和 $F^{\text{p},\text{0}}_{\mu^{\prime}\nu^{\prime}}$ 分别指气相下的电子 [Eq. ([13.37a](Ch13.S5.SS2.md#eq:neo-fock1))] 与质子 [Eq. ([13.37b](Ch13.S5.SS2.md#eq:neo-fock2))] Fock 矩阵或相应 Kohn-Sham 矩阵元。

NEO-PCM 计算涉及在介电连续介质溶剂存在下，对核-电子波函数进行迭代式的自洽收敛。
NEO-PCM 的解析梯度和解析 Hessian 也已实现。该计算可通过在 *$rem* 输入段中设置 SOLVENT_METHOD = PCM 来启用。溶剂化自由能中的非静电贡献也可以通过设置 SOLVENT_METHOD = SMD 来纳入：

SOLVENT_METHOD

 以指导模型选择。最后，关于如何设置含溶剂 NEO 计算的示例请参见第 [13.5.6](subsec_neo-examples.md) 节。

## 13.5.3.2 静电嵌入

通过在 *$rem* 输入段中设置 QM_MM = TRUE 并指定 *$external_charges* 输入段，即可将一组外部电荷纳入 NEO 计算。
其格式如下所示，由笛卡尔坐标及点电荷数值组成，每行一个电荷。电荷以原子单位（atomic units）表示，坐标以埃（Ångstroms）表示，除非通过设置 *$rem* 关键字 INPUT_BOHR 为 TRUE 而选用玻尔半径（bohr）作为单位。这些外部电荷会随分子一起旋转到标准原子核取向下，并按以下格式给出：

> ```qchem
> $external_charges
>    x-coord1  y-coord1  z-coord1  charge1
>    x-coord2  y-coord2  z-coord2  charge2
>    x-coord3  y-coord3  z-coord3  charge3
> $end
> ```

请注意，当存在 *$external_charges* 关键字时，电场和解析梯度会自动保存到磁盘。
因此，将 **Q-Chem** 与外部分子力学（molecular mechanics）软件包配合使用，即可执行 NEO-QM/MM 计算。当使用外部分子力学驱动程序时，应将以下 *$rem* 关键字设置为 FALSE，以避免双重计数（double counting）问题：

SKIP_CHARGE_SELF_INTERACT

## 13.5.3.4 伪势

**Q-Chem** 的有效核势（Effective Core Potential, ECP）模块已与 NEO 方法集成，从而可以对某些原子带有伪势的体系描述相对论效应及芯电子效应。
其做法是在电子 Fock 矩阵或相应的 Kohn-Sham 矩阵中增加一项额外的一电子势贡献，用以模拟芯电子的效应（另见第 [8.10](../ch08_basis/sec_ECPs.md) 节）。在电子与质子的 Fock 矩阵或相应 Kohn-Sham 矩阵中，对应于电子或量子化质子与带 ECP 的经典原子核相互作用的一电子项，均采用被芯电子屏蔽后的有效核电荷。[[817]](../bib_references/bib.md#bib857)

以下 *$rem* 变量控制所使用 ECP 的种类：

ECP

### `ECP`

> **定义所使用的有效核势及其配套基组（Basis Set）**
>
> * **类型**：`STRING`
> * **默认值**：`No ECP`
> * **选项**：
>     * General, Gen
>     * 用户自定义（需要
>     * $ecp
>     * 关键字）
>     * Symbol
>     * 使用上文讨论的标准 ECP。
> * **建议**：对第一行过渡金属及更重的元素建议使用 ECP。更多细节请参见第 8.10 节。
