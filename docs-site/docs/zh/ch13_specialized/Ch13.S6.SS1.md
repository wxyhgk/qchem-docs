## 13.6.1 概述

（2026 年 7 月 4 日）

有效哈密顿量（Effective Hamiltonians）为复杂电子结构的粗粒化表示提供了一个强大的框架，并可与实验-derived 参数进行直接比较。它常用于磁性体系。[[877]](../bib_references/bib.md#bib912)

依据有效哈密顿量的一般理论，[[877]](../bib_references/bib.md#bib912)
文献 [[1106]](../bib_references/bib.md#bib1154)
 描述了如何利用 Bloch 形式体系（Bloch's formalism）从 EOM-CC 波函数中提取有效哈密顿量。
该方法提供了将多体电子结构到所选模型空间（model space）的精确映射，从而在该模型空间中给出严格的有效哈密顿量。
目前仅支持 EOM-SF-CCSD 波函数以及 Heisenberg 模型空间和 Hubbard 模型空间。
所实现的程序是一个 $N$-to-$N$ 映射，即模型态的数目与用于构建有效哈密顿量的电子态数目相同。
对于 Heisenberg 哈密顿量，态的数目 $N$ 应与开壳层电子数相同，
因为单次自旋翻转（spin-flipping）激发所能提供的开壳层组态数即为此数目。
对于 Hubbard 哈密顿量，$N$ 应等于单次自旋翻转激发在开壳层子空间中所能生成的组态总数
（即开壳层轨道数的平方）。
一旦将 CC_MAKE_EFF_HAM *$rem* 变量设置为 1，
电子态即从 *$eff_ham* 部分所指定的列表中读取。
这些 EOM 态的右振幅和左振幅被用于有效哈密顿量的构建。
哈密顿量以两种形式构建：Bloch 形式（非厄米，non-Hermitian）和 des Cloizeaux 形式（厄米，Hermitian）。
若调用 CC_OSFNO（推荐使用），则开壳层轨道之间的对应关系通过
SVD 过程建立，[[1104]](../bib_references/bib.md#bib1153)
随后对这些轨道进行 Boys 定域化（Boys localization）。
如果需要获得这些轨道，则应通过 CC_CANONIZE = FALSE 禁用轨道正则化（orbital canonicalization）。
若 GUI 设置为 2，则 CCMAN2 计算中所使用的轨道会被输出到 `.fchk` 文件
并可通过 **IQmol** 进行可视化。

**注意：

请留意，当有多个轨道位于相同的自由基中心上时，定域化过程可能会失败，
因为在这种情况下 Boys 定域化会变成病态（ill-conditioned）问题。
**

*$eff_ham* 部分的语法与 *$trans_prop* 部分的语法类似。
首先，**state_list** 起始处列出用于构建有效哈密顿量的电子态。
EOM 态以方法类型（目前仅支持 SF_STATES）、其不可约表示（irreducible representation，对于 OSFNO 和定域化轨道请使用 1）
以及在该特定不可约表示中的序号来简写。
态列表以 **end_list** 结束。
有效哈密顿量的类型由 **eff_ham** 关键字指定，其取值可以是
**Heisenberg** 或 **Hubbard**。

下面的示例基于文献 [[1106]](../bib_references/bib.md#bib1154)
 中的分子 1。
它展示了如何从 EOM-SF-CCSD 波函数构建 Heisenberg 哈密顿量。若要构建 Hubbard 哈密顿量，可对其进行如下修改：($i$) 请求四个 SF 态（其中将包含
两个共价态和两个离子态），以及 ($ii$) 将 **eff_ham** 设置为 **Hubbard**。

???+ example "示例 13.38: 对于具有两个开壳层电子的分子，从 EOM-SF 波函数构建 Heisenberg 哈密顿量的输入"
    ```qchem
    $comment
       Molecule 1 from J. Chem. Phys. 152, 094108 (2020):  propane-1,3-diyl.
       This example illustrates the construction of the Heisenberg Hamiltonian
       from the two lowest diradical states computed by EOM-SF-CCSD.
    $end
    
    $molecule
       0 3
       C    -0.0720787494   -0.2443969570    1.2525335342
       C    -0.1914499016    0.5591929000    0.0000000000
       C    -0.0720787494   -0.2443969570   -1.2525335342
       H     0.1191211842    0.2375636339    2.2059937351
       H    -0.3120216606   -1.3031986575    1.2578210464
       H     0.5519313098    1.3748537257    0.0000000000
       H    -1.1649723712    1.1083017822    0.0000000000
       H     0.1191211842    0.2375636339   -2.2059937351
       H    -0.3120216606   -1.3031986575   -1.2578210464
    $end
    
    $rem
       METHOD            eom-ccsd
       BASIS             sto-3g
       GUI               2
       SF_STATES         [2]
       CC_OSFNO          true
       CC_FNO_THRESH     9900
       CC_CANONIZE       false
       CC_MAKE_EFF_HAM   1
       CC_EOM_PROP       1
       CC_EOM_PROP_TE    1
       POINT_GROUP_SYMMETRY false
       INTEGRAL_SYMMETRY    false
    $end
    
    $eff_ham
       state_list
       sf_states 1 1
       sf_states 1 2
       end_list
       eff_ham heisenberg
    $end
    ```
