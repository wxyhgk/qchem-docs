## 13.5.5 NEO 模型的分子性质与波函数分析工具

（2026 年 7 月 4 日）

**Q-Chem** 的部分分子性质与波函数分析工具已扩展支持 NEO 方法，这些工具会被自动调用并在输出文件中报告：

- 基态的 Mulliken 布居分析
- 基态的分子偶极矩与质子位置期望值
- 用于从基态 NEO-SCF 计算生成质子密度图的 **MolDen** 文件
- 用于从激发态 LR-NEO-TDHF（TDDFT）计算生成质子跃迁密度图的 **MolDen** 文件
- 使用 CNEO 或 NEO-SCF(V) Hessian 的振动分析（包括同位素取代）

质子密度 **MolDen** 文件不会自动生成，但可以通过指定以下两个 *$rem* 变量来启用：`MAKE_CUBE_FILES = TRUE` 和 `PLOTS = TRUE`。指定这些关键字还将生成用于电子密度可视化的 **MolDen** 文件。用于生成电子密度的网格参数可以通过 *$plots* 输入部分进行调整（详情请参阅第 [10.5.4.1 节](../ch10_properties/sect_plot.mo.md#sec:new-plots)）。请注意，目前用户无法自定义质子密度生成的网格，而是根据几个预定义选项自动选择。
