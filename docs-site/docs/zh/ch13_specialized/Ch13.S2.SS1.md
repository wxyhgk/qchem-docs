## 13.2.1 引言

(July 4, 2026)

电子波函数的高维特性使其难以分析和解释。通常 convenient 的做法是降低这一巨大的维度数量，从而得到更简单的函数，使其能更容易地提供化学洞见。其中最为人熟知的是一电子密度 $\rho(\mathbf{r})$，它给出在点 $\mathbf{r}$ 处发现某个电子的概率。类似地，一电子动量密度 $\pi(\mathbf{p})$ 给出电子具有动量 $\mathbf{p}$ 的概率。然而，将波函数约化为一电子密度会丢失大量信息。特别地，人们往往希望保留显式的二电子信息。内禀对分布函数（intracules）是二电子分布函数，提供关于电子*相对*位置与动量的信息。关于不同类型 intracules 的详细论述可参阅参考文献 [[450]](../bib_references/bib.md#bib466)。**Q-Chem** 的 intracule 计算模块由 Aaron Lee 和 Nick Besley 开发，能够针对 DFT 或 HF 波函数计算以下几种 intracules：

- 位置 intracule，$P(u)$：描述发现两个电子相距 $u$ 的概率。
- 动量 intracule，$M(v)$：描述发现两个电子具有相对动量 $v$ 的概率。
- Wigner intracule，$W(u,v)$：描述发现两个电子相距 $u$ *且*具有相对动量 $v$ 的联合概率。
