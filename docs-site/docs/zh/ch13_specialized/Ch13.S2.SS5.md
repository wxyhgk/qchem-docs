## 13.2.5 Intracule（内余轨）任务控制

（2026 年 7 月 4 日）

以下 *$rem* 变量可用于控制 intracule 的计算。

INTRACULE

### `INTRACULE`

> **控制是否计算 intracule 性质（另参见 $intracule 部分）。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * FALSE
>     * 不计算 intracule 性质。
>     * TRUE
>     * 计算 intracule 性质。
> * **建议**: 无

WIG_MEM

### `WIG_MEM`

> **降低计算 $W(u,v)$ 时所需的内存。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * FALSE
>     * 不使用低内存选项。
>     * TRUE
>     * 使用低内存选项。
> * **建议**: 低内存选项运行速度更慢，因此除非内存受限，否则请使用默认值。

WIG_LEB

### `WIG_LEB`

> **使用 Lebedev 求积法（Lebedev quadrature）计算 Wigner 积分。**
>
> * **类型**: `LOGICAL`
> * **默认值**: `FALSE`
> * **选项**:
>     * FALSE
>     * 通过级数求和计算 Wigner 积分。
>     * TRUE
>     * 使用求积法计算 Wigner 积分。
> * **建议**: 无

WIG_GRID

### `WIG_GRID`

> **为 Wigner intracule 计算指定角度方向的 Lebedev 网格。**
>
> * **类型**: `INTEGER`
> * **默认值**: `194`
> * **选项**:
>     * 最多可达 5810 个点的 Lebedev 网格。
> * **建议**: 若需要高精度，请使用更大的网格。

N_WIG_SERIES

### `N_WIG_SERIES`

> **设置 Wigner 积分的求和上限。**
>
> * **类型**: `INTEGER`
> * **默认值**: `10`
> * **选项**:
>     * $n<100$
> * **建议**: 增大 $n$ 可获得更高精度。

N_I_SERIES

### `N_I_SERIES`

> **设置 $i_{n}(x)$ 级数展开计算的求和上限。**
>
> * **类型**: `INTEGER`
> * **默认值**: `40`
> * **选项**:
>     * $n>0$
> * **建议**: 较小的值可加快计算速度，但可能影响精度。

N_J_SERIES

### `N_J_SERIES`

> **设置 $j_{n}(x)$ 级数展开计算的求和上限。**
>
> * **类型**: `INTEGER`
> * **默认值**: `40`
> * **选项**:
>     * $n>0$
> * **建议**: 较小的值可加快计算速度，但可能影响精度。
