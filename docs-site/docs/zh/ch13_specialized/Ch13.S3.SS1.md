## 13.3.1 概述

（2026 年 7 月 4 日）

库仑衰减薛定谔方程（Coulomb Attenuated Schrödinger Equation, CASE）近似[[23]](../bib_references/bib.md#bib8)
 源于 KWIK 算法[[350]](../bib_references/bib.md#bib354)
，该算法利用误差函数将库仑算符（Coulomb operator）分裂为两部分，见公式 ([5.12](../ch05_dft/Ch5.S3.SS1.md#eq:erf_partition))。在[第 5.6 节](../ch05_dft/sect_LRC-DFT.md)中，这种对库仑算符的分裂被用于将长程 Hartree-Fock 交换引入密度泛函理论（DFT）；而在 CASE 近似中，它被用于衰减公式 ([4.2](../ch04_scf/Ch4.S2.SS1.md#eq:Hamiltonian)) 中所有出现的库仑算符，做法是忽略公式 ([5.12](../ch05_dft/Ch5.S3.SS1.md#eq:erf_partition)) 中恒等式的长程部分。公式 ([5.12](../ch05_dft/Ch5.S3.SS1.md#eq:erf_partition)) 中的参数 $\omega$ 用于调节衰减的程度。尽管库仑衰减计算得到的总能量与非衰减能量存在显著差异，但只要选取合理的 $\omega$ 值，相对能量、相关能以及（尤其是）波函数都基本不受影响。

由于衰减后的算符呈指数衰减，可以基于邻近性（proximity）忽略电子排斥积分（ERI），从而得到用于单点能计算的严格 ${\cal{O}}({N})$ 算法。CASE 同样可以应用于几何优化和频率计算。

### `OMEGA`

> **控制库仑算符的衰减程度。**
>
> * **类型**: `INTEGER`
> * **默认值**: `无默认值`
> * **取值选项**:
>     * $n$: 对应于 $\omega=n/1000$，单位为 bohr ${}^{-1}$
> * **建议**: 无

### `INTEGRAL_2E_OPR`

> **指定双电子算符。**
>
> * **类型**: `INTEGER`
> * **默认值**: `-2`
> * **取值选项**:
>     * `-1`: 应用 CASE 近似。
>     * `-2`: 库仑算符（Coulomb Operator）。
> * **建议**: 除非需要用到 CASE 算符，否则请使用默认值。
