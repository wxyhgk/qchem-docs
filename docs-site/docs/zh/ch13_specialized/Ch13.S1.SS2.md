## 13.1.2 微扰校正

(July 4, 2026)

通过对缺失的 geminal 间关联效应进行微扰描述，可以改进 SSG 对分子电子结构的描述。我们实现了 Epstein-Nesbet 形式的微扰理论[[367]](../bib_references/bib.md#bib371)，该形式能够对 SSG 模型中激发态能量的一电子与二电子贡献给出均衡的描述。这种微扰理论形式在弱分子间作用力的计算中尤其精确。此外，除了使参考波函数成为参考哈密顿量本征函数所必需的 geminal 内 $[i\bar{j},i\bar{j}]$ 积分之外，二电子 $[i\bar{j},j\bar{i}]$ 积分也被包含在参考哈密顿量中。[[1153]](../bib_references/bib.md#bib1206)

SSG(EN2) 能量（SSG 波函数的二阶 Epstein-Nesbet 微扰理论）的所有微扰贡献，均按最大分子项、最小分母项以及按激发类型划分的总能量贡献进行分析。所有激发态被细分为类色散型（dispersion-like，即一个 geminal 内的关联激发与另一个 geminal 内的激发相耦合）、单电子电荷转移以及双电子电荷转移。这一分析使得可以对 SSG 参考波函数的质量进行审慎的评估。形式上，SSG(EN2) 校正既可以应用于 RSSG 波函数，也可以应用于 USSG 波函数。经验表明，存在断裂键或近乎断裂键的分子，其 RSSG(EN2) 校正可能出现发散。USSG(EN2) 理论则是均衡的，对波函数最大的微扰校正在数值上很少超过 0.1。
