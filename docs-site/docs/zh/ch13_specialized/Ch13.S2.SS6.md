## 13.2.6 *$intracule* 区段格式

(2026 年 7 月 4 日)

| int_type | 0 | 仅计算 $P(u)$ |
| --- | --- | --- |
|  | 1 | 仅计算 $M(v)$ |
|  | 2 | 仅计算 $W(u,v)$ |
|  | 3 | 计算 $P(u)$ 、 $M(v)$ 和 $W(u,v)$ |
|  | 4 | 计算 $P(u)$ 和 $M(v)$ |
|  | 5 | 计算 $P(u)$ 和 $W(u,v)$ |
|  | 6 | 计算 $M(v)$ 和 $W(u,v)$ |
| u_points |  | 点数、起点、终点。 |
| v_points |  | 点数、起点、终点。 |
| moments | 0–4 | 要计算的矩（moments）阶数（仅 $P(u)$ ）。 |
| derivs | 0–4 | 要计算的导数阶数（仅 $P(u)$ ）。 |
| accuracy | $n$ | ( $10^{-n})$ 指定内坐标（intracule）插值表的精度（仅 $P(u)$ ）。 |

???+ example "示例 13.1: 使用 974 点 Lebedev 球面求积网格，在 HF/STO-3G 水平下计算 Ne 的 $P(u)$ 、 $M(v)$ 和 $W(u,v)$"
    ```qchem
    $molecule
       0  1
       Ne
    $end
    
    $rem
       METHOD      hf
       BASIS       sto-3g
       INTRACULE   true
       WIG_LEB     true
       WIG_GRID    974
    $end
    
    $intracule
       int_type   3
       u_points  10   0.0  10.0
       v_points   8   0.0   8.0
       moments    4
       derivs     4
       accuracy   8
    $end
    ```

???+ example "示例 13.2: 在 $n$ =25 处对级数求和，并在 $j_{n}(x)$ 和 $i_{n}(x)$ 的级数求值中使用 30 项，在 HF/6-31G 水平下计算 H ${}_{2}$ O 的内坐标 $W(u,v)$"
    ```qchem
    $comment
      Note only a few points are calculated in this sample
    $end
    
    $molecule
       0  1
       H1
       O   H1  r
       H2  O   r  H1  theta
    
       r = 1.1
       theta = 106
    $end
    
    $rem
       METHOD         hf
       BASIS          6-31G
       INTRACULE      true
       WIG_MEM        true
       N_WIG_SERIES   25
       N_I_SERIES     40
       N_J_SERIES     50
    $end
    
    $intracule
       int_type   2
       u_points   2   0.0   15.0
       v_points   2   0.0   10.0
    $end
    ```
