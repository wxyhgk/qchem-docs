## B.2.2 含一般约束的几何优化

（2026 年 7 月 4 日）

`CONSTRAINT` 和 `ENDCONSTRAINT` 分别界定 *$opt* 中约束区段的起始与结束，用户可在该区段内指定多达六种不同类型的约束：

**原子间距离（interatomic distances）**

取值单位为埃（Ångstroms）；*value* $>0$：

`stre   atom1   atom2   value

`

**键角（angles）**

取值单位为度，$0\leq value\leq 180$；*atom2* 为该弯曲角的中心原子：

`bend   atom1   atom2   atom3   value

`

**面外弯曲角（out–of–plane–bends）**

取值单位为度，$-180\leq value\leq 180$ *atom2*；指 *atom4* 与 *atom1–atom2–atom3* 平面之间的夹角：

`outp   atom1   atom2   atom3   atom4   value

`

**二面角（dihedral angles）**

取值单位为度，$-180\leq value\leq 180$；指 *atom1–atom2–atom3* 平面与 *atom2–atom3–atom4* 平面之间的夹角：

`tors   atom1   atom2   atom3   atom4   value

`

**共面弯曲角（coplanar bends）**

取值单位为度，$-180\leq value\leq 180$；指 *atom1–atom2–atom3* 在 *atom2–atom3–atom4* 平面内的弯曲：

`linc   atom1   atom2   atom3   atom4   value

`

**垂直弯曲角（perpendicular bends）**

取值单位为度，$-180\leq value\leq 180$；指 *atom1–atom2–atom3* 相对于 *atom2–atom3–atom4* 平面的垂直弯曲：

`linp   atom1   atom2   atom3   atom4   value

`
