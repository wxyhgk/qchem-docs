## B.1.1 引言

(July 4, 2026)

- •

用户可以按任意顺序输入各个输入段（input section）；完整的输入段列表参见表 [3.1](../ch03_inputs/Ch3.S2.SS1.md#table:input_sections)。
- •

每个输入段都必须以 *$end* 结束。
- •

并非所有输入段都是必需的，但 *$rem* 和 *$molecule* 是必须提供的。
- •

整个 **Q-Chem** 输入均不区分大小写。
- •

多个作业（job）之间通过单独一行上的字符串 `@@@` 分隔。
