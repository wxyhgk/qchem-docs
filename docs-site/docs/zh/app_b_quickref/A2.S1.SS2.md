## B.1.2 Q-Chem 部分输入段的说明

(2026年7月4日)

## B.1.2.1 *$molecule*

共有四种方法可用于输入几何结构信息：

- •

*Z*-矩阵（单位为埃 Ångstrom 和度）： 

`$molecule`

      [电荷] [自旋多重度] 

      [*Z*-矩阵] 

      [若使用变量，则需空行] 

      [*Z*-矩阵变量（若使用）] 

`$end`
- •

笛卡尔坐标（Cartesian Coordinates，单位为埃 Ångstrom）： 

`$molecule`

      [电荷] [自旋多重度] 

      [笛卡尔坐标] 

      [若使用变量，则需空行] 

      [坐标变量（若使用）] 

`$end`
- •

从先前的计算中读取： 

`$molecule`

      `read`

`$end`
- •

从文件中读取： 

`$molecule`

      `read` `filename`

`$end`

## B.1.2.2 *$rem*

另请参见本附录末尾的 *$rem* 变量列表。其一般格式为：

> ```qchem
> $rem
>    REM_VARIABLE   VALUE   [optional comment]
> $end
> ```

不过，采用 "REM_VARIABLE = VALUE" 的写法也是可以接受的，*即*等号会被忽略。

## B.1.2.3 *$basis*

用户自定义基组（Basis Set）输入段的格式如下：

> | $basis |  |  |  |  |  |
> | --- | --- | --- | --- | --- | --- |
> |  | $X$ | 0 |  |  |  |
> |  | $L$ | $K$ | $scale$ |  |  |
> |  | $\alpha_{1}$ | $C_{1}^{L_{\text{min}}}$ | $C_{1}^{L_{\text{min}}+1}$ | $\ldots$ | $C_{1}^{L_{\text{max}}}$ |
> |  | $\alpha_{2}$ | $C_{2}^{L_{\text{min}}}$ | $C_{2}^{L_{\text{min}}+1}$ | $\ldots$ | $C_{2}^{L_{\text{max}}}$ |
> |  | $\vdots$ | $\vdots$ | $\vdots$ | $\ddots$ | $\vdots$ |
> |  | $\alpha_{K}$ | $C_{K}^{L_{\text{min}}}$ | $C_{K}^{L_{\text{min}}+1}$ | $\ldots$ | $C_{K}^{L_{\text{max}}}$ |
> | **** |  |  |  |  |  |
> | $end |  |  |  |  |  |

其中

$X$
原子的元素符号（不接受原子序数）

$L$
角动量符号（S、P、SP、D、F、G）

$K$
壳层（shell）的收缩度（整数）

$scale$
应用于指数的缩放因子（默认值为 1.00）

$a_{i}$
高斯原函数（primitive）指数（正实数）

$C_{i}^{L}
每个角动量对应的收缩系数（非零实数）。

每个原子以 `****` 结束，完整基组以 *$end* 关键字结束。基组一般输入中不能包含任何空行。注意，对于 SP 之类的复合壳层，每行需要包含不止一个收缩系数。与所有 Q-Chem 输入文件中的信息一样，所有输入均不区分大小写。

## B.1.2.4 *$comment*

用户可以在关键字输入段之外向输入文件添加注释，程序会将其忽略。这可以作为给用户自己的提醒，或者当需要教另一位用户编写输入文件时很有用。注释也可以放在 *$comment* 块中提供，不过鉴于整个输入文件都会被复制到输出文件中，这一做法实际上是多余的。

> ```qchem
> $comment
>    User comments - copied to output file
> $end
> ```

## B.1.2.5 *$ecp*

`$ecp

`对于每个带有赝势（ECP）的原子： 

      原子的化学符号 

      赝势（ECP）名称；该赝势的 $L$ 值；被移除的核心电子数 

      对于每个赝势分量（按以下顺序：非投影分量、$\hat{P}_{0}$、$\hat{P}_{1}$、…、$\hat{P}_{L-1}$） 

            分量名称 

            该分量中高斯函数的数目 

            对于该分量中的每个高斯函数 

                  $r$ 的幂次；指数；收缩系数 

`****`

`$end`

**注意： 

(1) *$ecp* 块中的所有信息均不区分大小写。
(2) $L$ 值不得超过 4。也就是说，不允许使用超出 $G$ 的投影算符。
(3) $r$ 的幂次（包含雅可比行列式 $r^{2}$ 因子）必须为 0、1 或 2。
**

## B.1.2.6 *$empirical_dispersion*

> ```qchem

>     S6 S6_value
>     D D_value
>     C6 element_1 C6_value_for_element_1 element_2 C6_value_for_element_2

本段仅用于用户希望修改 Grimme 推荐的默认值的场合。

## B.1.2.7 *$external_charges*

如果输入文件中存在 *$external_charges* 关键字，Q-Chem 会扫描一组待纳入计算的外部点电荷。其格式如下所示，由笛卡尔坐标和点电荷的数值组成，每个电荷占一行。电荷单位为原子单位，坐标单位为埃（Ångstrom），除非通过将 *$rem* 关键字 INPUT_BOHR 设为 TRUE 而选择玻尔（bohr）为单位。外部电荷会随分子一起旋转到标准核取向，并按以下格式给出：

> ```qchem
> $external_charges
>    x-coord1  y-coord1  z-coord1  charge1
>    x-coord2  y-coord2  z-coord2  charge2
>    x-coord3  y-coord3  z-coord3  charge3
> $end
> ```

此外，用户可以使用关键字 ADD_CHARGED_CAGE 请求在分子周围添加一个带电笼（用于所谓的“电荷稳定化”计算）。详细信息请参见第 [7.9.13](../ch07_excited/sec_CAGE.md) 节。

## B.1.2.9 *$isotopes*

注意，质量应以原子单位（atomic units）给出。

> ```qchem
> $isotopes
>    number_extra_loops  tp_flag
>       number_of_atoms  [temp pressure]
>       atom_number1 mass1
>       atom_number2 mass2
>    ...
> $end
> ```

## B.1.2.10 *$multipole_field*

可以通过指定 *$multipole_field* 输入段，对所研究的分子施加多极场（multipole field）。该段中的每一行包含所施加场的一个单一分量，格式如下：

> ```qchem
> $multipole_field
>    field_component_1   value_1
>    field_component_2   value_2
> $end
> ```

每个 *field_component* 采用笛卡尔（Cartesian）表示法指定：偶极场分量用 $x$、$y$ 或 $z$ 表示；四极场分量用 $xx$、$xy$ 等表示，依此类推（$\ldots$）。每个场分量的数值应以原子单位提供。与许多教科书中的约定相反，在 **Q-Chem** 中，电场线被定义为从负电荷指向正电荷。[[1235]](../bib_references/bib.md#bib1289)

偶极场分量也可以通过两个原子的编号后跟场的大小来指定。该场分量将始终与连接 *atom1* 和 *atom2* 的矢量平行，并随原子运动而跟随坐标变化。

> ```qchem
> $multipole_field
>    atom1 atom2 value
> $end
> ```

## B.1.2.14 *$svp*

```qchem
$svp
<KEYWORD>=<VALUE>, <KEYWORD>=<VALUE>,...
<KEYWORD>=<VALUE>
$end
```

例如，该输入段可以如下所示：

```qchem
$svp
    RHOISO=0.001, DIELST=78.39, NPTLEB=110
$end
```

## B.1.2.16 *$plots*

`$plots`

       一行注释

       在三行中指定三维点网格：

             $N_{x}\quad x_{\mathrm{min}}\quad x_{\mathrm{max}}$

             $N_{y}\quad y_{\mathrm{min}}\quad y_{\mathrm{max}}$

             $N_{z}\quad z_{\mathrm{min}}\quad z_{\mathrm{max}}$

       一行包含 4 个整数，指示要绘制的对象数量：

             $N_{\mathrm{MO}}\quad N_{\mathrm{Rho}}\quad N_{\mathrm{Trans}}\quad N_{\mathrm{DA}}$

       一行可选的整数列表，给出要计算的分子轨道（MO）编号（仅当 $N_{\mathrm{MO}}>0$ 时）

             MO(1)  MO(2) $\ldots$ MO($N_{\mathrm{MO}}$) 

       一行可选的整数列表，给出要计算的密度（仅当 $N_{\mathrm{Rho}}>0$ 时） 

             Rho(1)  Rho(2) $\ldots$ Rho($N_{\mathrm{Rho}}$) 

       一行可选的整数列表，给出要计算的跃迁密度（仅当 $N_{\mathrm{Trans}}>0$ 时） 

             Trans(1)  Trans(2) $\ldots$ Trans($N_{\mathrm{Trans}}$) 

       一行可选的状态列表，用于电离/附着密度（detachment/attachment densities）（若 $N_{\mathrm{DA}}>0$）

             DA(1)  DA(2) $\ldots$ DA($N_{\mathrm{DA}}$) 

`$end`

## B.1.2.17 *$localized_diabatization*

`$localized_diabatization`

&emsp;&emsp;&nbsp;一行注释。

&emsp;&emsp;&nbsp;一行列出需要混合的绝热态（adiabatic states）数组。

&emsp;&emsp;&nbsp;$<adiabat1>\;\;\;\;\;\;\;<adiabat2>\;\;\;\;\;\;\;<adiabat3>$ $\ldots$

`$end`

**注意：&emsp;

绝热态的计数方式为：第一激发态对应 $<adiabat>=1$，第五激发态对应 $<adiabat>=5$，依此类推。
**

## B.1.2.18 *$van_der_waals*

**注意：&emsp;

所有半径均以埃（Ångstroms）为单位给出。
**

> $van_der_waals
>    1
>    atomic_number   VdW_radius
> $end
> ```

> ```qchem

> $end
> ```
