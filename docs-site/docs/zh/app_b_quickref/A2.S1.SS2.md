## B.1.2 某些 **Q-Chem** 输入段的说明

（2026 年 7 月 4 日）

## B.1.2.1 *$molecule*

输入几何信息有四种可用方法：

- •

*Z*-矩阵（以埃和度为单位）： 

`$molecule`

      [电荷] [多重度] 

      [*Z*-矩阵] 

      [空行，如果使用参数的话] 

      [*Z*-矩阵参数，如果使用的话] 

`$end`
- •

笛卡尔坐标（以埃为单位）： 

`$molecule`

      [电荷] [多重度] 

      [笛卡尔坐标] 

      [空行，如果使用参数的话] 

      [坐标参数，如果使用的话] 

`$end`
- •

从先前的计算中读取： 

`$molecule`

      `read`

`$end`
- •

从文件中读取： 

`$molecule`

      `read` `filename`

`$end`

## B.1.2.2 *$rem*

另请参见本附录末尾的 *$rem* 变量列表。一般格式为：

> ```qchem
> $rem
>    REM_VARIABLE   VALUE   [可选注释]
> $end
> ```

尽管指定 "REM_VARIABLE = VALUE" 也是可以接受的，*即*，等号会被忽略。

## B.1.2.3 *$basis*

用户自定义基组段的格式如下：

> | $basis |  |  |  |  |  |
> | --- | --- | --- | --- | --- | --- |
> |  | $X$ | 0 |  |  |  |
> |  | $L$ | $K$ | $scale$ |  |  |
> |  | $\alpha_{1}$ | $C_{1}^{L_{\text{min}}}$ | $C_{1}^{L_{\text{min}}+1}$ | $\ldots$ | $C_{1}^{L_{\text{max}}}$ |
> |  | $\alpha_{2}$ | $C_{2}^{L_{\text{min}}}$ | $C_{2}^{L_{\text{min}}+1}$ | $\ldots$ | $C_{2}^{L_{\text{max}}}$ |
> |  | $\vdots$ | $\vdots$ | $\vdots$ | $\ddots$ | $\vdots$ |
> |  | $\alpha_{K}$ | $C_{K}^{L_{\text{min}}}$ | $C_{K}^{L_{\text{min}}+1}$ | $\ldots$ | $C_{K}^{L_{\text{max}}}$ |
> | **** |  |  |  |  |  |
> | $end |  |  |  |  |  |

其中

$X$
原子的元素符号（不接受原子序数）

$L$
角动量符号（S、P、SP、D、F、G）

$K$
壳层的收缩阶数（整数）

$scale$
应用于指数的缩放因子（默认值为 1.00）

$a_{i}$
高斯原始函数的指数（正实数）

$C_{i}^{L}$
每个角动量的收缩系数（非零实数）。

每个原子以 `****` 结尾，整个基组以 *$end* 关键字结束符结尾。在一般基组输入中不能包含空行。请注意，像 SP 这样的复合壳层每行必须有多个收缩系数。与所有 **Q-Chem** 输入组信息一样，所有输入均不区分大小写。

## B.1.2.4 *$comment*

用户可以在关键字输入段之外向输入文件添加注释，程序会忽略这些注释。这对用户自身可起到提醒作用，或者在指导其他用户设置输入时也可能有用。注释也可以在 *$comment* 块中提供，但鉴于整个输入组都会被复制到输出文件中，这实际上是多余的。

> ```qchem
> $comment
>    用户注释 - 会被复制到输出文件
> $end
> ```

## B.1.2.5 *$ecp*

`$ecp

`对于每个将使用 ECP 的原子 

      原子的化学符号 

      ECP 名称；ECP 的 $L$ 值；被移除的芯电子数 

      对于每个 ECP 分量（按未投影、$\hat{P}_{0}$、$\hat{P}_{1}$、 、 $\hat{P}_{L-1}$ 的顺序）

            分量名称 

            该分量中高斯函数的数目 

            对于该分量中的每个高斯函数 

                  $r$ 的幂；指数；收缩系数 

`****`

`$end`

**注意： 

(1) *$ecp* 块中的所有信息均不区分大小写。
(2) $L$ 值不得超过 4。也就是说，不允许使用 $G$ 投影算符之外的更高项。
(3) $r$ 的幂（其中包含雅可比因子 $r^{2}$）必须为 0、1 或 2。
**

## B.1.2.6 *$empirical_dispersion*

> ```qchem

>     S6 S6_value
>     D D_value
>     C6 element_1 C6_value_for_element_1 element_2 C6_value_for_element_2
>     VDW_RADII element_1 radii_for_element_1 element_2 radii_for_element_2
> $end
> ```

本节仅用于设置用户希望偏离 Grimme 推荐默认值的参数。

## B.1.2.7 *$external_charges*

如果存在 *$external_charges* 关键字，**Q-Chem** 会扫描一组要纳入计算的外加点电荷。其格式如下所示，由笛卡尔坐标和点电荷的值组成，每行一个电荷。电荷以原子单位表示，坐标以埃（Ångstroms）表示，除非通过将 *$rem* 关键字 INPUT_BOHR 设置为 TRUE 来选择使用玻尔半径（bohrs）。外加点电荷会随分子一起旋转到标准核取向坐标系中，并按以下格式指定：

> ```qchem
> $external_charges
>    x-coord1  y-coord1  z-coord1  charge1
>    x-coord2  y-coord2  z-coord2  charge2
>    x-coord3  y-coord3  z-coord3  charge3
> $end
> ```

此外，用户可以使用 ADD_CHARGED_CAGE 关键字请求在分子周围添加一个带电笼（用于所谓的"电荷稳定化"计算）。详见第 [7.9.13](../ch07_excited/sec_CAGE.md) 节。

## B.1.2.9 *$isotopes*

请注意，质量应以原子单位给出。

> ```qchem
> $isotopes
>    number_extra_loops  tp_flag
>       number_of_atoms  [temp pressure]
>       atom_number1 mass1
>       atom_number2 mass2
>    ...
> $end
> ```

## B.1.2.10 *$multipole_field*

可以通过指定 *$multipole_field* 输入段对所研究的分子施加多极场。该段中的每一行由所施加场的一个分量组成，格式如下：

> ```qchem
> $multipole_field
>    field_component_1   value_1
>    field_component_2   value_2
> $end
> ```

每个 *field_component* 使用笛卡尔表示法指定：偶极场分量用 $x$、$y$ 或 $z$ 表示；四极场分量用 $xx$、$xy$ 等表示，$\ldots$。每个场分量的值应以原子单位给出。与许多教科书的惯例相反，在 **Q-Chem** 中，电场线被定义为由负电荷指向正电荷。[[1235]](../bib_references/bib.md#bib1289)

偶极场分量也可以用两个原子的序号加上场的强度来指定。该场分量将始终平行于连接 *atom1* 和 *atom2* 的矢量方向，并随原子的运动而遵循坐标变化。

> ```qchem
> $multipole_field
>    atom1 atom2 value
> $end
> ```

## B.1.2.14 *$svp*

```qchem
$svp
<KEYWORD>=<VALUE>, <KEYWORD>=<VALUE>,...
<KEYWORD>=<VALUE>
$end
```

例如，该段可以写成如下形式：

```qchem
$svp
    RHOISO=0.001, DIELST=78.39, NPTLEB=110
$end
```

## B.1.2.16 *$plots*

`$plots`

       一行注释 

       用 3 行指定三维网格点： 

             $N_{x}\quad x_{\mathrm{min}}\quad x_{\mathrm{max}}$

             $N_{y}\quad y_{\mathrm{min}}\quad y_{\mathrm{max}}$

             $N_{z}\quad z_{\mathrm{min}}\quad z_{\mathrm{max}}$

       一行包含 4 个整数，指示要绘制的对象数量： 

             $N_{\mathrm{MO}}\quad N_{\mathrm{Rho}}\quad N_{\mathrm{Trans}}\quad N_{\mathrm{DA}}$

       一行可选的整数列表，给出要计算的分子轨道（MO）
（仅当 $N_{\mathrm{MO}}>0$ 时）

         MO(1)  MO(2) $\ldots$ MO($N_{\mathrm{MO}}$) 

       一行可选的整数列表，给出要计算的密度
（仅当 $N_{\mathrm{Rho}}>0$ 时） 

             Rho(1)  Rho(2) $\ldots$ Rho($N_{\mathrm{Rho}}$) 

       一行可选的整数列表，给出要计算的跃迁密度
（仅当 $N_{\mathrm{Trans}}>0$ 时） 

         Trans(1)  Trans(2) $\ldots$ Trans($N_{\mathrm{Trans}}$) 

       一行可选的态，用于电子 detachment/attachment 密度
（当 $N_{\mathrm{DA}}>0$ 时） 

             DA(1)  DA(2) $\ldots$ DA($N_{\mathrm{DA}}$) 

`$end`

## B.1.2.17 *$localized_diabatization*

`$localized_diabatization`

       一行注释。 

       一行，给出需要相互混合的绝热态数组。 

       $<adiabat1>\;\;\;\;\;\;<adiabat2>\;\;\;\;\;\;\;<adiabat3>$ $\ldots$

`$end`

**注意： 

我们对绝热态的计数方式为：第一激发态对应 $<adiabat>=1$，第五激发态对应 $<adiabat>=5$，依此类推。
**
