## B.1.3 *$rem* 变量列表

（2026 年 7 月 4 日）

## B.1.3.1 概述

**Q-Chem** 文本输入文件中 *$rem* 输入的通用格式非常简单，如下所示：

> ```qchem
> $rem
>    rem_variable   rem_option   [comment]
>    rem_variable   rem_option   [comment]
> $end
> ```

该输入不区分大小写。以下各节列出了供用户使用的各 *$rem* 变量的名称及其选项。描述每个 *$rem* 变量的格式如下：

### `REM_VARIABLE`

> **对该变量所控制内容的简要描述**
>
> * **Type（类型）**：`将变量定义为 INTEGER（整型）、LOGICAL（逻辑型）或 STRING（字符串型）。`
> * **Default（默认值）**：`描述默认值`
> * **Options（选项）**：
>     * 列出用户可用的选项
> * **Recommendation（建议）**：给出简要建议。
