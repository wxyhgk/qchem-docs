## 9.6.1 概述

(July 4, 2026)

扫描势能面（Potential Energy Surface, PES）时常很有用，即在每个被扫描变量的特定取值下优化其余所有自由度。这种"弛豫"（relaxed）扫描可以粗略估计反应物与产物之间的反应路径——前提是扫描坐标选择得当——并常用于经典力场（classical force field）的开发中，以优化二面角参数。例如，拉马克兰（Ramachandran）图是研究肽和蛋白质构象变化的关键工具，本质上就是二维扭转（torsional）扫描。

在某些情况下，弛豫扫描在几何优化时可能会遇到一些困难。而"冻结"（frozen）扫描由于不进行几何优化，可能更易于执行，尽管它提供的真实动力学信息较少。

**Q-Chem** 支持一维和二维 PES 扫描，方法是在 *$rem* 段中设置 JOBTYPE = PES_SCAN。
此外，还应指定一个 *$scan* 输入段，格式如下所示，但其中指定的键长（bond-length）、键角（bond-angle）或扭转（torsional）变量不得超过两个。

> ```qchem
> $scan
>    stre  atom1  atom2  value1 value2 incr
>    ...
>    bend  atom1  atom2  atom3  value1 value2 incr
>    ...
>    tors  atom1  atom2  atom3  atom4  value1 value2 incr
>    ...
> $end
> ```

**注意：

使用 JOBTYPE = PES_SCAN 的势能扫描仅适用于基态势能面，不过可以在 *$rem* 段中包含适当的垂直激发（vertical excitation）关键字，沿扫描坐标计算激发能，*e.g.*，用于 CIS/TDDFT 激发态的 CIS_N_ROOTS。
**

下面第一个示例演示如何扫描丁烷的扭转势，其本质是一系列约束优化，其中 C1–C2–C3–C4 二面角依次固定为 $-$180${}^{\circ}$、$-$165${}^{\circ}$、$-$150${}^{\circ}$、
$\ldots$、165${}^{\circ}$、180${}^{\circ}$。

       C       0.556601     0.526657     0.000200
       C      -0.556627    -0.526735     0.000173
       C      -1.934557     0.128837    -0.000138
       H       2.720125     0.655980    -0.000236
       H       2.061880    -0.759501    -0.905731
       H       2.062283    -0.759765     0.905211
       H       0.464285     1.168064    -0.903444
       H       0.464481     1.167909     0.903924
       H      -0.464539    -1.167976     0.903964
       H      -0.464346    -1.168166    -0.903402
       H      -2.062154     0.759848     0.905185
       H      -2.720189    -0.655832    -0.000229
       H      -2.061778     0.759577    -0.905748

       JOBTYPE  pes_scan

要执行冻结 PES 扫描，请将 FROZEN_SCAN 设置为 TRUE，并使用 *Z*-矩阵（*Z*-matrix）格式的输入几何结构。下面的示例演示甲醇的 C1–C2 键从 1.0 Å 拉伸到 2.0 Å 的一维冻结 PES 扫描。

???+ example "示例 9.21: 甲醇的一维冻结 PES 扫描"
    ```qchem
    $molecule
      0 1
       C
       O   C  RCO
       H1  C  RCH1  O  H1CO
       X   C  1.00  O  XCO   H1  180.0
       H2  C  RCH2  X  H2CX  H1   90.0
       H3  C  RCH2  X  H2CX  H1  -90.0
       H4  O  ROH   C  HOC   H1  180.0
    
       RCO  = 1.421
       RCH1 = 1.094
       RCH2 = 1.094
       ROH  = 0.963
       H1CO = 107.2
       XCO  = 129.9
       H2CX = 54.25
       HOC  = 108.0
    $end
    
    $rem
       JOBTYPE        pes_scan
       EXCHANGE       s
       CORRELATION    vwn
       BASIS          3-21g
       FROZEN_SCAN    true
    $end
    
    $scan
       stre 1 2 1.0 2.0 0.5
    $end
    ```

**Q-Chem** 支持一维约束（restrained）PES 扫描，包括键长、键角、扭转、原子到两个原子质心的距离，以及原子到一组原子的距离。注意，原子组定义为索引从 `atom2` 到 `atom3` 的原子，其中索引为 `atom2` 和 `atom3` 的原子也包含在该组内。这些约束扫描会施加一个谐振势（harmonic potential）来影响几何优化。
**Q-Chem** 还支持用于典型 S${}_{\rm N}$2 反应过渡态搜索的约束 PES 扫描，其几何约束形式为

<a id="Ch9.E47"></a>

$$
f(R)=k\left(R_{12}\pm R_{34}-R\right)^{2}\;. \tag{9.47}
$$

其中，$R_{12}$ 和 $R_{34}$ 是反应坐标中的两个键长，$k$ 是将 $R$ 约束在 $R_{12}\pm R_{34}$ 范围内的力常数。
要执行约束 PES 扫描，应采用以下格式指定。

> ```qchem
> $scan
>  r12      atom1  atom2  Rmax   Rmin   incr  force_constant
>  ...
>  rbend    atom1  atom2  atom3  Rmax   Rmin  incr  force_constant
>  ...
>  rtors    atom1  atom2  atom3  atom4  Rmax  Rmin  incr  force_constant
>  ...
>  r1to23   atom1  atom2  atom3  Rmax   Rmin  incr  force_constant
>  ...
>  r1toset  atom1  atom2  atom3  Rmax   Rmin  incr  force_constant
>  ...
>  r12mr34  atom1  atom2  atom3  atom4  Rmin  Rmax  incr  force_constant
>  ...
>  r12pr34  atom1  atom2  atom3  atom4  Rmin  Rmax  incr  force_constant
>  ...
> $end
> ```

???+ example "示例 9.22: 氯甲烷 S ${}_{\text{N}}$ 2 反应的一维约束 PES 扫描"
    ```qchem
    $molecule
      -1 1
       C     0.418808   -1.240869    0.249048
       Cl   -0.775224   -1.495584    1.586668
       H     1.408172   -1.490565    0.631227
       H     0.147593   -1.907736   -0.568952
       H     0.413296   -0.199000   -0.092071
       Cl    1.947359    1.619163   -1.747832
    $end
    
    $rem
       JOBTYPE   pes_scan
       METHOD    b3lyp
       BASIS     6-31G*
    $end
    
    $scan
       r12mr34 1 2 1 6 -2.0 2.0 0.2 1000.0
    $end
    ```
