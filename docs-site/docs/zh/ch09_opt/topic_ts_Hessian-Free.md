## 9.2.3 无需 Hessian 的驻点特征判定

(2026 年 7 月 4 日)

**Q-Chem** 允许用户对在几何优化或过渡态搜索中所找到的驻点进行特征判定，而无需执行完整的解析 Hessian（海森矩阵）计算——后者在某些情况下不可用，或计算代价过高。该功能通过 Sharada *et al.*[[1243]](../bib_references/bib.md#bib1297)
 开发的有限差分 Davidson（戴维森）过程实现。对于几何优化，它求解 Hessian 的最小本征值（$\lambda_{1}$）并检查是否满足 $\lambda_{1}>0$（若 $\lambda_{1}$ 为负则表明该点为鞍点）；对于过渡态（TS）搜索，它求解最小的两个本征值，而 $\lambda_{1}<0$ 且 $\lambda_{2}>0$ 则表明该点为过渡态。在收敛时，将更新后的 P-RFO（近似）Hessian 的最小本征向量用作 Davidson 求解器的初始猜测。

这种无需 Hessian 的特征判定方法的费用取决于 Davidson 求解器的收敛速度。例如，要判定一个能量极小点，需要总计 $2\times N_{\mathrm{iter}}$ 次能量 + 梯度计算，其中 $N_{\mathrm{iter}}$ 是 Davidson 算法收敛所需的迭代次数，而"2"对应每次迭代中的前向与后向位移。根据文献 [[1243]](../bib_references/bib.md#bib1297)
，对于规模较大的体系，该方法的效率可能远高于精确的 Hessian 计算。

!!! note "Note"
    目前，该方法不支持 QM/MM（量子力学/分子力学）或含有冻结原子的体系。


### `GEOM_OPT_CHARAC`

> **使用有限差分 Davidson 方法对所得到的能量极小点/过渡态进行特征判定。**
>
> * **类型**: `BOOLEAN`
> * **默认值**: `FALSE`
> * **取值选项**:
>     * `FALSE`: 不对所得驻点进行特征判定。
>     * `TRUE`: 对驻点进行特征判定。
> * **建议**: 当需要确认驻点的性质时（尤其是过渡结构），将其设置为 TRUE。

### `GEOM_OPT_CHARAC_CONV`

> **覆盖 Davidson 求解器内置的收敛判据。**
>
> * **类型**: `INTEGER`
> * **默认值**: `0 (use the built-in default value 10`
> * **取值选项**:
>     * $n$: 将收敛判据设置为 10 ${}^{-n}$。
> * **建议**: 使用默认值。若不收敛，可谨慎地放宽该判据。
