## 9.12.2 团簇优化作业控制

(2026 年 7 月 4 日)

### `NSEARCH`

> **INTEGER（整数）**
>
> * **类型**: `设置生成并优化的结构数目。`
> * **默认值**: `无默认值。`
> * **选项**:
>     * 由用户定义。
> * **建议**: 无

### `SEARCH_ATOMIC`

> **对原子团簇执行优化。**
>
> * **类型**: `BOOLEAN（布尔值）`
> * **默认值**: `False`
> * **选项**:
>     * `True`: 将执行原子团簇搜索。
>     * `False`: 将执行分子团簇搜索。
> * **建议**: 使用 N_SWOP 指定在结构生成过程中进行原子交换的原子序数。

### `N_SWOP`

> **INTEGER（整数）**
>
> * **类型**: `设置原子团簇搜索中坐标交换（swop）的原子数目。`
> * **默认值**: `无默认值。`
> * **选项**:
>     * 由用户定义
> * **建议**: 无

### `N_MOL_TYPE`

> **INTEGER（整数）**
>
> * **类型**: `设置不同原子或分子类型的数目。`
> * **默认值**: `无默认值。`
> * **选项**:
>     * 由用户定义：可取 1 或 2。
> * **建议**: 无

### `NMOL1`

> **INTEGER（整数）**
>
> * **类型**: `设置类型 1 分子的数目。`
> * **默认值**: `无默认值。`
> * **选项**:
>     * 由用户定义。
> * **建议**: 无

### `N_ATOM_TYPE_1`

> **INTEGER（整数）**
>
> * **类型**: `设置类型 1 分子中的原子数目。`
> * **默认值**: `无默认值。`
> * **选项**:
>     * 由用户定义。
> * **建议**: 无

### `NMOL2`

> **INTEGER（整数）**
>
> * **类型**: `设置类型 2 分子的数目。`
> * **默认值**: `无默认值。`
> * **选项**:
>     * 由用户定义。
> * **建议**: 无

### `N_ATOM_TYPE_2`

> **INTEGER（整数）**
>
> * **类型**: `设置类型 2 分子中的原子数目。`
> * **默认值**: `无默认值。`
> * **选项**:
>     * 由用户定义。
> * **建议**: 无

### `MAXBOX`

> **设置分子被限制在其中的盒（box）尺寸。**
>
> * **类型**: `INTEGER（整数）`
> * **默认值**: `20000`
> * **选项**:
>     * $n$: 对应于 = $n/1000$ bohr。
> * **建议**: 需要确保团簇能够容纳在该盒子内。

### `MIN_SEPARATION`

> **当分子间最短距离小于该值时，拒绝初始结构。**
>
> * **类型**: `INTEGER（整数）`
> * **默认值**: `300`
> * **选项**:
>     * $n$: 对应于 = $n/100$ bohr。
> * **建议**: 约为 2.5 bohr。

### `MAX_DISPLACE`

> **设置平移过程中分子移动的最大距离。**
>
> * **类型**: `INTEGER（整数）`
> * **默认值**: `500`
> * **选项**:
>     * $n$: 对应于 = $n/100$ bohr。
> * **建议**: 无。

### `SCF_NOCRASH`

> **确保当某个结构的 SCF（自洽场）计算不收敛时，整体计算仍继续进行。**
>
> * **类型**: `BOOLEAN（布尔值）`
> * **默认值**: `False`
> * **选项**:
>     * `True`: 确保计算继续处理下一个结构。
>     * `False`: 计算将停止。
> * **建议**: 设置为 = TRUE。

### `TIGHTEN_CONVERG`

> **在搜索结束后，使用更严格的 SCF 收敛标准重新计算已优化结构的能量。**
>
> * **类型**: `BOOLEAN（布尔值）`
> * **默认值**: `False`
> * **选项**:
>     * `True`: 执行使用更严格 SCF 收敛标准的附加计算。
>     * `False`: 不执行附加计算。
> * **建议**: 无。

### `USE_INITIAL`

> **将输入结构包含在搜索过程中。**
>
> * **类型**: `BOOLEAN（布尔值）`
> * **默认值**: `False`
> * **选项**:
>     * `True`: 输入结构被包含在搜索中。
>     * `False`: 输入结构不被包含在搜索中。
> * **建议**: 无。

### `SEARCH_MOM`

> **允许结合 MOM（最大占据方法，Maximum Occupied Method）进行搜索，以探索激发态。**
>
> * **类型**: `BOOLEAN（布尔值）`
> * **默认值**: `False`
> * **选项**:
>     * `True`: 执行结合 MOM 的搜索。
>     * `False`: 执行不使用 MOM 的常规计算。
> * **建议**: 无。
