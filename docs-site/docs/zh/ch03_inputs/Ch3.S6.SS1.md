## 3.6.1 概述

（2026 年 7 月 4 日）

当使用以下方式调用 **Q-Chem** 时

> ```qchem
> # qchem infile outfile
> ```

输出文件 *outfile* 包含各类信息，具体取决于作业类型，但一般而言包括以下内容。

- •

**Q-Chem** 引用文献
- •

用户输入（用于存档记录）
- •

以笛卡尔坐标表示的分子几何结构
- •

分子点群、核排斥能、$\alpha$-自旋和 $\beta$-自旋电子数
- •

基组（Basis Set）信息（函数数目、壳层（shells）及函数对数目）
- •

自洽场（SCF）细节（方法、初始猜测（guess）及收敛过程）
- •

每次 SCF 迭代的能量与 DIIS 误差
- •

任何激发态计算的结果
- •

波函分析
